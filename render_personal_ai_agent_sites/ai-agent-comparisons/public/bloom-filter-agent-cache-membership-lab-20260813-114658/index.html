The probability

Collisions buy compression.

Insert

Hash each key k times and set those bit positions to one. Existing ones remain one.

bit[hᵢ(key)] = 1

Query

If any queried bit is zero, the key is definitely absent. If every bit is one, the key may be present.

all ones → maybe · any zero → no

Tune

The optimal hash count is approximately bits per item multiplied by ln 2. Too many hashes saturate the filter.

k ≈ (m / n) ln 2

No false negatives

A standard Bloom filter never rejects an inserted key, provided bits are not deleted independently.

Counting deletes

Counters replace bits so deletions decrement positions without erasing evidence contributed by other keys.

Cuckoo relocation

Fingerprints live in small buckets and can be relocated, enabling deletion and high occupancy with a different failure profile.
