A tiny matrix buys a useful frequency oracle.

Update one counter in every row

Each independent hash maps the event key into one column. Standard updates increment all selected counters. Conservative updates increment only selected counters equal to the current minimum, reducing collision noise.

C[r, hᵣ(x)] += 1

Ask for the minimum

The estimate is the smallest selected counter. Since the event itself touched every selected cell, the answer never falls below the true frequency.

f̂(x) = minᵣ C[r,hᵣ(x)]

Width controls error

More columns reduce unrelated keys sharing counters. More rows reduce the chance that every selected counter is badly contaminated.

width ≈ e / ε
depth ≈ ln(1/δ)
