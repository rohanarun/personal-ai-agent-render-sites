Infinite depth is a numerical contract.

The layer output is not assigned after a fixed number of blocks. It is defined by a root. Architecture, solver, tolerance, and Jacobian regularity jointly determine whether that root is found efficiently and whether the implicit backward equation is well conditioned.

The hidden state defines itself.

A weight-tied transformation receives the input and its own current state. A black-box solver searches for the point where update and state agree.

z* = f_theta(z*, x)   and   g(z*) = f_theta(z*, x) - z* = 0

Convergence compresses a whole trajectory.

The final representation can be stored without retaining every forward iterate.

Forward solve

Plain iteration is transparent but can oscillate. Damping trades step size for stability. Anderson acceleration mixes residual history.

z_(k+1) = f(z_k, x)

Implicit backward

The implicit function theorem turns backpropagation through iterations into a linear fixed-point solve.

(I - J_f(z*)^T) v = dL/dz*

Constant memory

Implicit differentiation avoids storing the forward path, but the backward solve still costs iterations and can become unstable near singularity.

dL/dtheta = v^T df_theta/dtheta

The same Jacobian governs both directions.

Near one, convergence crawls.

As the local spectral radius approaches one, fixed-point residuals shrink slowly. Forward latency rises and the inverse in the implicit gradient becomes poorly conditioned.

Beyond one, iteration can diverge.

A nonlinear system may still possess a root even when naive iteration is not contractive. Solver choice, damping, regularization, initialization, and problem structure determine whether training can reach it.

A loose tolerance changes the model.

Stopping early does not merely save compute. It returns a different hidden state and a different gradient. Track residuals and task metrics together across training and deployment.

Operate the solver as part of the network.

Tolerance
Budget error explicitly.

Calibrate forward and backward tolerances against task quality, not only wall-clock speed. Record iteration distributions, not just means.

Jacobian
Regularize local dynamics.

Jacobian penalties can improve stability and reduce solver work, but they also shape the functions the model can represent.

Warm start
Reuse nearby equilibria carefully.

Sequential inputs can provide strong initial states. Distribution shifts can make stale warm starts misleading or unstable.

Telemetry
Monitor both root solves.

Forward convergence does not guarantee a healthy backward solve. Log residual curves, failures, fallbacks, and gradient norms independently.
