An edit is a four-objective evaluation, not a single changed answer.

Locate, write, then test the neighborhood.

ROME treats a factual association as a key-value relation in a feed-forward layer and applies a rank-one update. The intervention is only useful when the new relation appears under varied prompts without overwriting nearby knowledge.

new fact + paraphrases + neighbors + generation quality

Editing strength has two failure modes.

Too little intervention leaves the old fact intact. Too much raises efficacy while damaging specificity, fluency, or other memories.

Efficacy

Does the direct rewrite prompt prefer the requested answer over the old one?

Generalization

Does the edit survive paraphrases, aliases, and semantically equivalent prompts?

Locality

Do unrelated and semantically adjacent facts remain unchanged?

Choose a method that fits the edit volume.

Rank-one rewrite

ROME targets one factual association with a localized matrix update. Inspect causal localization and specificity for every edit.

Mass memory edit

MEMIT distributes many updates across a range of mediating layers. Capacity and interference become central as the edit batch grows.

Learned editor

MEND transforms edit gradients using a learned low-rank decomposition, optimizing fast updates and locality over an edit distribution.
