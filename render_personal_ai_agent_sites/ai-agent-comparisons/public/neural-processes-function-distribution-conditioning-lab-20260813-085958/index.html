Represent a set. Predict a process.

A Neural Process maps an unordered context set into a representation, then decodes target inputs into distributions. A global latent variable links target predictions into coherent sampled functions.

Context becomes a permutation-invariant representation.

Each observed pair is encoded, then pooled or attended so order does not change the represented task.

r_C = aggregate_i h(x_i, y_i)

Targets query the conditioned process.

The decoder combines target coordinates with context representation and latent state.

p(y_T|x_T,C)=int p(y_T|x_T,r_C,z)q(z|C)dz

Latents create global coherence.

One sampled z shifts an entire function, unlike independent noise at each target.

Attention preserves locality.

Cross-attention lets each target emphasize nearby or relevant context instead of sharing one pooled vector.

Meta-training spans tasks.

The model learns to infer a new function from contexts because training repeatedly varies functions and context splits.

Uncertainty can look smooth and still be wrong.

Underfitting erases context.

A single mean-pooled representation can bottleneck detailed observations, producing smooth predictions that miss local structure.

Latent collapse removes diversity.

If the decoder ignores z, nominal function samples become nearly identical. Inspect sample correlation and task-level diversity.

Coverage is not calibration.

Wide intervals can cover the truth without useful sharpness. Measure coverage and width together across held-out tasks.
