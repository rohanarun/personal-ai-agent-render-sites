Hash every memory bucket

Each leaf commits to its records. Any content change produces a different leaf digest.

leafᵢ = H(bucketᵢ)

Combine child hashes

Parents hash ordered child digests until one root summarizes the entire replica.

parent = H(left || right)

Descend only mismatches

Equal parent hashes prove every descendant matches. Unequal parents are opened until divergent leaves are isolated.

equal hash ⇒ equal subtree

Agent-system actions

  • Partition memory into stable key ranges.
  • Use canonical serialization before hashing.
  • Version repair writes and resolve conflicts.
  • Run anti-entropy continuously in the background.
