The continuous block

A vector field becomes a network when you integrate it.

The model parameterizes the derivative, not a finite sequence of states. Solver behavior is therefore part of the model’s effective computation graph and numerical contract.

Define hidden-state dynamics

A neural network f maps current state, time, and parameters to an instantaneous derivative. Integration composes infinitely small transformations conceptually, but finite solver evaluations realize them numerically.

dz(t)/dt = fθ(z(t), t)

Integrate to the readout time

The terminal state feeds the prediction head. Irregular observation times can be queried without redesigning a discrete layer stack.

Fixed-step solvers

Euler is cheap and first order. RK4 spends four evaluations per step for much smaller truncation error on smooth dynamics.

zₙ₊₁ = zₙ + h f(zₙ)

Adaptive depth

Embedded estimates adjust h to meet a local tolerance. Difficult regions automatically become deeper.

Adjoint sensitivity

Backward integration evolves a gradient state instead of storing every forward activation. Numerical reversibility and solver error now affect gradient fidelity.

da/dt = −aᵀ ∂f/∂z
Numerical failure modes

The solver is part of the learned system.

A smooth architecture can still produce difficult dynamics. Measure function evaluations, tolerance sensitivity, rejected steps, backward error, and task quality together.

Stiffness collapses explicit step sizes.

Fast and slow modes coexist. Stability, rather than desired accuracy, can force an explicit solver into many tiny updates.

Adaptive compute changes per example.

Different inputs can trigger different numbers of evaluations. This flexibility complicates batching, latency guarantees, and accelerator utilization.

NFE

Backward reconstruction can drift.

The memory-efficient adjoint method reconstructs a trajectory by solving backward. Non-reversible or chaotic dynamics can separate it from the forward path.

Report a curve, not one tolerance.

Compare prediction quality, terminal-state error, function evaluations, and wall time across tolerances. A tiny local tolerance need not improve task quality.

Match the integrator to the dynamics.

Explicit methods suit smooth non-stiff flows. Stiff systems may need implicit solvers, regularized dynamics, or architectural constraints.

Compare adjoint and direct differentiation.

On small problems, verify parameter gradients against stored-trajectory autodiff and finite differences before trusting memory savings.
