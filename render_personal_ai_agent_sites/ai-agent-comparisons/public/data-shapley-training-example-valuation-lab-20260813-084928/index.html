Credit depends on who else showed up.

A point can be redundant in a rich coalition and essential in a sparse one. Shapley value resolves that context dependence by averaging marginal gains over every insertion order.

Average the before-and-after utility.

For every subset that excludes point i, compare model utility before and after adding i, weighted so every coalition size receives fair representation.

phi_i = sum_S |S|!(n-|S|-1)!/n! [v(S union i)-v(S)]

Exact value is exponential.

Eight points need 256 coalition utilities. Real datasets require approximation, reuse, truncation, or structural assumptions.

cost proportional to 2^n model evaluations

Leave-one-out sees one coalition.

Removing a point only from the full dataset misses contributions that appear in smaller groups.

LOO_i = v(D)-v(D without i)

Permutation sampling is unbiased.

Random insertion orders estimate the same average marginal contribution while exposing Monte Carlo error.

Utility defines value.

Accuracy, class balance, robustness, fairness, and calibration can rank the same points differently.

data value is conditional on v(S)

A valuation is not an intrinsic price tag.

Correlated points share credit.

Duplicates and near-duplicates can divide value even when the cluster is important. Individual scores must be interpreted alongside groups and acquisition policy.

Utility can hide harm.

Aggregate accuracy may reward majority-class examples while undervaluing rare cases. Change the lab to balanced utility and watch attribution move.

Approximation changes rankings.

Small permutation budgets produce noisy estimates, especially when marginal contributions have high variance. Convergence diagnostics belong beside every score.
