Whether the path stays in a low-loss region.

Weight averaging is simple. Compatibility is the hard part.

Linear interpolation asks a sharp question.

Connect checkpoints A and B with a straight line in parameter space and evaluate models along it. A low curve suggests linear mode connectivity; a high midpoint reveals a loss barrier.

θ(α) = (1 − α) θA + α θB

Coordinates can disagree while functions agree.

Hidden units may be permuted across two networks. Averaging unmatched neurons mixes unrelated features, even when the endpoint models implement similar functions.

Re-basin first

Match or permute units before averaging. Alignment can reveal a low-loss path hidden by representational symmetry.

Use a curved connector

A polygonal or learned curve can bend around a linear barrier, showing that the solutions still belong to one broader connected region.

Build a soup

Average checkpoints fine-tuned from the same initialization, accepting an ingredient only when validation performance improves.

Choose the merge protocol that matches the evidence.

Naive average

Fast and parameter-free. Best when checkpoints share initialization, architecture, optimizer history, and a compatible basin.

Aligned average

Resolve permutation mismatch before interpolating. Verify that alignment reduces the barrier rather than merely changing weight distance.

Greedy soup

Begin with the strongest validation checkpoint, test candidate additions, and keep only averages that improve the chosen held-out objective.
