Three ways more inference compute stops helping.

Correlated errors

Every sample inherits the same misconception, so consensus rises while accuracy remains wrong.

Low-value diversity

Paths differ in wording but share the same latent computation. Unique text is not unique evidence.

Verifier overfit

A learned scorer prefers familiar formatting or verbosity, allowing persuasive failures to outrank concise correct work.
