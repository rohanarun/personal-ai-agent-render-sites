Superposition is a capacity strategy, not merely a naming problem.

Sparsity makes sharing possible.

If two features rarely activate together, their directions can overlap without corrupting most examples. Models can therefore represent a larger feature dictionary than the residual-stream width alone suggests.

capacity gain ↑ as simultaneous activation ↓

Interference is the price.

When shared features co-activate, their non-orthogonal directions produce cross-talk. Importance, frequency, and sparsity determine which features earn cleaner directions.

Neuron view

One coordinate can respond to several unrelated features. A polysemantic neuron is therefore a projection of a distributed code, not necessarily the code's natural unit.

Feature view

A feature is a direction or pattern that helps explain model behavior. Features may be distributed across many neurons and need not align with basis axes.

Dictionary view

Sparse autoencoders learn an overcomplete dictionary whose activations aim to separate recurring directions into more interpretable latent features.

Three views of the same activation.

Coordinates

Read raw neuron activations. This view is exact, cheap, and basis-dependent, but a single coordinate can mix several concepts.

Directions

Inspect feature vectors and their pairwise angles. Near-orthogonal directions interfere less; tightly packed directions permit greater capacity.

Sparse dictionary

Encode an activation using a small set of dictionary elements, then decode it. Measure reconstruction loss, sparsity, feature stability, and causal usefulness.
