Add a function the optimizer cannot erase.

Each member predicts with a trainable network plus a fixed random prior function. Data trains the residual to fit observations, while the untouched prior keeps members distinct where the likelihood supplies little evidence.

A fixed prior survives optimization.

The prior network is sampled once and never trained. Only its paired residual network receives gradient updates.

Q_k(x) = f_k(x; theta_k) + beta p_k(x)

Data can cancel the prior locally.

Inside observed support, the residual learns against the prior so members agree with evidence. Outside it, cancellation is unconstrained.

theta_k minimizes loss(y, f_k(x)+beta p_k(x))

Ensemble spread is epistemic.

Member disagreement approximates uncertainty about functions, not irreducible observation noise.

Bootstraps diversify evidence.

Resampling data per member adds posterior-like variation, but prior diversity remains important beyond support.

Uncertainty drives exploration.

Optimistic or information-seeking policies can prefer inputs with high predicted value or high ensemble spread.

Disagreement is useful only when it means something.

Prior scale can dominate.

Oversized priors create dramatic OOD spread but can damage in-domain fit. Tune scale against calibration and decision outcomes, not visual width.

Shared bias can hide uncertainty.

Members with identical architecture, data, and optimization may agree for the same wrong reason. Diverse priors do not repair missing hypotheses automatically.

OOD truth remains unknowable.

High disagreement flags ignorance; low disagreement does not prove correctness. Evaluate held-out shifts and exploration regret.
