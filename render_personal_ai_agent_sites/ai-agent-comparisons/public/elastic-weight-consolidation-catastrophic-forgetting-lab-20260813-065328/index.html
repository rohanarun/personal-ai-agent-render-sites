The consolidation mechanism

Not every weight carries equal memory.

EWC uses the diagonal Fisher information as a local estimate of how strongly each parameter matters to the old task. Moving a sensitive parameter costs more than moving an irrelevant one.

Estimate importance after Task A

Gradients of the old task’s log likelihood reveal which coordinates its predictions depend on. A diagonal approximation makes the memory cheap enough to store.

Fᵢ = E[(∂ log p(y|x, θ) / ∂θᵢ)²]

Freeze a soft anchor

Save the Task A optimum and its importance values. The weights remain trainable; their movement is priced, not forbidden.

Read the failure in order

Forgetting is a trajectory, not one final number.

Sequential learning changes a shared representation. The cards track the three moments that determine whether consolidation helped or merely made the model rigid.

Task A finds a useful basin.

The parameter vector settles near a minimum for the first task. Performance is high, but the solution is not isolated from future gradients.

Task B reuses the same capacity.

New gradients move coordinates that Task A also relied on. Without an old-task signal, nothing in ordinary fine-tuning distinguishes harmless movement from destructive drift.

Consolidation prices the collision.

EWC bends the path away from high-importance directions. The result can preserve more of A, but only while enough low-cost directions remain for B.

Tasks share a model but not every sensitive direction.

Soft parameter protection works best when a nearby solution can serve both tasks and the Fisher approximation reflects real old-task sensitivity.

The penalty can turn memory into rigidity.

If tasks conflict strongly, the diagonal Fisher is misleading, or λ is too large, Task B remains underfit even while Task A looks stable.

Replay, expansion, isolation, and regularization solve different constraints.

Match memory budgets and data access. Replay stores examples; adapters isolate capacity; EWC stores old parameters plus importance estimates.

Evaluation lens
“Retention without plasticity is not continual learning.”

Measure Task B quality alongside Task A retention. A frozen model remembers perfectly and learns nothing.
