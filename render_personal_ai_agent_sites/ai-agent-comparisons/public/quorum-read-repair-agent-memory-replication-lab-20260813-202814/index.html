Overlap finds the newest memory.

Quorums let a replicated system trade latency and availability against stronger freshness guarantees.

1

Write to W replicas.

A successful write acknowledges after W replicas store a higher version. Partitioned replicas may remain stale.

2

Read from R replicas.

The coordinator compares versions from the read quorum and returns the newest observed value. If R + W exceeds N, at least one contacted replica saw the successful write.

3

Repair stale respondents.

Read repair sends the chosen newest value back to stale replicas, gradually converging the memory without pausing the agent system.
