Distance enters before softmax.

ALiBi leaves token embeddings untouched. Each head receives a fixed slope, creating different recency ranges while preserving a score for every causal distance.

One linear term changes the geometry

Ordinary attention scores content compatibility. ALiBi subtracts slope times query-key distance before softmax. Far keys need stronger content evidence to overcome the penalty.

softmax(q_i K^T / sqrt(d) - m_h x [0, 1, ..., i])

Heads see different horizons

Steep slopes focus locally. Shallow slopes preserve longer-range candidates. Combining them gives the layer multiple distance priors.

m_h follows a geometric schedule

No learned table

Absolute learned embeddings allocate trainable vectors to positions seen during training. ALiBi allocates none.

Still quadratic

ALiBi changes attention scores, not the number of query-key pairs. It does not make full attention linear-time.

Not a guarantee

Defined scores beyond training length do not guarantee perfect retrieval, generation quality, or unlimited context.

Defined is not the same as solved.

Position mechanisms shape how a model generalizes, but training distribution, task structure, attention patterns, and inference memory still determine usable context.

Test the boundary

The training edge

Learned absolute positions have no trained vector after the maximum sequence length. Extending or interpolating that table introduces behavior the model did not optimize.

01

The distance prior

ALiBi applies the same distance rule on both sides of the training edge. The model still sees unfamiliar long sequences, but the position function itself does not stop.

02

The systems bill

A 4x longer sequence creates roughly 16x as many full-attention score pairs. Position extrapolation does not remove KV-cache growth, memory bandwidth, or latency.

Compare what each method changes.

Hover or focus to expand. These mechanisms are not interchangeable: they act on embeddings, vector phases, or logits and expose different extrapolation behavior.

Learned absolute

Position vectors

Add a trainable embedding for each supported index. Flexible inside the trained window, undefined outside it without a resizing strategy.

x_i = token_i + position_i
Rotary

Relative phase

Rotate query and key channels by position-dependent angles. Their dot product carries relative displacement; scaling methods alter long-range behavior.

q_i = R(i)q, k_j = R(j)k
ALiBi

Linear score bias

Subtract distance directly from each head's causal logits. No position vector is added to the residual stream.

score(i,j) = content(i,j) - m_h(i-j)
Evaluation

Real long tasks

Measure retrieval by position, perplexity by length, generation coherence, latency, memory, and task quality rather than one synthetic score.

defined bias != verified capability
