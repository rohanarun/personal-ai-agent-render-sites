Factor the matrix instead of every element.

For a matrix gradient G, Shampoo maintains covariance on both axes. Their inverse roots transform the update toward isotropic geometry without storing a full covariance over all parameters.

Two factors capture two axes

The left factor summarizes correlations among rows. The right factor summarizes columns. Exponential moving averages accumulate curvature information over steps.

L_t = beta L_(t-1) + (1-beta) G_t G_t^T
R_t = beta R_(t-1) + (1-beta) G_t^T G_t

Inverse roots rebalance scale

Large-variance directions shrink; weak directions grow. Numerical damping keeps tiny eigenvalues from exploding.

P_t = L_t^(-1/4) G_t R_t^(-1/4)

Cadence

Matrix roots are expensive. Recompute them periodically and reuse stale roots between updates.

Grafting

Use Shampoo's direction but match the norm of SGD, Adagrad, or Adam to inherit a known learning-rate scale.

Blocking

Large dimensions are split into bounded blocks so inverse roots and state fit device memory.

Second-order shape has first-order costs.

Preconditioning can shorten the path through difficult geometry, but factor storage, inverse roots, numerical stability, and distributed communication all become operational constraints.

Stress the workbench

Ill-conditioning

SGD must choose a step small enough for the steep direction, then crawls along the flat direction. Rotating the basin makes coordinate-wise scaling less aligned with curvature.

Stale preconditioners

Infrequent inverse-root updates save compute. If curvature changes quickly, stale factors can point the update through geometry that no longer exists.

State and communication

A matrix with r by c parameters stores r squared plus c squared factor entries. Block size and sharding policy decide whether that is affordable.

Compare the state each method remembers.

Hover or focus each optimizer. The trade is not “smart versus simple”; it is geometry, invariance, memory, kernel cost, tuning, and distributed behavior.

Raw first order

SGD

One global learning rate follows the gradient. Momentum adds a velocity but does not explicitly correct rotated curvature.

update = -eta x gradient
Coordinate adaptive

Adam

Per-parameter first and second moments normalize coordinates. Efficient and robust, but not invariant to rotations of a matrix parameterization.

update = -eta m / (sqrt(v) + eps)
Matrix adaptive

Shampoo

Left and right factors preserve axis structure, approximating a richer preconditioner with tractable state.

update = -eta L^-1/4 G R^-1/4
Natural geometry

K-FAC

Kronecker factors approximate Fisher blocks for layerwise natural-gradient updates. Its assumptions and factors differ from Shampoo.
