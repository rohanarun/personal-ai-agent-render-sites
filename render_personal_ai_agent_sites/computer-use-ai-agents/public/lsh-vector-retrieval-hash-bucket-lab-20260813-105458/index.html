Find nearby vectors without scanning everything.

Random-hyperplane locality-sensitive hashing turns vector directions into bit signatures. Similar vectors collide in the same buckets, so an agent can search a small candidate set before computing exact similarity.

Approximate retrieval

Trade a little certainty for a lot less search.

Each hyperplane asks one binary question: which side is the vector on? Stack the answers into a signature, group matching signatures into buckets, then inspect only nearby buckets. More bits shrink the candidate set; more probes recover neighbors split by a boundary.

The mechanism

Angle becomes address.

Project

A random plane passes through the origin. The sign of a vector’s dot product with the plane normal becomes one bit.

sign(r · x) → 0 or 1

Concatenate

Several independent planes produce a compact signature. Nearby directions have a higher probability of sharing every bit.

101101 → bucket 45

Probe

Search the matching bucket, then optionally visit signatures one or two bit flips away. Exact cosine distance reranks only those candidates.

101101 → {101100, 101111…}

More bits

Sharper buckets reduce work but increase boundary misses. The live frontier shows where candidate savings begin costing recall.

More probes

Nearby Hamming buckets rescue true neighbors split by one plane, trading extra distance computations for coverage.

More tables

Independent hash families create several chances for near vectors to collide. Union their candidates, then rerank exactly.
