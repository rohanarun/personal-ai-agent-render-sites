Discovery indices record visit order. Low-link values record the earliest active vertex reachable from a subtree.

Discover depth first.

Give each stage a monotonically increasing index, push it onto the active stack, and follow every outgoing dependency.

index[v] = low[v] = nextIndex

Propagate the oldest reach.

A tree edge inherits its child's low-link value. A back edge to an active stage lowers the current value to that stage's discovery index.

low[v] = min(low[v], low[w] or index[w])

Pop one complete component.

When a stage's low-link equals its own index, nothing in its active subtree reaches an earlier stack member. Pop through that root.
