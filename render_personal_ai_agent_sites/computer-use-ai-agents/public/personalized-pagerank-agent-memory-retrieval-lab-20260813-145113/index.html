Calculating the retrieval neighborhood.

A local compass for connected memory.

Personalized PageRank alternates between following a memory link and teleporting back to the task seed. Repeated walks transform local connections into a stable relevance score. High restart values stay literal. Lower values discover multi-hop context, but risk drifting into popular, weakly related clusters.

r(t+1) = alpha · seed + (1 - alpha) · Pᵀr(t)
01

Normalize the links

Each memory distributes its current probability across outgoing semantic or causal links. Link weights become transition probabilities.

02

Return to intent

With probability alpha, the walk restarts at the selected seed. That task-specific teleport vector is what makes PageRank personalized.

03

Iterate to stability

The score vector converges toward a stationary distribution. Ranking that distribution yields a connected retrieval set, not just nearest neighbors.
