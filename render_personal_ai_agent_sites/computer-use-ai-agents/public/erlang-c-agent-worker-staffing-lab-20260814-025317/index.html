Why averages fail near saturation.

Capacity greater than demand is necessary, but the margin controls how quickly a shared queue drains after random arrival clusters.

Offered load converts work into workers.

Multiply arrivals per unit time by mean service time. The result, measured in Erlangs, is the average number of workers that would be busy if capacity were unlimited.

a = λ / μ = arrivals × service time

Utilization marks the cliff.

Divide offered load by worker count. At or above one, arrivals meet or exceed service capacity and no finite steady-state queue exists.

ρ = a / c < 1

Erlang C estimates the tail.

The probability that every worker is busy gives the chance a task waits. Above any threshold t, the remaining wait tail decays exponentially with spare service capacity.

P(Wq > t) = C(c,a) · e^(−(cμ−λ)t)

Know where the model stops matching reality.

Variable task classes

Research calls and cache lookups have different service distributions. Segmenting classes or simulating traces can reveal bottlenecks hidden by one mean.

Cold worker startup

Erlang C treats all workers as immediately available. Autoscaling delays require headroom or a transient model before new capacity actually serves tasks.

Overload policy

No staffing formula rescues unbounded demand. Admission control, backpressure, deadlines, and load shedding remain necessary beyond the planned envelope.
