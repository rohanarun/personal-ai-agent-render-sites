The observed MMD² sits inside the shuffled-label null distribution.

MMD² = E[k(X,X′)] + E[k(Y,Y′)] − 2E[k(X,Y)]
k(a,b) = exp(−||a−b||² / 2σ²)

A scalar score answers whether. The witness field answers where. The permutation test asks whether chance is still plausible.
