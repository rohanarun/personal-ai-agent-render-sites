Three reactions one control signal.

The signs are arranged for this plant: high latency error asks for more workers. Anti-windup prevents a saturated pool from accumulating limitless integral pressure.

Proportional: react now

P responds directly to current error. It is fast, but too much gain can overshoot and oscillate.

Pₜ = Kp · eₜ

Integral: remember

I accumulates persistent error, eliminating steady bias while risking windup.

Iₜ = Ki · Σe

Derivative: anticipate

D responds to how quickly error changes. It damps abrupt movement but amplifies noisy measurements.

Dₜ = Kd · (eₜ−eₜ₋₁)

Agent-systems practice

  • Measure the actual service objective, not an easy proxy.
  • Clamp worker output and integral state to operational bounds.
  • Retune when tool latency dynamics or quotas change.
  • Keep a fallback policy for outages and discontinuities.
