Learn heartbeat arrivals

The detector maintains a distribution of recent inter-arrival times for each worker instead of assuming one universal network delay.

Δᵢ = arrivalᵢ − arrivalᵢ₋₁

Accrue a continuous score

Phi is the negative log probability that silence this long is still normal. Larger values mean stronger evidence of failure.

φ(t) = −log₁₀ P(later than t)

Separate evidence from policy

The detector reports Phi; the system decides when to warn, reroute, or evict. Thresholds can differ by workload.

act iff φ ≥ threshold

Agent-system actions

  • Model local latency rather than global averages.
  • Use indirect probes before costly eviction.
  • Require incarnation numbers for recovery.
  • Track false positives as an operational metric.
