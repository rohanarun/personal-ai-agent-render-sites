Different denominators, different ranking

Aggregate rates average the two task groups with different weights. Model B can receive enough easy tasks to overcome its lower success probability in each group. This is a constructed example of Simpson's paradox.

Find the reversal boundary

Let a and b be the easy-task fractions for A and B. A scores 0.40 + 0.50a; B scores 0.30 + 0.50b. B leads exactly when b - a is greater than 0.20. At a difference of 20 percentage points, the aggregate rates tie.

Why the common mix helps

Using the same task weights for both models preserves A's ten-point advantage in this example. The 50/50 row answers how the models compare on that particular reference distribution. Choose a reference mix that matches the evaluation question; 50/50 is illustrative, not universally correct.

What an evaluation report should retain

Report group-specific outcomes and group frequencies alongside the overall result. Actual benchmark estimates also need uncertainty and adequate support within groups. Arithmetic standardization alone does not establish a causal effect or prove how a model will perform on unseen tasks.
