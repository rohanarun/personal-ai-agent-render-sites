A wrong answer can be predictable or spread across several possibilities. Fano's inequality connects classification error to the uncertainty that remains after observing a noisy label.

Channel and decoder

X is uniform on 0, 1, 2, 3. Independent noise N has probabilities [1-e, e(1+2t)/3, e(1-t)/3, e(1-t)/3]. Y = X + N modulo 4. Predictions also wrap modulo 4.

Knowing that an error happened is not the whole story

H(X | Y) = h(Pe) + Pe H(N | N != d)
Fano: H(X | Y) <= h(Pe) + Pe log(3)
Slack = Pe [log(3) - H(N | N != d)]

For this cyclic channel, the error flag is independent of Y. Once the flag says the prediction is correct, X is known. Otherwise, up to three labels remain. Their entropy is at most log(3), which creates the Fano bound. Equal wrong-answer probabilities make it tight; concentrated errors leave slack.

The conditional entropy does not change when the decoder changes. Its error probability and bound can change. MAP chooses the most probable shift, breaking ties by the smallest index, and minimizes error for this uniform-prior model.

When Pe is zero, the wrong-answer conditional distribution is undefined; its weighted contribution is zero. Fano still holds for a poor decoder, even one that is always wrong. This exact four-class model uses ml-matrix for joint probabilities, not a fitted classifier. Natural logarithms and unrounded exports are used throughout.
