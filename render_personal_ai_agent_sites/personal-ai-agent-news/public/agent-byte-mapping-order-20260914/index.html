Map before the byte boundary.

A typed array is a conversion boundary. Once fractional or out-of-range values become unsigned bytes, a later map cannot recover the original inputs.

The two paths

const mapFirst = Uint8Array.from(source, fn);
const earlyBytes = Uint8Array.from(source);
const byteFirst = earlyBytes.map(fn);

With 256 and division by two, the first path maps 256 to 128 before storage. The second stores 256 as 0, then divides that 0. The final outputs are 128 and 0.

Uint8Array truncates finite fractional values and wraps integers into the range 0 through 255. It is not a clamp. This experiment uses ordinary Number inputs and native typed-array methods, not a model or simulated conversion engine.

Choose the intended boundary

For an agent pipeline that transforms numeric data into byte artifacts, decide whether the transform consumes original values or already-encoded bytes. Neither order is universally correct. Keep a source representation when the later calculation needs information that byte conversion discards.

This is a JavaScript conversion experiment, not a model-quantization benchmark or an image-processing recommendation. The source array is not mutated. Identical results for one input do not prove the pipelines interchangeable.
