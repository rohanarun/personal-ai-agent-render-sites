Permission should rise with consequence.

Observation is cheap to review. Proposals make intent concrete. Mutations change shared state. A tiered model helps an agent match proof and human visibility to the radius of its effect.

This is a compact teaching model. Production systems still need explicit authorization, provenance, rollback paths, and human review for consequential actions.
