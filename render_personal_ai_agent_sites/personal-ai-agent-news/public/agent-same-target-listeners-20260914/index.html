    The exact experiment

    Two bubbling listeners are registered on a detached child element in order, followed by a bubbling listener on its parent. A fresh, cancelable, bubbling custom event is dispatched for each run. No external task executes.

    Neither stop method cancels a default action. This experiment never calls preventDefault(), so defaultPrevented stays false and dispatchEvent() returns true. Capture listeners that ran earlier would not be undone.
    Routing is not authorization
    A UI event stop is not a security boundary, a rollback, or proof that an agent action was approved. Put permission checks at the action boundary. Other events and direct function calls can still invoke application logic.
