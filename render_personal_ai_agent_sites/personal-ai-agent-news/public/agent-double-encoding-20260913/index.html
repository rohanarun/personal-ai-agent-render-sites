Give one layer ownership
URLSearchParams accepts unencoded values. Its serializer escapes percent signs and uses + for spaces. Passing an already encoded value makes the percent signs data, so a later parse returns that encoded spelling rather than the original argument.
With the illustrative argument %2F, the intended value is three literal characters. The raw path preserves it after one parse. An extra decode turns it into a slash. “Decode until it looks right” has no reliable stopping rule without a representation contract.
At an agent-tool boundary, document whether each field is raw text, a serialized query, or a URL. Log the argument and the parsed result separately. This local exercise sends no request, invokes no agent, and does not establish how any particular server parses its inputs.
Read the mismatch precisely
A + supplied as a raw value is preserved by serialization. A + in an already serialized query has different semantics. The two paths can coincide for simple text; double encoding does not change every input. The optional extra decoder can throw URIError for a bare percent. The trace records that error rather than replacing the value.
The bars measure serialized ASCII query length, including q=. They are not token counts, latency or total network bytes. This demonstration uses ordinary text input; for lone UTF-16 surrogates and encoding failures, see the surrogate boundary lab.
