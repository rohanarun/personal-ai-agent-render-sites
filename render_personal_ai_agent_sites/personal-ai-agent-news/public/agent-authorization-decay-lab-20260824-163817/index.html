What the model shows

Freshness is part of least privilege.

Run a scenario to see how a valid approval loses context over time. A renewal is a deliberate check that the task, target, and permission still agree.

  • Sensitivity makes the same stale interval matter more for consequential actions.
  • Renewal cadence is a control surface: it limits how far intent can drift before review.
  • A pause is appropriate when the agent's current action needs more authority than the original approval expresses.
