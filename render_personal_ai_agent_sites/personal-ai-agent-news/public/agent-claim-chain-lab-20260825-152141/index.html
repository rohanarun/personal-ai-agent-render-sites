Support is a chain, not a vibe.

An agent can have a high-quality observation and still make a weak claim if it leaps too far. Tracing the chain makes the leap visible and gives the next action a defensible stopping point.

This is a compact teaching model. Production systems still need provenance, calibrated uncertainty, explicit permissions, and human review for consequential actions.
