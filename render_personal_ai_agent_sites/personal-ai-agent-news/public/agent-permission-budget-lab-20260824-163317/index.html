What the model shows

Least privilege is a rhythm, not a checkbox.

Run a scenario to see the pressure curve. An explicit review cadence keeps a long-running agent from turning yesterday's approval into today's blanket authorization.

  • Permission weight makes different tool calls visible as different kinds of risk.
  • Frequent review creates a stopping point where purpose and authorization can be checked again.
  • A pause is a control response when accumulated spend no longer matches the original task.
