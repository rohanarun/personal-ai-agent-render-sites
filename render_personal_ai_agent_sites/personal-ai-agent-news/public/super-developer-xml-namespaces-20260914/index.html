Same local name, different identity

The illustrative catalog has two item elements with different prefixes but the same namespace URI, urn:media. Another item inherits urn:studio as its default namespace. The last clears that default and has no namespace. A prefix-only comparison would miss these distinctions.

The native namespaceURI property reports an element's resolved namespace or null. A URI identifies the namespace; this desk does not fetch it or treat it as a required reachable website. Prefixes are aliases, not the namespace identity itself.

A bounded inspection, not a validator

The browser's XML parser produces a separate document. This desk lists element names in document order, including the root. Ordinals identify records within this inspection only; they are not XPath expressions or durable IDs.

It does not export text, attributes, comments or processing instructions. Attribute namespace rules are outside this view. The JSON report is an inspection artifact, not a lossless XML conversion. Filtering changes only the displayed and exported records, never the input.

Limits: 50,000 characters and 500 elements. Documents containing a DOCTYPE declaration are rejected, as are parser errors. The element name parsererror is reserved and rejected in any namespace. No parsed nodes are inserted into the visible page; record strings are displayed as text. This is not an XSD validator, an XML signature checker or a sanitizer for a later application.
