What changes at the boundary?
The accented-word example contains a two-byte sequence. Split between those bytes and the independent decoders see incomplete or invalid fragments. In default replacement mode, replacement characters appear.
A single decoder used with stream: true keeps the incomplete sequence between calls. A final decode() flush ends the stream. The example starts from valid text, so both chunks together always contain a complete encoding.
Three different units
A network chunk is a delivery unit. A Unicode character has an encoding in bytes. A model token belongs to its tokenizer. This lab only splits UTF-8 bytes; it does not tokenize text, parse server-sent events, measure latency or call a model.
Illustrative client pipeline: decode bytes incrementally, then parse the application's message framing, then handle the content. Proper decoding alone does not establish that a JSON object or an event is complete.
Scope of this experiment
Both approaches use native TextDecoder with its default replacement behavior. Fatal-mode errors, corrupted input, reconnection and protocol framing need separate tests. A clean rendering here is not proof of a production streaming implementation.
