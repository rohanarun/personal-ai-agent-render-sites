Use with a timestamp

The record is traceable enough for a bounded decision. Preserve its observation time and recheck before a high-impact action.

Lineage is part of the answer

A retrieved value without origin, observation time, and transformation history is not a complete fact. It is a claim with missing context.

Mutation changes policy

If a record can change under the agent's feet, the action needs a freshness check or a snapshot. Trust must match the data's stability.
