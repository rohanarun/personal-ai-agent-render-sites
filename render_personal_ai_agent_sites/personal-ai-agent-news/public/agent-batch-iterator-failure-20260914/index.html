Batch collection can fail

A task producer yields one pending promise, then throws. The aggregate rejects before that task finishes. This is a collection error, not a rejection from the task.

The iterator is part of the contract

This lab passes a real generator to native Promise.all. The generator yields task A, then either ends or throws Error("producer failed"). Collection happens while calling the combinator. In this ordinary native-Promise case, that abrupt iteration becomes a rejection of the returned aggregate promise, not an exception caught by the surrounding synchronous try/catch.

The trace logs the call returning before its rejection handler runs. A catch around only the call is therefore not enough here: handle the returned promise with a rejection handler or await it inside try/catch. This is a controlled example, not a claim that every misuse of a Promise method can never throw synchronously.

Collection failure is not task completion

Task A has already been created when the iterable is consumed. The lab keeps it pending behind a manual resolver. In the failure mode, finishing A later changes its own state but does not turn the rejected aggregate into a success. In normal mode, finishing A fulfills the aggregate with ["A done"].

For an agent task producer, separate errors while producing the batch from errors while executing a yielded task. Record which tasks were admitted before collection failed. Do not automatically submit the entire batch again: a previously admitted operation may still be running or may already have side effects.

The task here is only a local promise. There is no network request, worker, model or external mutation. A real executor needs explicit cancellation and acknowledgment semantics; the aggregate alone does not supply them. Reset abandons this page's prior observation and resolves its synthetic pending task without displaying stale callbacks.

Exact experiment shape

const taskA = new Promise(resolve => finish = resolve);
function* tasks() {
  yield taskA;
  if (fail) throw new Error("producer failed");
}
const aggregate = Promise.all(tasks());
aggregate.then(onSuccess, onFailure);
