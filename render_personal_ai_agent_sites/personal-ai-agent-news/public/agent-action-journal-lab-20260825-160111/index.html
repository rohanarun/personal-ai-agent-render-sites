A good journal is a decision’s smallest witness.

The point of an action journal is not to retain every token. It is to preserve the compact facts that let another person understand, verify, and recover the consequential step.

Intent before mechanics

Capture the goal, scope, and authorization basis before listing implementation detail.

Evidence beside claims

Attach the source or receipt that supports “allowed,” “changed,” and “completed,” rather than trusting a generated summary.

Outcome as state

Record what the system became, not only that a function returned. This is what makes recovery and review possible.
