Leases, made observable

Let work expire before stale ownership blocks the next useful action.

Set how old a work lease is and how long it may live. The simulator routes the claim toward active, renew, or release, making ownership a time-bounded coordination tool instead of an invisible lock.

Shape the lease

Lease age is elapsed time. Maximum duration is the point where the owner must renew or hand work back.

Active: the owner still has time to finish or report progress.

Read the ownership

A lease should protect active work without making a stalled worker permanent. Near expiry, renew explicitly; after expiry, release for recovery.
