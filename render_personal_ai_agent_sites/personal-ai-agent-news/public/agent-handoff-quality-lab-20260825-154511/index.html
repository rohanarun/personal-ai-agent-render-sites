A human handoff simulator

Good handoffs leave a person able to act.

When an agent cannot finish, its job is not to paste a transcript. Tune the context, uncertainty, and ownership it transfers, then see whether a human receives a decision-ready next step.

Transfer the decision, not the burden.

A useful handoff compresses the path to the next responsible action. It says what happened, what is known, what is not known, and who can change the state.

Facts before narrative

Lead with the state of the task, the attempted action, and the exact blocker. Search history belongs behind the decision.

Uncertainty is a field

Label unknowns explicitly so the next person does not mistake silence for a clean result.

Give ownership a verb

“Needs review” is not a plan. Name the owner, the next question, and the condition that lets the workflow resume.
