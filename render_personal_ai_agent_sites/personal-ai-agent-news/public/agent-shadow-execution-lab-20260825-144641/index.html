Rehearsal turns confidence into evidence.

A shadow run is useful because it separates “the tool can do this” from “the agent should do this now.” The system can inspect a consequence without silently creating it.

This teaching model is intentionally small. Production systems still need explicit permissions, isolation, audit logs, rollback paths, and domain-specific review for consequential actions.
