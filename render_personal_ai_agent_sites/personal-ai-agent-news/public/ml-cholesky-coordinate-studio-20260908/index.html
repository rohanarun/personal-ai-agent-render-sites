A root that preserves an order

A symmetric positive-definite matrix C has a unique lower triangular factor with positive diagonal entries such that C = L L^T. The triangular shape makes the construction sequential: the first output uses z1; the second combines z1 and z2. This is a factorization, not an element-by-element square root.

Here C has diagonal entries a squared and b squared, with off-diagonal entry r a b. The first pivot is a squared. After accounting for the shared part, the second pivot is b squared times (1 - r squared). A positive remainder gives two nonzero directions; at |r| = 1 the ellipse collapses to a line. Beyond that boundary the remainder is negative, so this matrix cannot be a covariance and no real factor L L^T can equal it.

Covariance is not a distribution

The 96 equally spaced input points form a ring of radius square root of 2. Their mean is zero and their population covariance is the identity. Multiplying each point by L therefore produces covariance L L^T. The ring coordinates are uncorrelated but not independent. This display is geometry, not a cloud of Gaussian draws.

For independent standard Gaussian inputs instead, the same linear map would produce a Gaussian with covariance C. A triangular root depends on coordinate order; a different order can change the factor while representing the corresponding reordered covariance. At the singular boundary a factor can still exist, but the positive-diagonal, invertible construction no longer applies. The numerical decomposition here is computed by ml-matrix; the displayed pivot formula explains its two-dimensional case.
