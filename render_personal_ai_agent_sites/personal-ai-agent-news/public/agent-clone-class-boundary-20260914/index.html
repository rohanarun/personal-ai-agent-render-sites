Data crosses. Methods do not.

A tool ticket is a class instance in one part of an agent system. What arrives after a structured clone?

class Ticket {
  constructor() { this.id = 'draft-17'; }
  describe() { return 'Ticket ' + this.id; }
}
const source = new Ticket();
// Optional: source.localAction = () => 'local only';
const copy = structuredClone(source);

    The instance is not reconstructed
    In this ordinary custom-class example, the clone contains the ticket's own data but not its class prototype. The clone is not a Ticket instance, and calling its missing describe() method throws a TypeError. The constructor counter stays at one: cloning did not call this constructor again.
    The optional own, enumerable localAction function changes the outcome. It is encountered as a value to clone and causes DataCloneError; no copy is returned. This differs from the prototype method, which is not copied in the first place. Built-in supported types have their own cloning rules; do not generalize this result to every object.
    Design the handoff as data
    For an illustrative agent worker, a ticket such as { id, operation, payload } can describe a requested action. The receiving component still needs to validate that request and choose an allowed implementation. A data record should not be mistaken for a live service client with methods, open connections, or execution authority.
    This experiment is not a security sandbox. Dropping a prototype is not an authorization check, and a receiver must not trust a command merely because it arrived through a clone. Keep transport validation and tool permissions explicit. Do not restore a prototype blindly just to make a missing-method error disappear.
    Every result above comes from a native local structuredClone call, Object.getPrototypeOf, instanceof, and a caught method invocation. No worker, model, network tool, or real action is invoked. Error wording can differ by browser. Toggling the option runs a fresh experiment; the exported JSON records observations rather than attempting to serialize a function.
