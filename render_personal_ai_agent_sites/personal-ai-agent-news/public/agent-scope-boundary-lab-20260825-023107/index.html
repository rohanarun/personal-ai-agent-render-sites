What the simulation teaches

Scope is a control surface. A good agent does not merely ask “can I call this tool?” It asks whether the next action is inside the user’s stated objective, reversible, and observable enough to approve.

A useful design move

Split the plan at the first consequential action. Let the agent prepare, show the proposed change, and wait for an explicit decision before it crosses the boundary.
