The API can stay familiar while the world changes.

Dependencies drift in quiet ways: a field becomes optional, a permission changes, a rate limit tightens, or an external system adds a new state. An agent that only remembers the happy path can turn a small contract mismatch into a broken workflow.

This lab makes the tradeoff visible. Contract coverage and fallback quality create room to act. Volatility and criticality consume it. The score is a teaching device, not a compatibility guarantee; use it to decide which assumption deserves a live check before the next tool call.
