The gap is a speed control

At each step, the numerical engine computes A u and divides by its Euclidean norm. Here the dominant eigenvalue is 1 when |q| < 1. The relative second component shrinks by |q| on every multiplication, provided the initial horizontal component is nonzero. Near |q| = 1, the separation is slow.

The Rayleigh quotient u transpose A u estimates an eigenvalue. The residual norm ||A u - rho u|| measures whether the current vector is close to satisfying an eigenpair equation. It does not prove that the eigenvalue is dominant: starting exactly on the vertical axis can give a zero residual for q.

Failure cases are information

At a 90-degree start, the horizontal component is exactly zero in this simulation. It stays absent. If q is also zero, multiplication annihilates the vector and normalization stops. With q = -1, generic vectors alternate without approaching the horizontal line. With q = 1, every vector is an eigenvector, so no unique dominant direction exists.

The horizontal direction error is |u_y| for a unit vector. It ignores vector sign, since an eigenvector and its negative span the same line. At tied magnitudes it remains a distance to the chosen horizontal reference, not an error against a unique solution. This two-dimensional diagonal model isolates convergence geometry; floating-point leakage can affect exact orthogonality in general matrices.
