A small range, not a full decomposition

A = diag(5, 2, 0.5), omega = (weight, 1, 0.5)
Q = orth(A omega)
Approximation = Q Q transpose A

Each refinement applies A transpose and then A, with QR normalization after each multiplication. In exact arithmetic, the final direction is proportional to (A A transpose)^q A omega. Larger singular modes gain relative weight.

Halko, Martinsson and Tropp describe range finding and power refinement as stages of randomized low-rank approximation. Here the probe is deliberately controlled, not random; no probabilistic guarantee is being demonstrated.

If its leading weight is exactly zero, multiplying this diagonal matrix cannot introduce that missing mode. The best rank-one approximation keeps singular value 5 and has Frobenius error sqrt(2 squared + 0.5 squared). A poor probe can remain far from that optimum.

The captured and residual matrices are orthogonal in Frobenius inner product, so their squared norms add to the original squared norm. Q's sign is irrelevant because Q Q transpose is unchanged. This three-dimensional example is not a speed benchmark or an oversampling study; export preserves the probe, projectors, approximations and all refinement levels.
