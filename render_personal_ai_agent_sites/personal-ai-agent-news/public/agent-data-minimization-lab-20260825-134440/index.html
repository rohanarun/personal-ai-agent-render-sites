A useful mental model

Less data is often more control.

Minimization is not a cosmetic redaction step. It limits the consequences of a wrong tool call, makes review faster, and gives an operator an inspectable account of what the agent actually needed.

Purpose first

Name the task before selecting fields. A vague purpose cannot justify a broad payload.

Reduce by default

Remove identifiers and free text unless they are necessary to complete the stated action.

Hold uncertainty

When the boundary is unclear, a review state protects both the user and the downstream tool. The agent should make the missing decision visible rather than silently expanding access.
