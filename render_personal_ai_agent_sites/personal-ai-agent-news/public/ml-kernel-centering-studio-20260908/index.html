Subtract two means, add one back

Let H = I − 11ᵀ/n. Then Kc = HKH = (HX)(HX)ᵀ. Entry by entry, subtract the row mean and column mean from K, then add the grand mean. The result is the Gram matrix of mean-centered features, without needing to reconstruct those features from K.

Because H1 = 0, a common translation X + 1tᵀ vanishes after centering. This demonstration uses the linear kernel; translating raw inputs to a nonlinear feature map need not have the same effect as translating the mapped features.

Negative entries, valid kernel

A negative entry means two centered vectors point in opposing directions. Positive semidefiniteness is a statement about quadratic forms: zᵀKc z = ‖XᵀHz‖² ≥ 0. It is not a requirement that every entry be positive. Also Kc1 = 0, so the all-ones vector is a null direction.

What changes and what stays

The five base points are (−2, 0), (−1, 2), (0, −1), (1, 1), (2, −2). Scaling changes their relative geometry and scales Kc by s²; translation does neither. At zero scale all observations coincide and Kc is zero. With only two features, both Gram matrices have rank at most two.

Centering is used in kernel PCA. It does not normalize feature variance or repair an arbitrary invalid kernel. This page computes matrix products and eigendecompositions with ml-matrix; tiny floating-point eigenvalues are displayed as zero below 10⁻⁹.
