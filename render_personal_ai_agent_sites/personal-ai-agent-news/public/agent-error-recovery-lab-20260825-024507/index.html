What the simulation teaches

An actionable error is part of the agent interface. It should preserve enough state to explain the failure, but not so much that the response becomes a new data-leak surface.

A useful design move

Return one precise cause, one safe correction, and one condition for retry. Recovery becomes a bounded decision instead of an invitation to repeat the same mistake.
