Reusing yesterday's values

Jacobi updates every coordinate from the previous iterate, not from partially updated values. Weighted Jacobi blends that update with the old vector. Because this matrix has unit diagonal, its update is x(next) = x + w(b - A x).

The error therefore evolves through B = I - w A. Its spectral radius is the largest absolute eigenvalue. A radius below one guarantees convergence from every starting vector. A radius above one means some error directions grow; a particular starting error can still miss them.

Positive definite is not enough

This matrix has eigenvalues 1 + 2c and 1 - c (twice), all positive over the slider range. Undamped Jacobi nevertheless has spectral radius 2c, so it is not convergent from every start when c is at least one half. Damping converges when 0 < w < 2 / (1 + 2c). Equality is a boundary, not a guarantee.

The right-hand side is constructed as b = A(1, -0.5, 0.75), and the reference solution is independently computed with QR. Relative residual means ||b - A x|| / ||b||. It measures equation mismatch, not directly the distance to the solution. Curves show forty updates without stopping early; numerical roundoff can leave small residuals.
