A good threshold is a policy, not a mood.

When intent is vague and the cost of error is high, clarification is an authorization boundary. When evidence can be cheaply gathered, inspection is a better move. When the step is reversible and low risk, an agent can act while preserving an easy path back.

This lab makes those tradeoffs visible. It is a simplified teaching model, not a production policy: real systems should add domain-specific controls, explicit permissions, logging, and human review where the stakes demand it.
