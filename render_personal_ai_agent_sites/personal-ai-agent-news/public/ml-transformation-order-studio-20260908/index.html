Commutator A B - B A

Read products from the right

With column vectors, A B x means apply B first, then A. Reversing the product gives B A x. The commutator A B - B A measures the difference for every possible input at once. A zero commutator means the maps commute; it is stronger evidence than agreement on one probe.

The plotted dot separation is ||(A B - B A) x|| for the chosen unit vector. The largest singular value of the commutator is the greatest possible dot separation over all unit vectors. The probe gap cannot exceed this value. A small gap for one direction alone does not establish that order is harmless.

Some transformations do commute

Uniform scaling commutes with every linear map, including rotation. In this example a zero-degree rotation is the identity and a 180-degree rotation is minus the identity, so both commute with every B shown here. Horizontal scaling commutes with every rotation when its strength is one, because B is then the identity. A zero shear is also the identity.

The commutator always has trace zero, but trace zero alone does not make it the zero matrix. Its Frobenius norm uses all four entries and therefore provides a separate numerical check.

This illustrates why reordering linear feature transforms can change a pipeline's output. It does not model nonlinear normalization, training, or learned accuracy. The fixed polygon is a geometric diagnostic; the probe always has length one. Products and singular values use ml-matrix, with a 10^-10 tolerance for numerical commutation.
