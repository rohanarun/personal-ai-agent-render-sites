For a real symmetric 3 by 3 matrix, order the eigenvalues as l1 <= l2 <= l3. Delete the same row and column to form a principal 2 by 2 submatrix with eigenvalues m1 <= m2. Cauchy interlacing guarantees l1 <= m1 <= l2 <= m2 <= l3. Equality is allowed.

The largest eigenvalue cannot increase and the smallest cannot decrease under this deletion. A positive-definite matrix therefore has positive-definite principal submatrices. The rule needs symmetry (or its complex analogue, Hermitian structure); arbitrary rectangular slicing is not the same operation.

What feature deletion means

If the full matrix is a covariance matrix, its principal submatrix is the covariance of the retained features. This is marginal feature selection, not conditioning on the deleted feature and not a Schur complement. The controls can also produce indefinite matrices, which still interlace but cannot represent covariance matrices.

The five controls define a symmetric chain: diagonal values A, B, C and couplings A-B, B-C; the A-C entry is zero. The numerical engine solves both eigenproblems directly. Values are sorted in ascending order, and checks allow a 10^-9 floating-point tolerance. This does not measure predictive usefulness or choose which feature to discard.
