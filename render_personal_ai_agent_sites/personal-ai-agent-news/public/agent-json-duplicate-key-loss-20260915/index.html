The audit starts too late
Parsing has already resolved the repetition
For repeated object member names, JavaScript's JSON.parse keeps the last value. The reviver operates on the resulting values, not every textual declaration. It also receives a final call for the root object. This experiment returns every value unchanged.
Reverse the members: the winning value changes even though the set of names and values has not. Make the names distinct and all three survive. Equal repeated values still erase declaration history.
Other consumers need not agree
RFC 8259 says object member names should be unique. Duplicate-name handling is not interoperable across implementations: some keep the last pair, some reject it, and others expose more than one pair. This page measures native JavaScript behavior only, not every JSON parser.
A reviver is not a duplicate-key detector
At a tool boundary, require unique member names before lossy object construction. Use a parser or validation layer that explicitly reports duplicates; don't assume a reviver or a schema applied only to the parsed object can recover discarded members.
The pre-parse decision shown here checks the three builder entries we already possess. It is not a general raw-JSON validator. A production implementation must handle nesting, escapes, and decoded member names correctly. Preserve raw evidence where appropriate to your data policy.
What this experiment does not cover
Names are literal strings of up to 30 characters, including empty names. Values are integers from 0 to 99. JSON string escaping is performed by the native serializer. The fixed builder avoids inventing a JSON parser. No payload is executed by an agent or sent to a service.
The root trace is identified by its object value, not an empty key, since an actual member may also have the empty name. Integer-like names may appear in JavaScript property enumeration order rather than source order.
Keep the evidence, not just the outcome
The export includes ordered members, raw JSON text, parsed output, and observed reviver calls. A re-serialized object alone cannot reconstruct the discarded values.
