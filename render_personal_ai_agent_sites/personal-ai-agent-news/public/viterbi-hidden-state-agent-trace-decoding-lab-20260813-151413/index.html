Decoding the hidden workflow.

One best story through noisy evidence.

A Hidden Markov Model separates hidden states from visible emissions. Viterbi decoding stores the best score reaching every state at every time, plus a backpointer to the winning predecessor. The final traceback returns the most likely complete path without enumerating every possible workflow.

Vₜ(s) = emission(actionₜ | s) · maxₛ′ [ transition(s | s′) · Vₜ₋₁(s′) ]

Score each observation

Search is likely during research; write is likely during execution. Noise spreads some probability across every action.

02

Respect workflow continuity

Transition probabilities reward plausible phase changes and penalize implausible jumps between distant plan states.

03

Trace back once

After the forward pass, backpointers recover the winning latent sequence from the final state to the first.
