Act inside the window.

An action is valid only while its preconditions remain true. The longer an agent waits after checking, the more it is relying on a world that may have moved.

A short action window can be safer than a clever plan with stale authorization.

Authorization, availability, and state all have a clock.

Check near the edge

Validate the condition as close as possible to the consequential action. Earlier checks lose authority as the world changes.

Keep windows explicit

Name how long a decision remains valid and what event closes the window early.

Fail closed

When the window expires, pause, refresh, or ask. Do not silently treat old authorization as current truth.
