    Equality is part of the policy

    includes() uses SameValueZero: NaN matches NaN. indexOf() uses strict equality and therefore cannot locate NaN, even when it is present. Neither coerces the string "NaN" into the numeric value.

    if (!includesQueue.includes(value)) {
  includesQueue.push(value);
}
if (indexQueue.indexOf(value) === -1) {
  indexQueue.push(value);
}

    Every admission here executes those native operations. Repeated numeric NaN entries accumulate only in the indexOf queue. Ordinary zero and the string "NaN" are deduplicated in both queues.

    Do not turn a missing score into an identity

    An agent pipeline might accidentally use a parsed score as its duplicate key. A failed numeric calculation can yield NaN. Fixing the membership method does not fix that data model: unrelated failures would then collapse into one value.

    Validate scores separately and choose an explicit task identity with defined equality semantics. This lesson isolates primitive membership; it does not implement reliable distributed deduplication, retries, or durable exactly-once execution.
