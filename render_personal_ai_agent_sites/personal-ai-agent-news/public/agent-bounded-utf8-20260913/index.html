Bounded UTF-8

A small buffer can stop an agent's text pipeline even when unused space remains. Follow one string through real browser encoding calls.

Local experiment; no model or network request. Text edits restart the trace. Buffer size changes apply to the next call.

Illustrative input includes ASCII, accented text, a CJK character and a supplementary-plane musical symbol.

Two counters, two units
read counts consumed UTF-16 code units; written counts destination bytes. Continue with source.slice(totalRead), not with the byte count. A supplementary code point consumes two source units but four UTF-8 bytes.
A partial buffer is not a partial character
The encoder stops before a code point whose complete byte sequence will not fit. If nothing fits, both counters are zero. Increase capacity before retrying unchanged input; otherwise a loop can make no progress. Only the written prefix belongs to the output.
This preserves code-point encoding boundaries, not grapheme clusters or LLM token boundaries. Unpaired UTF-16 surrogates are converted to replacement characters. This workbench models a complete input string, not arbitrary incoming network fragments.
Primary source: WHATWG Encoding Standard
