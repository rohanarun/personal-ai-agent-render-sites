The last step is where certainty gets expensive.

Suppose an agent reads one report, connects it to a second fact, and uses that connection to change a user’s data. Each fragment may be accurate while the final action remains unjustified. The chain needs more than a plausible story; it needs enough independent support for its distance and consequence.

This lab turns that intuition into four visible signals. Reliable sources and corroboration create support. Deeper chains consume it. Time pressure can make action feel attractive, but it should never manufacture confidence. The score is a teaching device, not a probability estimate.
