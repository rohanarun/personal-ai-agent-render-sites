State is a promise about the next step.

An agent should not jump from a vague plan to a consequential action. Adjust state clarity, goal stability, environment change, and interruption safety to see whether the next transition should proceed, wait, or escalate.

Advance with a checkpoint

advance = min(clarity, goal, world, interrupt)

Why the minimum?

A clear state is not enough if the world changed underneath the plan. Taking the minimum keeps transitions sensitive to one broken assumption and makes waiting a deliberate control action rather than an idle failure.
