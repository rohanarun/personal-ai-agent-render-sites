Design the pause

Human oversight is an interaction contract. The agent should explain what is waiting, how long the decision remains useful, and what safe fallback happens after the deadline.

  • Show the action and its consequence before asking for approval.
  • Set an explicit expiry instead of leaving work in limbo.
  • Prefer reversible defaults when waiting is unavoidable.

Try the trap

Increase the approval delay while keeping consequence high. The interface still says “human approved,” but the timing can turn the approval into documentation after the fact.
