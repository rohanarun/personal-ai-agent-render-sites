What to notice

Intent is not scope.
“Help with this” may reveal a goal while leaving the actual action and boundary undefined.
Precision prevents invention.
Explicit owners, limits, and outputs keep an agent from filling gaps with guesses.
Confirmation is a boundary.
When ambiguity changes the side effect, asking is safer than silently choosing.
