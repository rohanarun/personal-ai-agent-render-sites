Averages and differences

Haar analysis transforms neighboring samples into an average-like coefficient, (a+b)/sqrt(2), and a detail coefficient, (a-b)/sqrt(2). Repeating the operation on the averages separates changes at several scales. Here eight samples produce one coarse coefficient A3, one D3, two D2, and four D1 coefficients. D1 describes adjacent pairs; D3 compares the two halves.

The square-root normalization makes this transform orthonormal. With all coefficients present, reconstruction recovers the input up to floating-point precision. Signal energy, the sum of squared samples, equals the sum of squared coefficients.

Thresholding trades detail for simplicity

This experiment applies hard thresholding only to details. A retained coefficient is unchanged, while a discarded one becomes zero. The retained coarse coefficient preserves the mean. In this orthonormal example, squared reconstruction error equals the energy of the coefficients removed. The count of nonzero coefficients is a sparsity measure, not a compressed file size.

Representation is not validation

Wavelet features separate localized changes by scale and can be inputs to learning systems. Thresholding is a preprocessing choice, not learned evidence that a feature is irrelevant. An isolated event may be the target of interest. Haar reconstructions can have staircase artifacts, and moving an event by one sample can substantially change its decimated coefficients.

This studio fixes the Haar basis, three decomposition levels, and eight samples. The library uses symmetric extension; even lengths at every level avoid extra boundary coefficients here. No ground-truth clean signal is supplied, so the error is measured against the input, not against an unknown noise-free target.
