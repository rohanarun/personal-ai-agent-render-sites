Minimize with purpose

Less data is useful only when the agent can still explain why every remaining field matters.

Name the required fields

Define the smallest input shape that lets the tool perform its task instead of forwarding the whole conversation.

Separate need from convenience

A field that makes a prompt easier to write is not automatically a field the tool needs to receive.

Keep sensitive defaults out

Do not include private context “just in case.” Retrieve it only when the task and authority require it.

This simulation is a teaching model, not a production privacy policy. It demonstrates a contract-first pattern: define the minimum useful input and gate extra context by necessity and impact.
