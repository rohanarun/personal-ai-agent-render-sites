Try the boundary cases
With a seed, the callback begins at index zero. Without one, the first array element becomes the accumulator and the callback begins at the next element. For a single chunk without a seed, no callback runs.
Replace the input with []. With an explicit seed, the result is that seed. Without an initial value, reduce throws a TypeError. An empty seed string is still an explicitly supplied initial value.
The callback here appends a visible separator: accumulator + " | " + chunk. That makes the initial value observable rather than hiding it in an identity operation.
Implications for agent assembly
If your callback also validates or records each chunk, an unseeded reduction will skip that work for the first chunk. Decide whether validation belongs in a separate pass, and define what an empty batch means before assembling results.
This example accepts only dense JSON arrays of strings. It does not cover sparse arrays, async reducers, or concurrent tasks. Exported traces describe browser execution on your supplied sample, not the success of an agent workflow.
