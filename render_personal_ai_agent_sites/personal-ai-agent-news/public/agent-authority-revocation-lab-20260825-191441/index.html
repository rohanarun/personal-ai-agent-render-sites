Make revocation real

Revocation is a control, not a footnote. The agent should check whether the user, task, data, or environment changed before reusing an old permission.

  • Give permissions a bounded lifetime.
  • Recheck before high-consequence actions.
  • Make withdrawal propagate through delegated work.

Try the trap

Raise consequence while leaving the revocation signal low. The permission still looks convenient, but its continued use is not well justified.
