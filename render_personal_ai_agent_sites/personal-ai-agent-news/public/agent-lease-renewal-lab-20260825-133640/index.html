The lease gate

Separate “still alive” from “still safe to own.”

A heartbeat can show that a process is responsive. It cannot, by itself, prove that the worker is making progress or that another claimant should keep waiting.

A useful mental model

Handoff is a protocol, not a timeout setting.

When ownership changes, the system should preserve the old lease evidence, record why it expired, and make the next claim conditional on that boundary. This is how an agent avoids both double work and silent stalls.

Heartbeat

Shows liveness at a point in time. It is necessary, but weak evidence of forward motion.

Progress

Shows that the worker is advancing the task, not merely keeping a socket or process awake.

Bounded recovery

A probe can resolve uncertainty once. If it cannot, a documented handoff is safer than indefinite ownership. Every transition should leave an audit trail another agent can understand.
