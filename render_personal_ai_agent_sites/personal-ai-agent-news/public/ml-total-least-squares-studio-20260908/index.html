Which distance is the error?

Ordinary least squares (OLS) fits y = ax + b by minimizing squared vertical residuals. It treats x as fixed. Total least squares (TLS), in this unweighted line-fitting setting, minimizes squared perpendicular distances and allows corrections in both coordinates. Different objectives are not interchangeable measures of quality.

Both fitted lines pass through the sample mean. TLS takes the leading right singular vector of the centered point matrix as its direction. The squared smaller singular value is its orthogonal residual sum of squares. OLS is solved with a QR decomposition when x has nonzero spread.

Units are part of the model

This TLS geometry assumes comparable Euclidean units and isotropic coordinate errors. Rescaling one axis changes the question and generally the answer. Weighted orthogonal distance regression can express different measurement uncertainties; this studio does not estimate those uncertainties or select a statistically correct model for you.

A vertical TLS line is valid even though y = ax + b cannot represent it. Equal singular values give no unique TLS direction; identical x values give no unique OLS slope. Those cases are reported rather than hidden.
