The regex remembers

Reuse a regular expression while parsing an agent's text and its cursor may carry state into the next call. Step through native exec(), one call at a time.

Execution trace
Changing text or mode resets the experiment. The fixed pattern matches literal lowercase tool. No custom regex, model, or network execution.
Three modes, three paths
With global mode, repeated calls find the two matches, then fail and reset lastIndex to zero. Sticky mode requires a match exactly at its cursor: the space after the first tool makes the next call fail. Without either flag, each call searches from the start and finds the first occurrence.
Why an agent developer cares
Illustrative parser: a shared global regex checks several independent response strings. A cursor left by one check can influence the next. If you intend independent checks, choose a stateless pattern or explicitly define when to reset. If you intend a scan, preserve the cursor deliberately.
A failed match is not evidence of a model failure. Inspect the input, flags and cursor together before blaming the response. This lab's literal pattern is not a parser for tool calls or a validator for structured agent output.
Scope of the trace
Indices use JavaScript string positions, not model tokens. There are no zero-length matches in this pattern. Other patterns, Unicode modes and string methods introduce additional rules; these observations apply to the shown exec() experiment.
