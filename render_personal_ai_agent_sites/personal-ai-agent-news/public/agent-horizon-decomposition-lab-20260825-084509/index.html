Shorten the horizon.

A long plan compounds uncertainty. A checkpoint turns uncertainty into a question the agent can answer before it commits to the next leg.

Planning is not a promise about the whole route. It is a sequence of testable commitments.

Commit locally

Make the next action precise and keep later actions conditional on what the environment returns.

Expose drift

At each checkpoint, compare the intended state with the observed state. Drift should trigger replanning, not silent improvisation.

Recover deliberately

A checkpoint is useful when it names the fallback: retry, ask, undo, or stop before damage compounds.
