The source graph

const shared = { status: 'pending' };
const source = { left: shared, right: shared };

// The experiment then changes:
copy.left.status = 'reviewed';

Left and right are references, not separate copies of the status. The diagram groups fields by actual JavaScript object identity. Its labels describe the currently observed values, not simulated predictions.

What each strategy preserves

Structured clone: for this supported plain-object graph, the new nested object is independent of the source, but copy.left and copy.right still share it. Changing the copied left status also changes the copied right status.

Shallow spread: only the outer container is new. Its left and right references still point to the original nested object, so the mutation reaches the source too.

JSON round trip: this acyclic example becomes a JSON tree. The repeated object appears twice and is parsed into separate objects. Changing copy.left does not change copy.right. JSON is not a general-purpose replacement for structured cloning.

Why an agent-state handoff cares

Suppose two steps intentionally share one progress record. A deep copy can preserve that relationship within the new state; two independent deserializations need not. Decide whether the consumer needs a shared record, isolated records, or access to the original before choosing serialization.

This lesson does not test custom classes, functions, cycles, transfer lists, shared memory, or network transport. Structured cloning supports some types JSON cannot represent and rejects unsupported inputs; inspect the specific data contract instead of treating either operation as universal.
