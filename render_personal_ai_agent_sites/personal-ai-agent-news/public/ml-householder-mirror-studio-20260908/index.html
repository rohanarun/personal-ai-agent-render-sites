Flip the normal component, keep the rest

For a unit normal n, H = I - 2nn transpose reflects across the line perpendicular to n. The parallel-to-n part reverses; the perpendicular part stays fixed. H is symmetric and orthogonal, so lengths and pairwise distances are preserved. Its determinant is -1: orientation reverses.

H squared equals I. Two applications restore every point, not just the selected vector. The second view makes that identity visible without changing the mirror.

A geometric route to a triangular matrix

To send x to an equal-length target y, a reflector normal can be chosen along x - y. Automatic mode picks y = [-sign(x first) times norm(x), 0], treating a zero first coordinate as positive. This avoids subtracting nearly equal first coordinates when constructing the normal.

Applied to all columns of A, the same H zeros the selected first-column entry. Larger QR algorithms repeat such orthogonal transformations on remaining submatrices. A reflection is not a projection: it is reversible and does not discard a dimension.

The vector is always nonzero in this experiment. Trigonometric values and matrix products use floating-point arithmetic, so displayed zeros can have tiny residuals. The reference triangle is synthetic geometry, not a dataset or a learned model. Matrix products use ml-matrix; the unit-normal construction is explicit.
