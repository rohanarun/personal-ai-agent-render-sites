Good reasoning knows when to refinance.

Inference is not the enemy. Hidden inference is. When the evidence gap and action stakes rise together, the agent should spend verification budget, narrow the action, or ask for help before its assumptions become facts by repetition.

This is a compact teaching model. Production systems still need provenance, explicit permissions, calibrated uncertainty, and human review for consequential work.
