A tiny draw preserves fairness.

After t events, each one has exactly k/t probability of occupying the reservoir. The proof is inductive; the implementation needs only one pass and k storage slots.

Fill the first k slots

The initial reservoir receives the first k events directly. No final stream length is needed.

R[i] ← stream[i], i ≤ k

Draw an index

For event t, draw j uniformly from 1…t.

j ∼ Uniform{1,…,t}

Replace only if j ≤ k

The event enters with probability k/t and replaces slot j. Otherwise it leaves no stored state.

P(enter at t) = k/t

Agent-memory cautions

  • Uniform sampling does not prioritize importance or recency.
  • Stratify deliberately when rare event coverage is required.
  • Keep provenance so retained traces remain interpretable.
  • Use weighted reservoirs only with the correct inclusion math.
