Reliability is what the history says together.

One success proves one call. It does not prove a stable tool. An agent should read recent outcomes, volatility, and failure cost together before turning a retry into a habit.

This is a compact teaching model. Production systems still need explicit timeouts, idempotency, circuit breaking, provenance, and human review for consequential work.
