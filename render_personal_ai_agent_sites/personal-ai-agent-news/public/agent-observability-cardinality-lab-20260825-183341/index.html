The design move

Put stable, decision-relevant dimensions in metric labels. Keep request IDs, raw prompts, and unbounded user text in traces or logs with access controls.

  • Metrics answer “is this class of work healthy?”
  • Traces answer “what happened in this one run?”
  • Logs preserve details that should not multiply every metric.
