Add the derivatives too
For a residual map y = x + alpha f(x), the local Jacobian is J = I + alpha Df(x). The identity term provides a direct route, but it is added to another matrix, not protected from it. In this experiment f(x) = A x is linear, so the displayed map is exact everywhere, not merely a local approximation.
A = [ -1   k   0 ]
    [  0  0.5  0 ]
    [  0   0   1 ]

J = I + alpha A
  = [ 1-alpha   alpha*k       0     ]
    [    0     1+alpha/2      0     ]
    [    0         0       1+alpha ]
The original residual-network paper introduced learning residual functions relative to inputs and reported optimization benefits. The later identity-mapping analysis studied direct signal paths. Our constructed example is not a contradiction of those empirical findings; it distinguishes a useful architecture from a universal conditioning guarantee.


Follow one direction to zero
Choose "Collapse a direction." Alpha becomes one. For e1 = (1, 0, 0), A e1 = -e1, so J e1 = e1 - e1 = 0. Every pair of inputs differing only along that direction now has the same output. The sphere's image becomes a filled elliptical disk represented here by wire curves. Orbit to see its zero thickness.
At alpha zero, J is the identity and the output overlaps the unit sphere. With k zero, its three principal stretch factors are |1-alpha|, |1+alpha/2| and |1+alpha|. At alpha two, the first coordinate flips sign rather than disappearing. The surface alone cannot distinguish that reflection from a positive stretch, so the signed matrix remains visible above the singular values.


Shear is why eigenvalues are not enough
Increase k while holding alpha at 0.5. The diagonal entries, and therefore the eigenvalues of this triangular matrix, stay unchanged. Yet its singular values change: combinations of input directions can stretch differently when the axes are sheared.
The singular values are the minimum-to-maximum directional length gains. The displayed condition number is the largest divided by the smallest; at exact collapse it is infinite. This experiment calculates the decomposition using ml-matrix, not an eigenvalue shortcut.


What a small branch can guarantee
Our direct triangle-inequality argument gives a useful sufficient condition. If the operator norm ||alpha A|| is below one, then every unit vector v satisfies ||(I + alpha A)v|| at least 1 - ||alpha A||, which is positive. This rules out a collapsed direction in that case. It is sufficient, not necessary: a larger branch does not automatically imply collapse.
Across many blocks, Jacobians multiply. One block's attractive spectrum alone does not establish a well-conditioned whole network. Nonlinearities, normalization, data and learned weights all matter. Backpropagation uses transposed Jacobians; the same singular values govern their possible amplification, but this page does not measure a training run, gradient trajectory or model accuracy.


Scope and reproduction
Three features, one linear residual block, no activation after addition, no normalization and no learned parameters. The wire surface samples the unit sphere; it is not a training dataset. Numerical decomposition uses ml-matrix 6.12.1; rendering uses Three.js 0.180.0. Export includes the actual matrix and computed singular values. The numerical controls remain available without WebGL.
