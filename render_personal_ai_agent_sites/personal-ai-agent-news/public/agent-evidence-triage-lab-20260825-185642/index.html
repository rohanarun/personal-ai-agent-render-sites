Make triage legible

Evidence triage is not an excuse to ignore inconvenient facts. It is a way to spend verification effort where an error would change the action.

  • Keep the claim, source, and consequence together.
  • Separate “not checked” from “checked and false.”
  • Re-rank when new evidence changes the decision.

Try the trap

Set consequence low and verification cost high. The claim may be inconvenient to check, but that is not evidence that it matters less.

Cost is not importanceA difficult claim can still deserve priority when the decision depends on it.
