Two constraints, not one

The clean signal is yt = 0.6at + 0.4bt. The Hankel matrix has Hij = yi+j, so each anti-diagonal repeats one sample. It is a sum of two rank-one outer products; equal modes reduce its rank to one.

Ordinary SVD truncation keeps two singular components and minimizes unweighted matrix Frobenius error among rank-at-most-two matrices. It does not enforce constant anti-diagonals. Averaging those diagonals restores Hankel structure, but can raise rank again.

The structure error is the Frobenius distance to the anti-diagonal average. Numerical rank counts singular values above 10-8 times the largest; it is a display convention, not a noise-model selection rule.

Noise is one fixed uniform draw scaled by the amplitude control. A new draw changes the realization. This single truncation-and-average pass uses ml-matrix SVD; it does not claim optimal structured denoising or better forecasts.
