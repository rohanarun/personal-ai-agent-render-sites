What the model shows

Renewal is a conversation, not a timeout.

Run a scenario to see how a task can outgrow its original consent. A renewal should make the next action explicit, not silently extend an old instruction.

  • Specificity is a resource: vague approvals leave more room for interpretation.
  • Task changes create new consent questions even when the original goal sounds similar.
  • When ambiguity is high, asking again is the reliable action, not a failure of autonomy.
