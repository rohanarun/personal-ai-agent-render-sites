Undoing an action can be another action.

Recovery deserves the same authority as the original action.

“Undo” is not a magic word. A rollback can affect people who already reacted, destroy useful evidence, or create a second inconsistent state.

Name the inverse

Define exactly what state the rollback targets. “Put it back” is not precise enough when the source state is uncertain.

Trace propagation

Before reversing, identify downstream notifications, permissions, exports, or workflows that may already depend on the change.

Prefer compensation when needed

If a clean inverse is impossible, preserve the record and create a new, reviewable compensating action instead of rewriting history.
