What to notice

Retry value is contextual.
A second attempt is useful when it can change the outcome, not simply repeat the same failure.
Latency is a user cost.
Time spent recovering can be worse than a clear partial answer for an urgent task.
Harm raises the bar.
High-consequence actions deserve more evidence before the system spends another attempt.
Try the failure case.
