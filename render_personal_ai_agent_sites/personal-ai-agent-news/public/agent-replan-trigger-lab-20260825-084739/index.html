Know when to replan.

A capable agent does not treat every surprise as a crisis. It watches for the observations that break a precondition, change the risk, or make the next action impossible.

Replanning is a control decision: react to meaningful state change, not to noise.

Replanning should change the next action, not merely rewrite the explanation.

Watch preconditions

Record the facts that made an action valid. A changed precondition is a strong trigger; a changed decoration is not.

Bound the reaction

Use a focused check before throwing away a useful plan. The smallest sufficient replan protects time and tool budget.

Leave a trace

When the plan changes, preserve the trigger and the new postcondition so evaluation can tell recovery from improvisation.
