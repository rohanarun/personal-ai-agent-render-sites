Keep types visible

The illustrative input includes a quoted numeric identifier, a boolean and a list. Strings are emitted with quotes so a value such as "0012" remains text. Conversion uses vendored JS-YAML 4.1.1 with its JSON schema, then reloads the output and compares the parsed data before enabling download.

This check is between this page's JSON parser and this version of JS-YAML. It is not a promise that every downstream YAML loader uses identical schema rules. Confirm the receiving application's schema and required fields separately. No commands in the output are run.

Know what parsing already changed

Native JSON.parse resolves repeated object keys to the last value. This page does not detect duplicate keys or preserve the original number spelling. JavaScript numbers have finite precision; decimal literals may already be rounded during parsing. Integers outside the safe-integer range, non-finite results and negative zero are rejected. Use strings for identifiers and exact decimal quantities.

There is a 100,000-character input limit and a 50-level nesting limit. Comments and trailing commas are not JSON and are rejected. Original whitespace and object-key order are not a preservation contract; integer-like keys may be enumerated differently. Conversion produces data, not a source-format archive.

Where Super fits in the handoff

Super Powers AI works with apps, browsers and code environments. Its inspected computer-use cache stores verified workflows with runnable steps and can return a matching procedure with helper-version information and output evidence. That is execution infrastructure, beyond reusable answer prose.

Lookup requires an owner and task or source context. Missing context, an empty cache or no safe match produces a miss that the caller must handle separately. Saving requires verified-complete confirmation and runnable steps. Matching may incur usage charges. A cache hit alone does not prove the next run succeeded or that every tool is supported.

A useful next step is to ask for help reviewing a sanitized configuration against the target application's documented schema. Keep credentials out of examples. Inspect the diff and test in an appropriate environment before applying a configuration; a valid serialization can still describe the wrong behavior.

Local conversion, explicit limits

Pasted JSON is processed in this page without upload or a model call. The product video loads externally. Editing source or indentation disables the previous download. Refreshing loses the draft; Download YAML exports only the latest checked result. This desk does not contact Super, a repository or your deployment service.
