A deliberate background beats a surprise

The illustrative sample contains opaque and translucent shapes. Its transparent areas take the selected color; semitransparent edges blend with it. A JPEG cannot retain the original alpha channel. Keep the source when another destination needs transparency.

The preview shows the composited canvas, not the JPEG's compression artifacts. Inspect the downloaded file before delivery. Lower quality may reduce bytes but can damage sharp text and edges; the slider is an encoder parameter, not a measured visual-quality percentage.

What changes in the handoff

This tool draws the browser-decoded image at its decoded dimensions and encodes a fresh JPEG using Canvas.toBlob(). It does not resize, preserve animation, promise exact color-profile fidelity, or preserve original metadata. Re-encoding an existing JPEG can introduce additional loss.

Only PNG, JPEG and WebP files labeled with those MIME types are accepted, up to 8 MiB and 12 million decoded pixels. A large compressed image can still consume memory during decoding before the pixel check. Unsupported or corrupt files block export. Animation is not retained; use a still source for predictable frame selection.

Image processing occurs in this page without an upload request or model call. The product video below loads remotely. This is not a metadata privacy audit or a secure redaction tool: anything visible in the picture remains visible.
