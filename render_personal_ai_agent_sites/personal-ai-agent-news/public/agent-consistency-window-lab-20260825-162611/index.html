A plan coherence simulator

A multi-step plan can outlive the facts it started from.

An agent may read a record, make a choice, and act later after another update changes the world. Tune the snapshot age, intervening mutation, and restart cost to see whether the plan can continue coherently.

Consistency is a property of the whole plan.

Each step inherits assumptions from the previous read. When the world can change between steps, the agent needs a version, a conditional write, or a deliberate restart boundary.

Carry the version

Keep the record version or observation time attached to the plan so later actions can test whether it is still current.

Detect intervening change

A new mutation matters when it changes the object, permission, quantity, or recipient that the plan relies on.

Restart narrowly

When coherence breaks, re-read the smallest dependency that invalidated the plan instead of blindly replaying every step.
