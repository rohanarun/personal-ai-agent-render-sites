    Why the bridge matters

    Single linkage uses the smallest cross-cluster pair distance; complete uses the largest. Average uses the mean over every cross-cluster pair, weighted by the number of pairs. Each step merges the closest two clusters. The dendrogram records these merge distances, not a model's confidence.

    In the Bridge dataset at height 25, single linkage connects all eight points through short links. Complete linkage does not: a short path is not the same as a small maximum pair distance.

    Reading the cut

    A merge at or below the cut is included. A cut of zero leaves distinct points separate; identical points can merge at zero. Branch order has no statistical meaning, and tied distances can produce different valid merge orders. The group numbers identify only the current partition.

    Assumptions and limits

    Both features use the same 0-100 scale. Changing feature units changes Euclidean distances and may change the hierarchy. These unlabeled clusters are not discovered ground truth and do not establish predictive performance.
