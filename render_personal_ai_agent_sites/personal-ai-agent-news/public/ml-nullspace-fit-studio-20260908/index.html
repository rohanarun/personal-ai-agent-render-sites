The data do not choose a unique weight vector

For this two-by-three matrix, the null space is one-dimensional. The vector [-c, -c, 1] maps to zero. Normalize it to unit length and call it n. Adding t n to any exact solution therefore leaves A x unchanged.

The pseudoinverse gives xstar = A+ b, the minimum Euclidean-norm least-squares solution. Here every target can be fitted exactly, so xstar is the smallest-norm exact fit. It is orthogonal to the null space. Consequently ||xstar + t n|| squared equals ||xstar|| squared + t squared.

A fit criterion and a preference are different things

Every displayed weight vector fits these two observations equally well. Minimum norm selects one representative using an additional geometric preference; it is not evidence that this choice will predict unseen data better. Changing the feature scale can change what a small weight norm means.

The pseudoinverse is uniquely defined by the four Moore-Penrose conditions: A A+ A = A, A+ A A+ = A+, and symmetry of A A+ and A+ A. The maximum residual shown below is a numerical check of all four conditions. It is not a model-performance score.

The controls define the entire synthetic problem. No optimization training loop or hidden observations are involved. The pseudoinverse is computed by ml-matrix SVD, while the null direction is the explicit vector for this matrix family. The chart uses fixed weight-axis limits and a norm-curve scale that adjusts to the current minimum norm.
