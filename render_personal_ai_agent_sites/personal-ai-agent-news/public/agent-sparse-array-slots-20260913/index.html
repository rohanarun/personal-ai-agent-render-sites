Length is not a completion count
In this example, the array length remains three even when an indexed property is absent. A missing slot is not a stored value. An explicit undefined is a present property whose value is undefined.
The trace records which indices the native map callback visits. Spread uses the array iterator and produces a dense copy here. JSON serialization loses the distinction between these missing and undefined entries, showing null in both cases.
For agent pipelines
Illustrative scenario: reserving three positions with new Array(3) does not establish that three tools completed. Track completion explicitly, for example with records containing a task ID and a pending, fulfilled, or rejected state. Do not infer success from length or from JSON nulls.
This page uses fresh ordinary arrays with an unchanged prototype. Inherited indexed properties can affect map because its specification checks property presence, not just own properties. The own-slot display is intentionally a separate measurement. No tools, models, or external jobs run here.
