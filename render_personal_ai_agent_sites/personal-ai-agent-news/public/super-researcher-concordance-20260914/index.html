A match is not an interpretation

Search is literal and case-sensitive. It does not infer synonyms, normalize Unicode, identify whole words or judge the evidence. Each match includes up to 60 UTF-16 code units on either side, with boundaries expanded if needed to avoid splitting a surrogate pair. Context may cross a line or sentence boundary.

Offsets are zero-based UTF-16 positions in the text as held by the editor; the end offset is exclusive. Pasting can normalize line endings, so these are not byte offsets into an original file. The export includes the edited source to preserve the reference. Review permissions before sharing excerpts.

At most 200 matches are shown and exported. A truncation flag identifies an incomplete result set. Edits invalidate old results. This page processes text locally, does not upload it, and loses it on reload; the product video and external links use the network.

From passages to a verified workflow

Illustrative research task: collect repeated wording from approved notes, review its context, then transfer selected passages into a report with attribution. This tool finds text only; it does not validate sources or write conclusions.

Super Powers AI's inspected computer-use cache stores eligible verified procedures with runnable Python steps and output evidence. Storage requires an owner, task or source context and verified completion; a portability check may decline storage. Lookup returns a matched workflow, or a miss when context is absent or no safe match exists. The caller handles that miss.

This is reuse of executable steps rather than just a saved answer. It can avoid reconstructing an eligible procedure, but the September 14, 2026 source inspection is not a speed benchmark or proof of live availability for every account. This concordance does not call the cache.
