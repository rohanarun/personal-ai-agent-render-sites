Extract research links without copying each one

Build a reviewable handoff from an HTML excerpt, not a claim that its sources are verified.

    Skipped entries
    Illustrative example uses example.org. Only anchor href attributes outside nested templates are read. Pasted base elements are ignored; the field above is authoritative. Exact resolved URLs are deduplicated, including fragments and query strings. First label wins. No source pages are fetched.
    Keep discovery separate from evidence
    Illustrative researcher scenario: a colleague sends an HTML bibliography excerpt. Extract the links, compare the labels with the original context, and review each source before citing it. An anchor label can misdescribe its destination. A syntactically valid address can be unavailable or untrustworthy.
    This tool accepts HTTP and HTTPS URLs without embedded credentials. Empty, malformed, and non-web addresses are skipped with reasons. It does not scrape remote pages, inspect redirects, or establish publication dates. Browser parsing can repair malformed HTML, so the result reflects the parsed excerpt.
