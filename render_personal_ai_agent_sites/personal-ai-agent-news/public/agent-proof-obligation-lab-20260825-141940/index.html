A useful mental model

Proof is proportional to consequence.

A low-impact reversible action can move with modest evidence. A consequential action needs a stronger argument, a clearer boundary, and a credible way back.

State the action

Name what will change before asking whether the evidence is enough.

Find the gap

Turn uncertainty into a concrete verification step instead of a vague confidence score.

Stop when recovery fails

If the action is consequential and the recovery path is weak, stopping is the evidence-aware result. The agent can return the proof gap instead of manufacturing certainty.
