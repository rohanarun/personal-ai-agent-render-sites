Risk is shaped by the action, not only the answer.

A low-confidence draft can be safely inspected. The same draft should not silently become an external commitment. An agent needs a visible boundary between exploring, preparing, and sending.

A working rule
Raise the proof bar as the undo path disappears.

Reversibility is a design variable. Keep uncertain work local, ask for confirmation at the boundary, and record the evidence used.
