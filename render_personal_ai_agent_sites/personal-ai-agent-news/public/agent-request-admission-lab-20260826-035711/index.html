Graceful degradation is a promise.

Load shedding is not simply refusing work. It is deciding which requests can complete safely, which can take a reduced path, and which must wait for capacity.

Make the policy visible before overload arrives. A bounded fallback gives operators and users a clearer outcome than a queue that grows until every path becomes slow and opaque.
