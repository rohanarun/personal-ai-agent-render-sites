Diagnosis improves when an agent records whether failure repeats, changes with context, and carries a meaningful side-effect cost. The fingerprint makes “try again” a testable hypothesis instead of a reflex.

This is a compact teaching model. Production systems still need provenance, bounded retries, isolation, idempotency, circuit breakers, and human review for consequential work.
