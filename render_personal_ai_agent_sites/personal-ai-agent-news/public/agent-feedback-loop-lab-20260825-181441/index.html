A feedback loop needs a brake.

A learning agent should use feedback to correct its next step, not to accelerate blindly. Adjust signal quality, response speed, correction authority, and loop visibility to see whether feedback supports action or needs containment.

Correct with a visible checkpoint

loop quality = min(signal, speed, correction, visible)

Why the minimum?

Fast response is not useful when the signal is noisy. Strong correction authority is not safe when the loop is invisible. The minimum keeps a feedback loop accountable at its weakest point.
