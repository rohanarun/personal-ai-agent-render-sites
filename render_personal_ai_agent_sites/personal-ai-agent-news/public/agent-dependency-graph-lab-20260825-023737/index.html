What the simulation teaches

A dependency graph makes waiting visible. It shows which work is truly blocked, which work can proceed, and where a shared resource creates a hidden single point of failure.

A useful design move

Give the agent a graph of prerequisites and explicit readiness states. Then it can schedule independent work, report the blocked edge, and avoid pretending that “in progress” means “safe to continue.”
