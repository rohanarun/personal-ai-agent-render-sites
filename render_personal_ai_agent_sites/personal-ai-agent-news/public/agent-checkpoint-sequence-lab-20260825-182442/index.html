Checkpoints change the shape of work.

A checkpoint is not just a pause button. It is a contract about what must be known before the next step. Adjust transition risk, state clarity, reviewer proximity, and recovery ease to see when a workflow should checkpoint.

Workflow posture

Checkpoint at the boundary

checkpoint need = min(risk, state, review, recovery)

Why the minimum?

A risky transition with perfect state clarity still deserves a checkpoint. A nearby reviewer does not help if there is no recovery path. The minimum makes checkpoint placement respond to the weakest protection.
