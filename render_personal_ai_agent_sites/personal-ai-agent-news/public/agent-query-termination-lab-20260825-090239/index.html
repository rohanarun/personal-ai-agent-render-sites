Know when enough is enough.

An agent should stop querying when another answer is unlikely to change the action. Without that boundary, research becomes motion instead of progress.

Termination is a claim about the next decision: the evidence is sufficient for this action, at this risk, now.

Set how much the next query could change the decision, how expensive it is, how risky the current uncertainty remains, and how strong the current evidence is.

Keep risk visible

High residual risk can justify one more query even when evidence feels strong. Make that tradeoff explicit.

Commit with a condition

Stopping should name the action, the evidence supporting it, and the signal that would reopen the investigation.
