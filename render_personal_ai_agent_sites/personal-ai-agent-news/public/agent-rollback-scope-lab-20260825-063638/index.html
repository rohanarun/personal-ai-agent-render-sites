What to notice

Rollback is a boundary, not a button.

Recovery becomes trustworthy when the agent can say which effects it restores and which ones require review.

Scope

Name the effects that move.

Internal state, tool calls, messages, and external mutations may have different rollback semantics. Keep the promise specific.

Reversibility

Some actions cannot be undone.

A sent message or external charge may need compensation, not a pretend rewind. Model the recovery path that actually exists.

Coverage

Restore evidence, not only memory.

Recovery needs current state, action history, and a way to verify the world after rollback. A snapshot alone does not close the loop.

Handoff

Uncovered effects require review.

When the agent cannot restore the full scope, stop with an explicit list of unrecovered effects and ask for a decision.
