Keep conflict useful

A disagreement is data when it tells the next step what to verify instead of being silently flattened into a convenient answer.

Merge compatible views

Combine observations when they describe the same state and their reliability supports a shared conclusion.

Defer the hinge

Ask for one more signal when disagreement could change a consequential decision but remains resolvable.

Preserve the conflict

Keep both observations and escalate when a forced merge would hide uncertainty or create unsafe action.

This simulation is a teaching model, not a production reconciliation policy. It demonstrates a contract-first pattern: compare observations, weight reliability, and preserve unresolved conflicts.
