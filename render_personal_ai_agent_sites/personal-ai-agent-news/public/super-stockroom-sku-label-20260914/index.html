Stockroom SKU Label Desk

Create a Code 128 label from an existing identifier. Keep the encoded value visible for a manual check.

For the person maintaining bin labels

Illustrative scenario: a bin already has the identifier BIN-0012 in your stock system, but its label needs replacing. Enter that identifier exactly, generate the image and compare the displayed text before downloading. The example identifier is not a real inventory record.

This desk uses JsBarcode 3.12.1 with automatic Code 128 encoding. Leading zeros, case and spaces are preserved. This page accepts one to forty printable ASCII characters and fixes black bars on white with a twenty-module margin on each side. Larger module widths increase exported pixel dimensions.

A barcode is not a stock record

Generation does not register a SKU, assign a globally unique product number, or confirm that the item exists. This is not an EAN/UPC or GS1 product-number issuing service. Use identifiers from your existing system. The local tool makes no inventory API call and does not check uniqueness.

The preview may shrink to fit the screen; the PNG retains its original pixel dimensions. Physical dimensions depend on printer resolution and print scaling. Test the printed label with your actual scanner and destination system before applying a batch. No physical scan or printer certification is claimed by this page. Do not crop away the white margins or assume a visible image proves reliable scanning.
