Four constraints per coordinate

A cubic Hermite interpolant matches function values and first derivatives at both endpoints. Each coordinate here solves four linear equations for coefficients in p(t) = a0 + a1 t + a2 t squared + a3 t cubed.

The positions stay fixed while the velocity constraints change the curve. Equal endpoint velocities (2, 0) produce constant-speed straight motion. Zero endpoint velocities produce a straight path with nonconstant speed: stopping at both ends does not imply staying still between them.

Time is normalized to [0, 1]. Velocity is the derivative with respect to that normalized time. Matching position and velocity across adjacent Hermite segments gives C1 continuity, but does not by itself match acceleration. This is interpolation, not a collision-free or dynamically feasible motion planner.
