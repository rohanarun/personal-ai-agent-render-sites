One Bit of Grace

A toy agent sends a four-bit status payload through a noisy channel. Three parity bits can repair one flipped bit. Two flips can make a confident decoder produce the wrong payload.

A correction has assumptions

The decoder XORs the positions of all received one-bits. A zero syndrome triggers no correction; otherwise it flips the indicated position. For one error, this restores the original codeword. With two errors, that same rule changes a third bit and produces another valid codeword.

Why the parity checks locate a bit

Even-parity groups are 1,3,5,7; 2,3,6,7; and 4,5,6,7. Each position has a unique binary address. A single flip changes exactly the checks whose address bits are one, identifying its position.

Zero does not prove an intact message

Hamming(7,4) has minimum distance three. Some three-bit changes turn one valid codeword into another with zero syndrome. An extra overall parity bit enables single-error correction with double-error detection; that extended code is not implemented here.

Agent-system boundary

This is a bit-corruption model, not a claim about an actual agent transport. Error correction does not authenticate a sender, validate a tool's semantics, or repair hallucinations. The original payload comparison is a teaching oracle, not information the receiver normally has.
