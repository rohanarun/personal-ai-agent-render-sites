A useful mental model

Arrival order is only a transport fact.

A late event can still be valid, and a fast event can still be wrong. Reconciliation separates transport timing from the ordering key the state machine actually trusts.

Identify

Give every event a stable identity and sequence signal that survives delivery retries.

Reconcile

Apply, replay, or quarantine based on evidence rather than whichever packet arrived last.

Keep uncertainty visible

A quarantine record is useful state. It lets the system delay mutation without pretending that a weak clock or missing key is good enough.
