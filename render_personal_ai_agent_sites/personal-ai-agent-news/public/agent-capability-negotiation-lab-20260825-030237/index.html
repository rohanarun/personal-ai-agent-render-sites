What the simulation teaches

Capability negotiation is a useful middle path between blind execution and blanket refusal. The agent can clarify the goal, inspect the tool boundary, and propose the smallest request that remains useful.

A useful design move

Describe supported operations and return machine-readable limits. When a request is too broad, expose one valid alternative instead of making the agent guess.
