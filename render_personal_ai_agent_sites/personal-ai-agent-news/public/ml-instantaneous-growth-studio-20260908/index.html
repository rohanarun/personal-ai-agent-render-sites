A derivative, not a norm

For x′ = Ax and a unit initial x, the initial derivative of ‖x‖₂ is xᵀSx, where S = (A + Aᵀ)/2. Maximizing over directions gives μ₂(A) = λmax(S), the Euclidean logarithmic norm. Unlike an ordinary norm, it can be negative.

The table evaluates its defining one-sided limit using singular values of I + hA. A finite h is only an approximation, not the logarithmic norm itself. The global bound is ‖exp(tA)‖₂ ≤ exp(tμ₂(A)) for t ≥ 0.

Rotation cancels from the rate

This family is A = [[−1, c − ω], [c + ω, −1]]. Its symmetric part is [[−1, c], [c, −1]], so μ₂ = c − 1 and the rate at x = (cos θ, sin θ) is −1 + c sin(2θ). Changing ω leaves the whole curve unchanged.

Yet the eigenvalues are −1 ± √(c² − ω²), with a complex square root when needed. The default has spectral abscissa −1 but μ₂ = 0.2: all eigenvalues are stable while some directions initially grow. A positive μ₂ does not alone imply long-term instability. A negative μ₂ does guarantee Euclidean contraction.

This is a continuous-time local dynamics example, relevant to stability reasoning in iterative and learned dynamical systems. It is not a discrete optimizer step-size guarantee. Matrix eigendecomposition and singular values use ml-matrix.
