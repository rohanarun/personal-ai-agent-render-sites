Make narrowing observable

Least privilege is a runtime behavior. The agent should say what capability it requested, what task it covers, and when it will be removed.

  • Grant only the resource and operation needed.
  • Separate preview from commit authority.
  • Require a fresh decision when scope expands.

Try the trap

Raise task breadth and side-effect risk while keeping expiry high. The permission may still feel convenient, but convenience is not a least-privilege proof.

Scope needs a reasonA broad permission should name the extra task it enables and the condition that removes it.
