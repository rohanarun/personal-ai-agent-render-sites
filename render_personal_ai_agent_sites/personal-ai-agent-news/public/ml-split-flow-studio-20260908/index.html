Separate, then compose

The test system is y' = (A + B)y, starting at y(0) = [1, 0.5]. A = -uu^T with u = [1, 0]; B = -vv^T with v = [cos(angle), sin(angle)]. Each component damps along one direction. The joint flow is exp(t(A+B)).

With h = final time / steps, Lie–Trotter applies exp(hA) then exp(hB). Strang applies exp(hA/2), exp(hB), then exp(hA/2). Matrix products act rightmost first. All component exponentials and the exact reference use symmetric eigendecomposition in ml-matrix.

For smooth fixed systems, Lie–Trotter has first-order global accuracy and Strang second-order: halving h eventually reduces error by roughly two and four. This is an asymptotic statement, not a guarantee at every coarse step. At 0 or 90 degrees, A and B commute and both splits are exact up to roundoff.

Such composition ideas also arise in numerical models used in machine learning. This controlled linear example is not a trained neural ODE or a model-quality benchmark.
