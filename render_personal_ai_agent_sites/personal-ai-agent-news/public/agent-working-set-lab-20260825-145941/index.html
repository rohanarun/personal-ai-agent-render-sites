Compression should preserve obligations.

A small working set can improve focus, but dropping a fact that controls authorization or safety turns context management into hidden risk. The right question is not “how much can be forgotten?” but “what must remain true for this action?”

This is a compact teaching model. Production systems still need provenance, explicit permissions, durable state, and human review for consequential actions.
