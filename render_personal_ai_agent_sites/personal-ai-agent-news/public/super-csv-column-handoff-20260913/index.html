Illustrative inventory. Paste up to 20,000 characters. The first record is the header. Completely empty records are skipped; ragged records and malformed quotes block export. Text is processed locally with no model call or data upload.

Included columns

Adds an apostrophe before values beginning with =, +, -, @, tab or carriage return. This changes those values, including negative-number strings. It is not a universal guarantee for every spreadsheet importer.

Export preview

Preview shows the first 20 data records; export includes every parsed record. Output uses commas and CRLF line endings. Column order is preserved. Duplicate and blank headers are retained by position.
