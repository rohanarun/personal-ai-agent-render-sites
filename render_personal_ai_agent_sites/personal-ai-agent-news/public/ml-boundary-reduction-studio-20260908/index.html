Elimination creates direct connections

Write the graph Laplacian in boundary and interior blocks. With interior current fixed at zero, solve L interior-interior times x interior = -L interior-boundary times x boundary. Substitution gives the reduced Laplacian L boundary-boundary - L boundary-interior L interior-interior inverse L interior-boundary: a Schur complement.

For this star, let s be the sum of its three weights. If s is positive, the interior value is the weighted average of the boundary values. Each reduced edge i,j has weight w[i] w[j] / s. Zero-weight boundary connections contribute no reduced edges. If all weights vanish, the interior is unconstrained; its value is withheld, and both graph energies are zero.

Which properties survive?

With zero interior forcing, this reduction preserves boundary currents for every boundary value and the minimum energy after the interior settles. It does not preserve node count, all eigenvalues, arbitrary interior forcing, or a time-dependent trajectory. In graph-based learning, eliminating latent nodes from a quadratic smoothness penalty uses this same algebra, but that alone does not certify downstream prediction quality.
