What good traces preserve

Stable correlation, meaningful event names, input and output boundaries, and enough timing context to distinguish a slow dependency from a wrong decision.

Observability is a reasoning aid.

A trace is not a transcript of everything. It is a structured record that helps an operator form and test a causal hypothesis about what happened.

Instrument the boundaries where the system changes state: planning, retrieval, tool invocation, approval, and final response. Every missing boundary adds a guess to the investigation.
