Agent Cache Invalidation Lab

A fast answer is not useful when its evidence has expired.

Test the boundary between a reusable cached result and a refresh-worthy one. This lab makes freshness, tolerance, and refresh cost explicit.

Set the evidence policy

The policy compares source age with a time-to-live and a review tolerance before an agent relies on cached context.
