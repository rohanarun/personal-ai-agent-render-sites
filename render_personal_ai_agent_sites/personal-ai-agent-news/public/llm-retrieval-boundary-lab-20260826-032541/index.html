Why overlap matters

Chunking is a representation choice. It affects what can be matched, how much context must be reassembled, and how much irrelevant text travels into the model's context.

Context has edges.

Retrieval quality is not only a ranking problem. The unit you index determines which relationships remain visible when a query arrives later.

Use evaluation questions that cross headings, sentences, and document boundaries. A chunking strategy that looks tidy on a diagram can still hide the evidence a real user needs.
