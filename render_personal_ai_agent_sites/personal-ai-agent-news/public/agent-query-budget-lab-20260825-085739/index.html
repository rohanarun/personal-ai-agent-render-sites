Spend the next query well.

A tool call is not automatically progress. The best query is the one whose answer can change the next decision enough to justify its latency, cost, and risk.

Query budgets turn curiosity into a control loop: ask, measure the change, then stop when the answer no longer moves the plan.

Query Budget Lab

Set how much the next answer could change the plan, how expensive the query is, how urgent the task is, and how risky a wrong decision would be.

A query earns its place by changing the action, not by making the transcript longer.

Ask for contrast

Queries are strongest when they distinguish live options. Broad collection is weaker than a question tied to a decision.

Measure the delta

After an answer, compare the plan before and after. If nothing changed, the next query needs a sharper purpose.

Respect urgency

When time is short, accept bounded uncertainty only when the downside is reversible and visible.
