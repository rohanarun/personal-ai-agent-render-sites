A better fit can be a worse signal

Blur hides a high-frequency direction. A tiny amount of noise in that direction becomes large when inverted. Ridge regularization trades some fit for a less amplified reconstruction.

The inverse, with a filter

minimize ||Ax - b||22 + lambda ||x||22
x = V diag(sigma / (sigma2 + lambda)) UTb

DirectionSingular valueInverse gainRidge gainRetained fraction

Without a penalty, each observation coefficient along a left singular vector is multiplied by 1/sigma. Ridge replaces that gain with sigma/(sigma squared + lambda). The retained fraction sigma squared/(sigma squared + lambda) compares the regularized gain with the unregularized gain; it is not a probability.

This page uses lambda as the coefficient of ||x|| squared. The linked Cornell notes write that coefficient as lambda squared. Repeated singular values share the same gain even though a basis within their subspace is not unique.

What the blur hides

(Ax)[i] = 0.24 x[i-1] + 0.52 x[i] + 0.24 x[i+1]

Indices wrap around eight positions. The singular values range from 1 down to 0.04, so the condition number is 25. Alternating noise eta times [1,-1,1,-1,1,-1,1,-1] lies in the weakest direction. The unregularized reconstruction amplifies its amplitude by 25, giving an error norm sqrt(8) eta / 0.04.

With no noise, the inverse recovers the signal, while a positive penalty introduces bias. With noise, an intermediate penalty can improve reconstruction, but too much shrinks real structure. The alternating-signal preset makes that cost visible: the signal and noise occupy the same hard-to-recover direction.

This is one controlled noise realization, not a statistical average. Real inverse problems usually do not reveal x_true, so its error cannot normally be used to tune lambda directly. All reconstruction uses the ml-matrix SVD, not an explicit inverse of the normal-equation matrix. Export contains observations, solutions, singular values, gains, and stationarity residual.
