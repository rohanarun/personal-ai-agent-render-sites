Sprite Alpha Inspector

How to inspect sprite transparency without guessing from the background color.

PNG, WebP or JPEG, up to 8 MiB, 4 megapixels and 4096 pixels per edge. Animated files use one decoded frame. No resizing is applied to accepted images.

Preview

Alpha is not brightness

For the 8-bit canvas data used here, alpha 0 is transparent and 255 is opaque. An opaque black pixel and an opaque white pixel both produce white in the exported mask. Partially transparent pixels become gray. The mask stores the observed alpha as equal red, green and blue values, with its own alpha fixed at 255.

The coordinates refer to the decoded image, starting at the top-left (0, 0). The readout always probes the source artwork, even in mask view. Clicking or tapping the preview selects a pixel; the numeric fields provide an exact alternative. The checkerboard is only a CSS backdrop and is not part of the mask export.

What this inspection does not prove

These are browser-decoded canvas values, not a forensic read of the original file. Color conversion and premultiplied-alpha round trips can change RGB values, especially near transparency. The tool does not recover hidden original RGB, diagnose a game engine's blend settings, or repair edge halos. Inspect the asset in its target engine too. A JPEG normally has no transparency, so its mask is opaque white.
