What the simulation teaches

A stopping rule is part of agent quality. Without one, retrieval can become a loop that adds volume while reducing clarity and delaying a bounded action.

A useful design move

Estimate whether the next observation could change the decision. If not, stop, report the evidence boundary, and let the user decide whether more search is worth the cost.
