Presence is a separate question
Object.hasOwn checks the task itself. The in operator includes its prototype chain. A read can find an inherited value, while an own undefined property still counts as present and shadows the default.
Illustrative debugging exercise: set an own false, change the default to true, and delete the own setting. Observe which operation reveals the default. Now set own undefined. A value-only test cannot tell that state from a missing field with no default.
This lab uses Object.create and Object.setPrototypeOf on isolated objects. No global prototype is changed. Its retry field is teaching data: it neither authorizes actions nor schedules retries. Property ownership alone is not input validation, provenance or permission.
Keep intent in the contract
For a real agent configuration, decide whether omission means “inherit,” whether null means “clear,” and whether undefined is allowed. Those are application choices, not answers JavaScript supplies. Validate the chosen types before executing a tool.
The downloadable transition log stores tagged values and own-property presence separately. An ordinary JSON object can omit undefined values, so exporting only that object would lose this experiment's key evidence. Reloading or resetting clears the log.
