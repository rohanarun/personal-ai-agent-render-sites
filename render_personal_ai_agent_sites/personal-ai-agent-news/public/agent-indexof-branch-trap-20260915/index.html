The branch can disagree with membership

At the first element, indexOf returns 0. Converting that result to a Boolean produces false. With no matching element, it returns -1, which converts to true. A later match such as index 1 is also truthy, so testing only that case hides both boundary failures.

Interpret the sentinel explicitly

The native method returns the first matching position or -1 when the element is absent. Compare that sentinel when you need both the position and the membership decision. Array.indexOf reference.

Use a Boolean when you only need membership

includes returns a Boolean directly. For the dense string arrays accepted here, it agrees with index !== -1. Other types and sparse arrays have additional semantics, so this result is deliberately scoped. Array.includes reference.

Routing is not authorization

These outputs describe whether a local JavaScript branch is entered. No job executes. A matching label does not establish a user's permission, the current task state, or whether an external action is safe. Agent tool routers need their own validated contracts and authorization checks.

The queue accepts zero to eight strings, each up to forty characters. Matching is exact and case-sensitive; spaces and empty strings are preserved. Duplicate IDs are allowed so the first-match behavior remains visible. Input changes invalidate the previous observation until evaluation. No JavaScript source is evaluated from the text box.
