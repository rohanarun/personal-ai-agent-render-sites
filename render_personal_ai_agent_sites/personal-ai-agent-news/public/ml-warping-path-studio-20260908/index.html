Alignment is a modeling choice

DTW finds a low-cost monotone path from the first pair to the last. A step advances A, B, or both by one sample. Horizontal and vertical moves allow repeated matches: time may stretch, but never run backward.

The stretched preset has zero alignment cost even though the arrays differ in length. That does not make the signals identical. Unconstrained warping can erase timing distinctions that matter to the task.

Which distance is displayed?

Each grid cell contains either |A[i] - B[j]| or (A[i] - B[j]) squared. The result is the sum along the chosen optimal path. No square root or path-length normalization is applied. The same-index baseline exists only for equal lengths and uses the same local cost.

Ties may yield multiple optimal paths. This page shows one returned by the library. A low cost is not a probability, semantic match, or classifier accuracy. Real applications may constrain the warping window; this small demonstration is unconstrained.
