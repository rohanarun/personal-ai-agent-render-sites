Ask for sharper evidence.

An agent can gather a lot of information and still learn very little. The missing ingredient is resolution: can the next observation actually separate the explanations that remain?

A useful observation does more than add data. It changes which branch deserves the next action.

Stop when the observation can change the decision, not merely decorate the explanation.

Separate signal from volume

More tokens, logs, or tool results do not guarantee more information. Ask what competing hypotheses the observation can actually distinguish.

Price the delay

A sharper check has a cost. Compare its expected decision improvement with latency, tool use, and the risk of waiting.

Make stopping explicit

An agent needs a postcondition: what evidence is enough, what action follows, and what recovery path exists if the test fails?
