CSV Transpose Desk

How to swap rows and columns without spreadsheet copy-paste. Turn a small research matrix sideways before handing it to a collaborator.

Orientation changes, observations do not

The illustrative matrix has measurements down the left and sample labels across the top. Transposing moves each original cell at row r, column c to row c, column r. A 3-by-4 matrix becomes 4-by-3. No values are summed, averaged or joined. This is not a pivot table.

The first row is ordinary data, not a special header. Leading zeros stay text. Every row must have the same field count: an empty cell between commas is valid, but a missing field is not silently padded. Blank physical records are skipped; quoted multiline cells remain cells. This desk accepts at most 100,000 characters and 100 rows by 100 columns.

A CSV is not a workbook

Papa Parse handles quoted commas, embedded newlines and quote escaping. Output uses commas and CRLF record separators; original byte formatting is not preserved. The table shows the actual exported cell strings.

Formula protection is enabled by default. Cells beginning with =, +, -, @, tab or carriage return receive an apostrophe, which changes their text. This includes negative-number strings. Disable it only when exact cell strings are required and the receiving application will not evaluate them. Quoting alone is not formula protection. This page does not execute formulas; a spreadsheet may interpret an unprotected export.

Changing the input or protection setting invalidates the old download. Review the new matrix before exporting. Use non-sensitive sample data; parsing and transposition happen in this page, with no file upload or model request.
