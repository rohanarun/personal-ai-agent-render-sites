What is being calculated?

Encoding = (category label sum + smoothing × reference mean) / (category count + smoothing). With smoothing zero this is the ordinary category mean. If the category is absent, use the reference mean.

In-sample encoding uses all eight rows. Out-of-fold encoding uses only the other fold, including for its reference mean. Fold assignments stay fixed when labels change. The rare category on row 7 demonstrates the fallback.

Where this fits

Cross-fitting prevents a training row's label from directly entering its own encoding. It does not guarantee generalization or fix group/time leakage. For separate validation or test data, learn the mapping from training data only; never use validation or test labels. No downstream classifier is trained here.

This small, unsmoothed-or-fixed-smoothing illustration is not a full implementation of scikit-learn. See TargetEncoder documentation for cross-fitting, smoothing and unseen-category behavior.
