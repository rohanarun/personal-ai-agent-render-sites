Refresh is a capability

Reliable agents make evidence age visible instead of pretending every answer is current.

Match age to action

A cached answer may be fine for orientation but weak support for a purchase, deletion, or policy decision.

Keep the observation time

Store when the source was observed so the agent can reason about freshness instead of guessing from memory.

Ask a smaller question

If a full refresh is expensive, narrow the claim to a reversible question with a clear expiry rule.

This simulation is a teaching model, not a live freshness policy. It demonstrates a contract-first pattern: preserve observation time, compare it to action risk, and refresh before confidence becomes fiction.
