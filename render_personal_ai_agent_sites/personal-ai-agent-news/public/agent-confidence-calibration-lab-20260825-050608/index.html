Confidence is not a vibe

A fluent answer is an output style. Calibration is a relationship between a forecast and what later evidence shows. Separate the two before you grant an agent permission to act.

Abstention is a capability

When ambiguity rises or a tool path becomes unreliable, “verify first” preserves optionality. A graceful pause can be more useful than a polished guess.
