Delegate deliberately

A good handoff makes ownership, limits, and return shape impossible to confuse.

Give one bounded outcome

Delegate a result the sub-agent can complete without inventing a new objective or expanding the scope.

Define the return shape

Require status, evidence, uncertainty, and remaining work so the parent can decide what happens next.

Keep commitment control

Let the sub-agent prepare an action, but reserve irreversible side effects for the owner of the original goal.

This simulation is a teaching model, not a production delegation policy. It demonstrates a contract-first pattern: bound the subtask, specify the return, and gate consequential commitments.
