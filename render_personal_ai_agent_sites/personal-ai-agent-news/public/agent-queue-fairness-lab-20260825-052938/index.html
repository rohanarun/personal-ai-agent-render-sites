Add aging

Priority is useful, but waiting work needs a path back into consideration. Let time change a task's effective priority.

Urgency is not the only clock

Priority queues optimize for what looks important now. Aging protects tasks whose importance is revealed by how long they have been waiting.

Measure the tail

Average latency can look healthy while one class of work waits forever. Track tail wait, class coverage, and whether every task has a credible service path.
