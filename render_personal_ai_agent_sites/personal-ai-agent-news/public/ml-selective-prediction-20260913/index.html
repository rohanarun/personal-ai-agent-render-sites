When to Abstain

Ten synthetic predictions have confidence scores and known outcomes. Accept only scores at or above the threshold. Which errors remain, and how much work does the model decline?

Coverage is accepted predictions divided by all ten predictions. Selective error rate is errors among accepted predictions divided by accepted predictions. Abstentions are not counted as correct answers. At zero accepted predictions, this error rate is undefined.

Green accepted tiles are correct, red accepted tiles are wrong, and gray tiles are declined. Every tile retains its known outcome so you can inspect the selection. In deployment, those labels may not be available immediately.

A score is not a guarantee

The two examples have the same number of errors overall. Only their position in the confidence ordering changes. Raising a threshold reduces coverage but need not reduce the error rate; it can preserve the most confidently wrong cases.

This tiny hand-authored dataset illustrates a reject option. It does not implement statistical risk control, calibration, or the method in the cited paper. Selecting a threshold after inspecting these same labels is not independent evaluation. A real assessment needs representative held-out data and a defined process for declined tasks.
