Mass crossing each boundary

For this unit-spaced support, Wasserstein-1 is the sum of the absolute cumulative probability gaps at boundaries 0 through 6. It equals the minimum mass-times-distance cost of transporting the reference into the current distribution.

Same mean is not the same distribution

The reference puts half its mass at 3 and half at 4. The wider preset puts half at 2 and half at 5. Both means are 3.5, yet moving each half by one unit costs 1. The shifted preset instead has distance 2.

What this says about a model

This is a descriptive shift measure for one ordered feature. It is not a significance test or proof of performance degradation. Feature units matter: doubling every support value doubles the distance. Categorical labels without a meaningful distance need a different treatment.

Weights, not a sample-size claim

The sliders supply nonnegative weights, normalized separately from the reference. Multiplying all current weights by the same positive factor leaves the result unchanged. All-zero weights do not define a probability distribution, so no distance is reported.
