Zeros by orthogonal transformations

A Givens rotation maps [f, g] to [r, 0] with c = f/hypot(f,g) and s = g/hypot(f,g), choosing r nonnegative. If both entries are zero, this experiment uses the identity. The rotation preserves Euclidean length.

Each application updates R to G R and Q to Q G transpose, starting from R = A and Q = I. Thus A = QR remains true even when an angle misses its target. A QR factorization additionally requires R to be upper triangular.

The row pairs are (1,2), (1,3), then (2,3), targeting entries (2,1), (3,1), and (3,2). An inaccurate early rotation can leave residual entries after all three stages. Undo or restart to try again. Givens rotations are useful when matrix structure contains many zeros.
