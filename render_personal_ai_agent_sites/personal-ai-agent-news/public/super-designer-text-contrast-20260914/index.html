Text contrast desk

Check a text-and-background pair without guessing from the swatches. A focused designer's desk for opaque sRGB colors.

A pair check, not a page certificate
WCAG's minimum text-contrast criterion uses 4.5:1 for normal text and 3:1 for large text, with exceptions such as incidental text and logotypes. Large text is at least 18 point, or 14 point bold. This desk's large preview is 32 CSS pixels at normal weight. It does not decide whether text in your actual design qualifies.
Pass or fail uses the unrounded ratio. The display is rounded to four decimal places only for reading. Swapping colors keeps this ratio the same, but it can change the visual experience. Equal colors have a 1:1 ratio; black and white reach 21:1 in this calculation.
This tool does not test focus states, images, gradients, transparent layers, disabled controls, keyboard access or screen-reader behavior. It cannot certify WCAG conformance. Check the actual rendered interface and all relevant states. A passing pair does not make tiny or poorly chosen typography easy to read.
The CSS export sets color, background-color and the preview font size on a named class. Apply it intentionally and check inherited styles and overlays. The illustrative sentence is not exported. Inputs and previews are local; the demonstration video below loads externally. No model is called.
