Scores explain only part of a flow

Fit node scores p so that p(head) - p(tail) approximates each edge value in least squares. Those differences form the gradient component. The remaining cycle component has zero net inflow at every node and is orthogonal to every gradient flow. This two-way decomposition underlies the ranking approach of Jiang, Lim, Yao and Ye, Statistical ranking and combinatorial Hodge theory.

f = g + c, g = D transpose p, D c = 0
||f|| squared = ||g|| squared + ||c|| squared

D has -1 at each edge's tail and +1 at its head. The normal equations are D D transpose p = D f. A pseudoinverse selects the zero-mean solution; adding a constant to every score changes no edge difference.

For pairwise preference data, a large cycle component means a score vector leaves substantial inconsistency unexplained. It is not automatically evidence of bad data: genuine cyclic preferences can exist. A pure circulation may be nonzero even though all fitted scores are zero.

This is the unweighted gradient-versus-cycle split on a fixed connected graph. We do not separate the cycle space further into curl and harmonic components. Squared norms here are algebraic flow energies, not a physical power model.
