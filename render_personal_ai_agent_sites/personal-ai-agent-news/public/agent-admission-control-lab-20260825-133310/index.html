What the gate is protecting

Accepting work is useful only while the system can preserve enough capacity to complete it. As pressure rises, the policy moves from optimistic throughput toward explicit deferral and rejection.

A useful mental model

Backpressure is an agent capability, not an infrastructure detail.

When a tool call, delegated task, or long-running workflow enters a system, admission is the first chance to make its cost and authority legible. A bounded queue gives operators a place to see pressure before it becomes a cascade.

1. Measure

Read the current queue, available capacity, priority, and reserved buffer. Keep the inputs observable.

2. Decide

Apply a simple policy with explicit thresholds. The explanation is part of the decision, not a debug afterthought.

3. Make recovery cheap

A deferred request should have a clear retry condition. A rejected request should return a bounded reason. Both are safer than letting hidden work grow until cancellation, latency, or cost becomes the surprise.
