The control-flow rule
Generator.throw(error) resumes a suspended generator with an exception at its pause point. A surrounding catch may handle it and yield a value, so throw() can return an iterator result with done: false. An uncaught exception reaches the caller and closes the generator. See MDN's Generator.throw reference.
Agent-system boundary
This fixture models a controller reporting an unsuccessful step to a local procedure. A recovery yield is only a program value: it does not retry a tool, roll back a side effect, restore a browser, or prove that a task recovered. Those operations need their own implementation and evidence.
The lab uses native synchronous generators, not promises or an LLM. Each mode change creates a fresh iterator. Trace exports record calls and observed results; undefined is represented explicitly as a type marker. The display keeps at most 30 calls per run.
