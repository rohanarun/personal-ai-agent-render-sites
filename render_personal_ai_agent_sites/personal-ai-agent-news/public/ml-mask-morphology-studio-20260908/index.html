Expand, shrink, or compose

Dilation turns a pixel on when any foreground pixel falls under the centered structuring element. Erosion keeps a pixel on only when every active part of that element fits inside foreground. The square checks all nine positions; the cross checks the center and four orthogonal neighbors.

Opening is erosion followed by dilation. It can remove isolated specks and narrow foreground features. Closing is dilation followed by erosion. It can fill small gaps and holes. Neither operation knows whether a feature is noise or a real object.

Edges are part of the model

This lab embeds the 8 x 8 input in three pixels of zero padding on each side. All stages run on that padded image, then the center is cropped once. The surrounding world begins as background; intermediate dilation can extend into it. Counts and changed-pixel marks refer only to the displayed 8 x 8 region.

Post-processing is not ground truth

In segmentation workflows, morphology is a geometric post-processing choice, not a learned semantic correction. A thin structure can disappear during opening; nearby objects can merge during closing. Compare against labeled validation data before treating a visually smoother mask as an improvement.

These synthetic masks illustrate one application of the selected element. The result is always recomputed from the input, not repeatedly applied to the previous output.
