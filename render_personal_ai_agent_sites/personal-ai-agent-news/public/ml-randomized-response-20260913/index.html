For either report, changing the true answer changes its probability by at most a factor of three. This one-report mechanism satisfies local differential privacy with epsilon = ln(3), approximately 1.099.

Recover the aggregate

If the true yes rate is theta, the reported rate has expectation q = 0.25 + 0.50 theta. The unbiased estimate is therefore 2 times the observed report rate minus 0.5. We leave estimates outside 0 to 100% visible: clipping would change the estimator.

Why sample size matters

Each respondent is sampled independently from the population, then independently randomized. Under this model, the estimator's standard error is 2 sqrt(q(1-q)/n). The displayed value uses the known synthetic population q; it is not an uncertainty estimate inferred from a real private survey.

Privacy has a scope

The bound describes a single randomized report, not certainty that the true bit remains unknown. Repeated reports about the same person consume additional privacy. This teaching simulation retains synthetic truth for explanation; a real local-private collection system must randomize before the collector receives the response.
