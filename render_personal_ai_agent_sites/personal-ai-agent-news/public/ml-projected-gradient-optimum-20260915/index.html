At the Optimum, Still Pointing Downhill

How can an optimizer be finished when its gradient is not zero?

A constraint changes what “no better move” means. Step through projected gradient descent on a quadratic, distinguish feasibility from optimality, and test why projecting the unconstrained minimum once is usually not enough.

The minimum you cannot reach

We minimize F(x,y)=½[(x−2)²+k(y−1)²] subject to x²+y²≤R². The unconstrained minimum (2,1) has zero loss. If R is below √5, that point is forbidden. The task is not to reach it anyway, but to find the lowest loss among allowed points.

The two Hessian eigenvalues are 1 and k. With k=4, an error in y contributes four times as much squared loss as the same error in x. The loss contours are ellipses rather than circles. That is why Euclidean closeness to (2,1) is not generally the same as low objective value.

Two operations, one iteration

First take a gradient step u=x−η∇F(x). Then project it: x_next=ΠC(u). The learning rate is fixed at η=0.8/k for each selected problem. The initial point is (−0.6R,0), which is feasible.

For a disk, Euclidean projection is explicit. If u is already inside, keep it. Otherwise replace it by R u/||u||. This moves to the nearest point of the disk. It is not coordinate-wise clipping, which would instead project onto a box and could leave the result outside the disk.

The orange marker is the proposed u from the currently selected iterate. The teal segment shows where projection sends that proposal. Even after the black point reaches the optimum, a new orange proposal can lie outside the feasible set; projection sends it back. Forty steps are shown, with no automatic playback or hidden stopping rule.

Why projecting the unconstrained answer fails

The gray marker takes the shortcut ΠC(2,1). It is certainly feasible. But feasibility alone does not solve the original minimization problem. For k=4, the better boundary point spends more of its available radius reducing y error because that coordinate is more expensive.

Set k=1 and compare again. Now the objective is half the squared Euclidean distance to (2,1), so its constrained minimizer is exactly that Euclidean projection. Gray and pink coincide. This special case explains why the shortcut can feel convincing and why unequal curvature breaks it.

Increase R to 2.3. The unconstrained minimum is now inside the disk, so the constraint is inactive at the solution. Both reference markers coincide at (2,1), and the gradient approaches zero. A constraint can matter during early iterations without remaining active at the optimum.

Optimality is about feasible directions

For differentiable convex F over a convex set C, a point x* is optimal when ∇F(x*)ᵀ(z−x*) ≥ 0 for every feasible z. No allowed displacement gives a negative first-order change. This does not require the gradient itself to vanish.

At a boundary optimum for our disk, ∇F(x*) + μx* = 0 with μ≥0. The negative gradient therefore points radially outward when μ is positive. That is exactly the direction the constraint blocks. Moving inward is feasible but initially increases loss; tangential feasible motion also cannot improve the convex objective.

The reference point is calculated independently of the displayed iterations. Solving the stationarity equation gives x*=2/(1+μ) and y*=k/(k+μ). If the unconstrained center is outside, μ is the unique positive root of [2/(1+μ)]²+[k/(k+μ)]²=R². The fmin bisection library solves this scalar equation; the residual is checked numerically. The multiplier convention uses μ/2 on the squared-radius constraint.

Use the right residual

The ordinary gradient norm can remain large at the constrained optimum. The projected-gradient mapping is a better diagnostic here:

Gη(x) = [x−ΠC(x−η∇F(x))]/η

It is zero at a projected fixed point. In this convex setting, that fixed point satisfies the constrained optimality condition. The readout displays both norms so that you can see them disagree for a meaningful reason rather than treating the nonzero gradient as a failed solver.

The loss gap compares the selected iterate against the independent constrained reference. It uses the same original objective for both points. Tiny signed roundoff may appear near convergence. The height scale is only for drawing and is not used in the loss, gradients, projection or gap.

What is guaranteed in this experiment

Our gradient is Lipschitz with L=k, and the chosen step is below 1/L. Combined with the closed convex disk and exact Euclidean projection, this supports descent and convergence to the unique solution of this strongly convex quadratic. The program does not infer convergence merely because the last few dots look stationary.

This is a constructed optimization problem, not a trained network or an operational safety guarantee. Nonconvex constraints can make projection nonunique; nonconvex objectives can have multiple stationary points; approximate projections and noisy gradients change the analysis. Keeping a parameter vector in a mathematical disk is not evidence that an agent obeys a real-world policy.

For the projected and proximal viewpoint, read Parikh and Boyd's Proximal Algorithms, especially the projection and proximal-gradient sections. The reference root uses fmin. Compare momentum stability, where the issue is unconstrained dynamics rather than a forbidden descent direction.
