Coordinates share a spectral budget

We form C = Q diag(eigenvalues) Q^T, with Q = R23(c) R13(b) R12(a). Each R is an orthogonal plane rotation; the rightmost acts first. Orthogonal similarity preserves the spectrum, while diagonal entries report variance along the displayed coordinate axes.

Schur's inequality says the sorted diagonal is majorized by the sorted eigenvalues: each leading partial sum is no larger, and the total sums agree. Horn's converse characterizes the diagonals achievable by Hermitian matrices with a prescribed spectrum. These sliders demonstrate the inequality, not a solver for every feasible target diagonal.

For a covariance matrix this distinguishes coordinate variances from principal-component variances. Equal coordinate variances alone do not imply an isotropic covariance matrix. The isotropic spectrum here does imply C = 3I for every rotation. ml-matrix computes the products and independently recovers the eigenvalues.
