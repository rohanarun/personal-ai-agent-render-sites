Low-Rank Update, Not Low-Rank Model

Factor the change, keep the base

For a linear layer, write the adapted output as y=(W₀+ΔW)x. A low-rank parameterization uses ΔW=BA, where A has r rows and B has r columns. A first maps the input into r coordinates; B maps those coordinates into the output space. The update's rank is at most r.

At rank one, B is one output vector b and A is one row aᵀ. Then ΔWx=b(aᵀx). Different inputs produce different scalar coefficients, including negative ones, but every update lies on the same line through b. Many changed outputs do not imply many independent output directions.

This is the basic factorization used by LoRA-style adaptation. This page does not train an adapter, run an LLM or measure fine-tuning quality. We choose a target correction and calculate a transparent approximation so the constraint is visible.

An explicit target with two directions

Define orthonormal output vectors u=(1,1,0)/√2 and v=(−1,1,2)/√6. The desired 3-by-2 update is T=[u, s v]. Its first input coordinate requests a correction along u; its second requests one along v, scaled by s. For positive s, these corrections are independent.

As x traverses the unit input circle, Tx traces an ellipse in the output plane spanned by u and v. At s=0 the ellipse collapses to a line. At s=1 it is a circle in that plane. The tilted plane is real output geometry, not an extra axis added for decoration.

For rank one, the direction control sets b=cos ψ·u+sin ψ·v. We choose A=bᵀT, so BA=bbᵀT. Since b is unit length, this is the orthogonal projection of the target columns onto the selected output line. It is the least-squares fit for that fixed line; the direction itself is selected by you, not learned.

One input can look perfect while another fails

At reset, s=0.6 and ψ=0. For input (1,0), both the target and approximation produce u. Error is zero. For input (0,1), the target produces 0.6v while the rank-one approximation produces zero. Squared output error is 0.36.

The squared Frobenius matrix error is also 0.36 because it sums squared errors on the two standard input basis vectors. That equality does not mean every input has error 0.36. For input (cos θ,sin θ), the squared error here is 0.36 sin²θ. The average around a uniformly distributed unit circle is 0.18.

The readout keeps these quantities separate: matrix error, uniform-circle mean error and selected-probe error. A demonstration on one favorable input would miss the lost direction. Conversely, a worst-direction example does not describe average performance under an arbitrary data distribution.

Rotate the allowed line

For our target, the exact squared matrix error at rank one is sin²ψ+s²cos²ψ. When s<1, alignment with u minimizes this expression. Rotating toward v sacrifices more of the stronger correction than it gains from the weaker one. At ψ=90° and s=0.6, the error is 1 rather than 0.36.

When s=1, every direction in this output plane gives error 1. The two singular values tie, so the best rank-one direction is not unique. When s=0, alignment with u gives exact reconstruction; rotating away from u can still introduce error even though the target itself is rank one.

Choose rank two. We use B=[u,v] and A=diag(1,s), which reconstruct T exactly up to roundoff. The direction slider is then disabled because this rank-two construction already includes both directions. A rank budget is an upper bound: at s=0 the resulting update still has rank one.

The total layer need not collapse

Turn on the frozen base layer. Here W₀=[u,v]. With rank-one alignment at ψ=0, the total layer maps the unit circle to an ellipse with axes 2 and 1. It has rank two, even though the added update has rank one. The base already supplies an independent direction.

Both target and approximate traces receive the same W₀x, so their difference remains (BA−T)x. The error metrics must not change when this checkbox changes the view. A low-rank update constrains the modification; it does not require all information passing through the existing layer to fit into that low-rank subspace.

Parameter savings have conditions

A dense d_out-by-d_in update has d_out·d_in entries. Its two factors have r(d_out+d_in) entries. For a 4096-by-4096 matrix and r=8, that is 65,536 factor entries versus 16,777,216 dense entries. This is an arithmetic parameter count, not a measured memory, speed or price improvement.

Our deliberately tiny 3-by-2 example has six dense entries. Rank one uses five factor entries, while rank two uses ten, more than the dense matrix. Low-rank parameterization is not automatically economical at every dimension or rank. Factor entries also have redundancy: rescaling one factor and inversely rescaling the other can leave their product unchanged.

What real adaptation still has to solve

A real task does not normally supply a target matrix T whose projection you can compute. Training must find factors from a task loss, and useful rank depends on the layer, data and desired changes. Nonlinear downstream layers, multiple adapted matrices, scaling conventions and optimization all affect behavior. Our Euclidean matrix error is not a language-model quality score.
