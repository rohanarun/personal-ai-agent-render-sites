Set

Start with the user-visible promise.

The root request chooses an absolute deadline instead of granting every internal stage a full timeout.

Propagate

Forward only remaining time.

Each downstream call subtracts elapsed work and transport reserve before accepting a new operation.

Cancel

Stop work that cannot matter.

When remaining time is insufficient, cancel early and return a bounded fallback instead of a stale success.
