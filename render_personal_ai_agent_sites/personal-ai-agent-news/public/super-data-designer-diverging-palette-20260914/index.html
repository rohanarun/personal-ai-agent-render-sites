Only finite numbers between -1 and 1, or null for missing data, are accepted. This page does not normalize a dataset. Editing values disables export until a valid sample is applied.

Make the mapping explicit
Illustrative scenario: a designer is reviewing deviations from a reference value. Zero is the center of this fixed scale, not the average of the sample. Keeping that center explicit prevents a new batch of values from silently changing what a color means.
The bundled chroma.js library interpolates three anchors in RGB or CIE Lab. Those modes can produce different intermediate colors. The exported CSS contains discrete hex variables, not a continuous CSS gradient; the JSON also records the anchors, mode, positions and sample-to-color mapping.
This is a palette workbench, not an accessibility certification. Labels remain visible, missing cells have a separate pattern, and label text uses whichever of black or white has higher computed contrast. Still test the actual chart, legend and surrounding interface with your audience. No color-vision, print-proofing or perceptual-uniformity guarantee is made. Hex output is limited to display RGB.

What the cache actually reuses

The store requires an owner, verified-complete confirmation, task/source context and runnable Python steps, and can decline a workflow on portability grounds. A hit returns a procedure with helper-version information, a verification reason and output evidence. Reusing an eligible procedure is different from retrieving an answer about colors.
Missing context, an empty cache or no safe match returns a miss for the caller to handle. The route alone does not establish automatic fallback, account availability or successful execution in another app. Matching may incur charges. We have not measured speed or cost improvements here.
A bounded design pilot would use the approved tokens, a test destination and an explicit permitted action, then check the resulting artifact. Exporting these colors does not run that pilot or authorize a production change.
