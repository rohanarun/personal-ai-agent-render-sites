An absence-of-evidence simulator

“Nothing found” is a result you have to earn.

An agent can search a system and return an empty list, but the meaning of that empty list depends on coverage, freshness, and the precision of the query. Tune the search and see whether absence is defensible.

Empty is only as strong as the boundary around it.

A negative result is a claim about a search space. An agent should carry the scope of that search into its language and recovery plan instead of treating an empty response as universal truth.

State the search boundary

Name which system, time window, identity, and record types were checked.

Prefer authoritative absence

An empty cache is weaker than an empty system of record, especially when duplicate creation has consequences.

Use absence to guide the next check

When confidence is partial, ask what additional source or identity would make the negative result defensible.
