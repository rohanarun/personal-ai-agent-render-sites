Only discordant pairs enter this test

Let b be examples only A gets right, and c those only B gets right. Under the null of equal marginal correctness probabilities, the conditional count among b+c discordant pairs is binomial with probability 1/2. The two-sided exact McNemar p-value is twice the lower tail through min(b,c), capped at one.

Read the contrast

Six wins and zero losses give p = 0.03125. Eight wins and two losses give p = 0.109375. Both give a six-example accuracy advantage here. The extra opposing outcomes change the evidence, despite identical marginal scores.

What the number does not say

A p-value is not the probability the models are equally good. A large value does not establish equivalence. This demo makes no automatic deployment decision and shows no accuracy confidence interval.

Evaluation assumptions

Pairs must refer to the same examples, with independence across examples. Repeated users or near-duplicate tasks may violate that assumption. Select the test before examining outcomes; searching many model variants requires accounting for selection and multiple testing. The UI retains every pair solely for inspection and export.
