A similarity, not a new spectrum

Balancing uses B = inv(D) A D to reduce row/column magnitude differences before eigensolver work. Because this is a similarity transformation, eigenvalues are unchanged. If B v = lambda v, then D v is an eigenvector of A.

For this family, B has off-diagonal entries 2^(e-t) and 2^(t-e). At t = e both equal 1, B is symmetric, and its eigenvectors are perpendicular. Its Frobenius norm is minimized there. The eigenvalues are always (3 - sqrt(5))/2 and (3 + sqrt(5))/2.

The angle is measured between eigenvector lines in the current coordinates, so it does change under a nonorthogonal scaling. Powers of two mirror a common numerical scaling choice. This small example illustrates balancing, not a full LAPACK implementation or a guarantee that every matrix benefits.
