The surface is manageable and the recovery path is useful. Keep the change bounded and verify the connected behavior.

A small request can have a wide shadow.

Agents often optimize for completing the visible request. But a change can cross hidden boundaries: shared state, permissions, external tools, or neighboring workflows. The larger and more coupled the surface, the more valuable it is to split the work into steps that can be checked independently.

This lab makes the tradeoff visible. Validation and rollback readiness create room to act. Surface size and coupling consume it. The score is a teaching device, not a project estimate; use it to ask which edge of the change deserves a boundary before the first mutation.
