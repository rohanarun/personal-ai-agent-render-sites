Confirmation timing

Ask for approval when it still changes the outcome.

A confirmation is useful only while a person can understand the choice and redirect the agent. Tune certainty, urgency, consequence, and review cost to see when an agent should pause, stage, or proceed with a narrow action.

Shape the moment

Higher urgency and consequence make late confirmation more dangerous. Higher review cost makes earlier, well-scoped checkpoints more valuable.
