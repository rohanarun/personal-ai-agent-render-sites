Markdown Outline Desk

How to review a draft's heading structure without scrolling through every paragraph. Extract an outline, inspect source locations, and hand off the review as JSON.

    An outline, not a rewrite

    An illustrative report moves from a title to methods and results. A jump from level 2 to level 4 may be worth reviewing, but it is not automatically invalid Markdown. This tool flags that jump and leaves the source untouched. A first heading below level 1 is also a review signal, not a rejected document.

    The bundled markdown-it 14.1.0 parser recognizes Markdown headings, including underlined Setext headings. Hash marks inside fenced code are not headings. Raw HTML heading tags are not included. Headings within a block quote or list can be included: this is the parser's document-order heading stream, not a claim that they form your main article outline.

    Display labels use inline text, code spans and image alt text; formatting markers are omitted. Source line spans are one-based and inclusive. The export includes the original Markdown for each heading as well as its plain label, level and review flag. No browser-specific anchor IDs are invented.

    Review before publishing

    Use the outline to ask whether each heading promises something the section actually delivers. A repeated label may be intentional, and a hierarchy flag may reflect quoted material. The parser cannot judge argument quality, factual correctness, accessibility conformance or editorial completeness.

    Input is limited to 100,000 characters and 200 extracted headings. Editing invalidates the old export. The draft is parsed locally without rendering its HTML, following links, loading its images or sending a model request. This page does not save drafts across reloads.
