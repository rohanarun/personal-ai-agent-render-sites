Freshness is a filter

Which documents could enter an assistant's context? Inspect five synthetic records against a fixed clock and a visible date rule.

Query: “What is the return window?” Clock: 2026-09-08 00:00 UTC. All records below are fictional.

    Freshness does not establish truth

    Indexing time records when a system stored a document; publication time records when the document says it was issued. A recent indexing timestamp can admit old content. A narrow cutoff can also discard useful background or return nothing.

    This example selects candidates only. It does not rank relevance, resolve conflicting policies, check authority, or generate an answer. A date filter alone cannot do those jobs.

    Exact rule and edge cases

    Include records when cutoff ≤ selected timestamp ≤ clock, with both boundaries inclusive. Missing timestamps and future timestamps are excluded. Ages are whole UTC-day differences in this fixture. Production timestamps need explicit formats, provenance and timezone handling.

    Source: Elasticsearch range queries, including inclusive bounds and date fields. This browser exercise implements the same comparison on a small synthetic list.
