One decision changes what remains

Greedy visits agents A, B, then C and takes each agent's cheapest unused task. In the reset example, A takes task 1 for 1 unit. B is left paying 9. Giving A task 2 instead costs one extra unit, but frees task 1 for B. The complete cost drops from 12 to 6.

The objective is to minimize the sum of the three selected costs, subject to one selection in every row and column. The bundled Hungarian solver searches for a global optimum of this assignment problem. Multiple allocations can tie: gold marks one optimum, not necessarily the only one.

What an agent scheduler still needs

This is a deterministic, one-shot allocation model. It does not execute agents or estimate costs. Dependencies, multiple tasks per agent, uncertain outcomes, deadlines, and changing availability require additional modeling; the cheapest plan here is not a guarantee of a successful real workflow.
