False means zero, not before

The boolean callback returns 1 or 0 after numeric conversion. For distinct priorities, one direction says after while the reverse says equal. That breaks sign consistency. A malformed comparator has no portable sorting outcome; the result above is an observation from this browser, not a promised failure pattern.

The numeric callback supplies negative, zero and positive results. The constant-zero callback is consistent too, but treats all entries as tied. A valid comparison contract is not the same as meeting your application's ascending-priority goal.

A small witness, not a general proof

This table checks sign reversal only on the supplied values, including self-pairs and repeated values. It does not certify arbitrary callbacks, transitivity or freedom from side effects. No user-provided code is evaluated. The three functions are fixed experiment choices.

Each run sorts a new copy; reversing changes the input for the next observation. Priorities are restricted to integers from -999 through 999. Equal-priority jobs need a separate product policy, and priority scores themselves are not evidence of usefulness or safety.
