Size selects the traversal

For ordinary Sets, intersection iterates the smaller operand. When sizes tie, it iterates the receiver. Both calls find common members, but their iteration order can differ. This lab invokes the native method; it does not substitute a polyfill.

In the presets, adding unrelated labels to B changes its size while the shared jobs remain review and send. The two-entry B places send first. At equal size, A.intersection(B) follows A and places review first. B.intersection(A) follows B in that tie. At four B entries, A is smaller for both calls.

Make the scheduling rule explicit

The third strip walks A's insertion order and retains members of B. It is appropriate only when A really is the chosen priority order. It is not a sort by score, a fairness policy or a permission check.

Inputs contain zero to eight nonempty strings, at most 32 characters each. Native Set construction removes exact duplicates and preserves first insertion order. Labels are case-sensitive and are not trimmed. This is a string-only example, not object-identity matching. An empty intersection is a valid result.

Editing pauses export until a new comparison succeeds. Presets replace both inputs. The export records normalized Set contents and all three output sequences. No jobs execute and no model or network tool is called.
