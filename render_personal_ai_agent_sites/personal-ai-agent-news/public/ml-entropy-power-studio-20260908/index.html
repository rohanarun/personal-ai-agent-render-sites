Shape mismatch creates slack

For independent random vectors, entropy power of the sum is at least the sum of entropy powers. For nonsingular Gaussian inputs, equality holds exactly when their covariance matrices are proportional.

A = diag(2, 0.5)
B = s R(angle) diag(b, 1/b) R(angle)T
C = A + B
h = ln(2 pi e) + 0.5 ln det(C)
N = exp(h) / (2 pi e) = sqrt(det(C))

These last two formulas are for two-dimensional Gaussians. Here N(X) = 1 and N(Y) = s, so rotation cannot change the lower bound 1 + s. Independence is essential: correlated inputs need cross-covariance terms in C.

This is an exact Gaussian calculation, not a density estimate or a proof for all distributions. Matrix products, determinants, and contour eigendecompositions use ml-matrix. Entropy is measured in nats; entropy power has squared-coordinate units.
