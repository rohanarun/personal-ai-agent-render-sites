Posterior vectors follow input order 1, 2, 3. An impossible output has undefined posteriors and contributes zero to the weighted remainder. This family gives P and Q the same support.

A chain-rule accounting identity

D(PX ‖ QX) = D(PY ‖ QY)
+ Σᵧ PY(y) D(PX|y ‖ QX|y)

Construct two joint distributions using the same K: P(x,y)=P(x)K(y|x), Q(x,y)=Q(x)K(y|x). Their joint KL equals the input KL because the channel factors cancel wherever mass is nonzero. Applying the KL chain rule in the other direction gives the displayed identity.

The conditional terms are nonnegative, proving data processing. Equality requires matching posteriors for every output with positive P probability. When every row of K is identical, the output ignores X and its KL is zero.

This is why a shared noisy representation cannot create distinguishability between two distributions. The claim requires the same channel; applying different transformations is a different experiment.
