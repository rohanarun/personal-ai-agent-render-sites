Global balance permits circulation

Stationarity requires each state's total incoming probability to equal its total outgoing probability. It does not require balance on each edge. In this example, the same current passes around all three edges, so no state accumulates probability even when the cycle is directional.

Changing the bias leaves the row-weight totals unchanged: A has total 2+d and B and C each have total 3. The stationary distribution is therefore ((2+d), 3, 3) divided by (8+d), independent of bias. In contrast, the signed cycle current is 2b/(8+d). The explorer verifies both by solving the stationary equations.

Two different reversals

Reversing the displayed path while keeping P asks whether that reversed history is equally likely in the original process. It need not be. A stationary path probability includes pi at its first state, multiplied by its transition probabilities; ignoring that initial factor can give the wrong comparison.

The time-reversed rule is P*[i,j] = pi[j] P[j,i] / pi[i]. Under P*, the reversed history has the same probability as the forward history under P. Detailed balance is the special case P* = P, equivalently zero current on every pair.

What this means for sampling

Detailed balance is a sufficient construction principle for a sampler to preserve a target distribution, but stationarity does not require it. This finite example separates distribution preservation from path symmetry; it does not compare mixing speed, establish independence of samples, or model whether a real agent action can be undone.

Aldous and Fill, Reversible Markov Chains, section 3.1 defines detailed balance and the stationary time-reversed chain. The biased weighted triangle and its current formula are worked examples.
