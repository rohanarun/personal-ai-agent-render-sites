A denser grid is not a longer recording

The complex tone is x[n] = exp(i(2 pi f n / 64 + phase)). Its real and imaginary parts are cosine and sine. A rectangular window uses w[n] = 1; the periodic Hann uses w[n] = (1 - cos(2 pi n / 64)) / 2.

Each displayed amplitude is |FFT(w x)[k]| / sum(w). At the exact tone frequency this normalization gives one. An off-grid peak can be sampled below one. Changing phase rotates the complex spectrum without changing its magnitude.

A Hann window suppresses distant sidelobes while widening the main lobe. On the original grid, an integer-frequency rectangular tone occupies one bin; the periodic Hann distributes it over that bin and its two neighbors.

Zero-padding evaluates the same finite-record spectrum at more frequencies. It preserves the original bin values and adds no observations or narrower window lobes. Lines between FFT samples are visual guides, not additional measurements.

Parseval checks sum(|w x| squared) = sum(|FFT(w x)| squared) / FFT length. The dB floor affects only the drawing. This is a noiseless single-tone experiment, not a frequency-confidence estimator.
