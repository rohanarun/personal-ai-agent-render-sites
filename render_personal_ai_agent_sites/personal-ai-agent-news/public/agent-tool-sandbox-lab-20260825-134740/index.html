A useful mental model

Capability is not permission.

A tool schema says what a connector can do. It does not decide whether this request is allowed. The agent should keep capability, scope, approval, and side-effect risk separate.

Declare

Make the tool and its side effects visible before planning the call.

Constrain

Keep arguments within the smallest scope that can complete the request.

Confirm or refuse

When the call changes the world, a clear approval boundary is part of the action. If the capability or scope does not fit, refusal protects the user better than improvisation.
