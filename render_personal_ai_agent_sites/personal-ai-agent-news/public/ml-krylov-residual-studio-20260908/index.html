Use everything the matrix has revealed so far

The Krylov space K_k(A, b) is the span of b, Ab, through A to the power k-1 times b. Here the initial guess is zero. The selected approximation minimizes the Euclidean residual norm ||Ax - b|| over that space. It is a small dense demonstration of the minimum-residual idea, not a production GMRES implementation.

The spaces are nested, so the best residual cannot increase in exact arithmetic when k grows. A new power can be redundant: if b is an eigenvector, every power is a multiple of b. For this nonsingular diagonal example, one search direction then already contains the exact solution.

Eigenvalues matter only where b has support

A is diagonal with entries 1, 2, the adjustable value, and 4. All are positive, so the exact solution is simply b divided coordinatewise by those entries. With all coordinates active and four distinct entries, up to four independent powers are available. Matching the third entry to another merges a spectral value and reduces the needed dimension.

With only the first and fourth coordinates active, the middle entries do not affect this solve. Changing an unexcited eigenvalue therefore changes the matrix without changing the displayed residual curve. This is a controlled example, not a claim that eigenvalues alone determine every iterative solver's behavior.

Separate the space from its numerical representation

Raw powers can become nearly parallel. This studio extracts an orthonormal basis Q using ml-matrix SVD, retaining singular values above 1e-10 times the largest. It then solves the reduced least-squares problem for AQ using a pseudoinverse and returns Q times that solution. Production methods usually build an orthonormal basis incrementally, for example with Arnoldi.

The rank threshold is a numerical convention, not a learned decision. The chart uses a linear residual scale and reports tiny residuals numerically. This four-dimensional synthetic system illustrates linear algebra used inside learning algorithms; it contains no training data or model-quality benchmark.
