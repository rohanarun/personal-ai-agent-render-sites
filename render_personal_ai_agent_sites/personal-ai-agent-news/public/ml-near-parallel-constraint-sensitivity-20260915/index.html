Numerical linear algebra / Model fitting

A small residual can hide a large parameter error

Nearly parallel constraints leave one direction weakly determined. A tiny change in a measurement can move their intersection a long way, even when the new equations are solved almost perfectly.

This is a data-sensitivity problem, not necessarily a bad solver. The experiment below makes the distinction visible with three measurement planes and an SVD-based linear solve.

Move the measurement, watch the fit

The reference parameter vector is w = (0.4, 0.4, 0.1). Only the second measurement receives an offset. The angle changes the relationship between the first two constraints; every angle has fresh noiseless measurements generated from the same reference.

The exact calculation
Let c = cos(angle) and s = sin(angle). The matrix and noiseless right-hand side are:
A = [ 1  0  0 ]     b = [ 0.4          ]
    [ c  s  0 ]         [ 0.4c + 0.4s ]
    [ 0  0  1 ]         [ 0.1          ]

A w = b
A w_hat = b + [0, offset, 0]
The first and third equations fix w_hat1 = 0.4 and w_hat3 = 0.1. Substituting into the second gives an exact expression for the remaining coordinate:
w_hat2 = 0.4 + offset / sin(angle)

Parameter error = ||w_hat - w||2
                = |offset| / sin(angle)
This identity is an independent check on the library solve. At 90 degrees, the error equals the offset magnitude. At 5 degrees, the same offset is amplified by about 11.47. With offset 0.05, the parameter error is about 0.574, even though the noisy-data residual remains close to floating-point precision.
Try the controlled comparison: reset, choose 90-degree constraints, then 5-degree constraints. The offset stays at 0.05. Finally choose Zero offset: both solutions coincide despite the matrix remaining poorly conditioned. Sensitivity describes what could happen under perturbation, not an error that must exist.


Condition number is a bound, not this observed gain
For an invertible matrix, the 2-norm condition number is the largest singular value divided by the smallest. NumPy's condition-number documentation describes the norm-based definition and SVD computation.
For this matrix, the singular values are sqrt(1+c), 1 and sqrt(1-c). Thus the condition number is cot(angle/2). The largest singular value describes a strongly measured direction; the smallest describes a weakly measured direction.
kappa2(A) = sqrt((1+c)/(1-c)) = cot(angle/2)

||delta w||2 / ||w||2
    <= kappa2(A) * ||delta b||2 / ||b||2
The inequality follows from delta w = inverse(A) delta b and ||b||2 <= ||A||2 ||w||2, with A fixed and nonzero b and w. It bounds relative changes. Our displayed gain 1/sin(angle) instead measures an absolute change for one particular perturbation direction: only the second measurement changes. These numbers are not supposed to be equal.
The condition number depends on scaling and units. Here all three rows have unit length, so reducing the angle isolates near-redundancy rather than simply shrinking a row. At zero degrees the matrix would be singular: the first two equations would no longer determine the second parameter. The slider deliberately excludes that case.


Why a tiny training residual is not enough
Think of the rows as three linear observations of a parameter vector. The perturbed observations can still be fitted exactly, because the system is square and invertible. The resulting parameters nevertheless differ from the reference that generated the clean data.
This illustrates one reason that fitting observed data closely does not by itself establish parameter accuracy. It does not simulate generalization on a real dataset, estimate a noise distribution or prove that a particular trained model is unstable. The reference is known here only because we constructed the example.
It also separates two errors: measurement perturbation, which we intentionally add, and numerical error from solving the resulting system. LAPACK's error-analysis discussion explains why residual, backward error and forward error are different quantities. Our experiment uses an SVD solve from ml-matrix, not a hand-written matrix inverse.
What can help?
  • Collect independent information. A new measurement aligned with the weak direction can distinguish parameters that the near-parallel rows barely separate.
  • Check scale and units. A large condition number can reflect representation choices as well as structural redundancy.
  • Consider regularization deliberately. It can trade sensitivity for bias; it changes the estimation problem rather than magically restoring missing information.
  • Report more than residual. Inspect conditioning and perturbation sensitivity alongside the fit. A stable numerical method cannot make uncertain input exact.
