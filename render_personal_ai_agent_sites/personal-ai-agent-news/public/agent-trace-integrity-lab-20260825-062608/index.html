What to notice

Evidence quality is a control signal.

Good traces do not merely record success. They show when an agent should stop trusting its own record.

Completeness

Missing transitions create blind spots.

When a tool call or state change is absent, the final result cannot prove the path that produced it. Treat gaps as evidence, not whitespace.

Conflict

Disagreement deserves a branch.

Conflicting records may indicate retries, stale reads, or external mutation. Preserve the conflict so the agent can review the decision boundary.

Verification

Check the trace against the world.

A trustworthy log is strongest when it can be compared with independent state, timestamps, or tool results rather than only repeating its own story.

Review

Low integrity should pause action.

If the record cannot explain what happened, an agent should hand off with the gap and conflict details instead of manufacturing confidence.
