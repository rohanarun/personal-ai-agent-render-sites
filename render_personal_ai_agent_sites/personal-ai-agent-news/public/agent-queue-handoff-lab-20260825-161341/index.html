A work ownership simulator

Passing work is not passing responsibility.

When one agent hands a pending task to another, the queue must preserve who owns it, whether it may run twice, and how fresh the decision still is. Tune the handoff and see when the work is safe to resume.

Continuity is a data contract.

A queue handoff is safe when the next worker inherits the same intent, state, and duplicate boundary. Otherwise “resume” is just another way to start over.

Keep one work identity

Use a stable job or idempotency identity so every worker can tell continuation from a new request.

Transfer the checkpoint

Record what was attempted, what was not attempted, and which evidence the next worker may trust.

Make expiry explicit

When ownership expires, re-claiming should be a deliberate recovery path with a visible boundary, not a silent race.
