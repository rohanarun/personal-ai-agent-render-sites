Healthy checkpoints

The best recovery move is often a short question, asked before the expensive action.

Compare to the outcome

Measure the current subtask against the user’s desired result, not only against the previous tool call.

Expose the changed assumption

Name what moved: scope, evidence, time, or authorization. Hidden drift is hard to correct.

Pause before commitment

For a high-impact action, ask for confirmation when alignment is low instead of burying the mismatch in a long plan.

This simulation is a teaching model, not a production planner. It demonstrates a contract-first pattern: compare the current state with the goal, expose drift, and gate consequential actions.
