CSV append desk

Combine two research tables without duplicating the header or silently shifting a column. This desk appends rows; it does not join records by an identifier.

Export preview

One header, explicit row policy
The illustrative tables contain public-style reading notes with a quoted comma. Both headers must match in spelling, whitespace and order. Empty or duplicate header names are rejected. Every record must contain the header's number of fields. The desk does not guess a mapping when the shapes disagree.
Rows from the first table precede rows from the second. With duplicate removal off, all data rows remain. With it on, the first occurrence of each exact parsed row is retained across both tables. Equal identifiers with different other fields are not duplicates. Whether repeated observations should be removed is your research decision, not evidence inferred by this tool.
Cells remain strings, so leading zeros are not converted into numbers here. Parsing uses commas and skips empty records. Output is regenerated CSV, not original bytes: quoting and line endings can change. Papa Parse's formula escaping is always enabled for export; cells beginning with its formula-trigger characters receive an apostrophe. The preview shows the actual export, including these changes. Review the result before opening in a spreadsheet; this is not a universal safety guarantee.
Each pasted table is limited to 100,000 characters. The preview shows the first 12,000 output characters; download retains the full result. Input changes clear the previous result. Use illustrative rather than sensitive records. The append code runs locally, while the video below loads from an external host. Reload clears the working tables.
