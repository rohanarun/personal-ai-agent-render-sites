What the simulation teaches

A precondition connects evidence to action. It says what must still be true when the agent commits, not merely what was true when planning began.

A useful design move

Place a cheap, explicit state check immediately before high-impact actions. If it fails, narrow the plan or ask for a fresh decision instead of silently proceeding.
