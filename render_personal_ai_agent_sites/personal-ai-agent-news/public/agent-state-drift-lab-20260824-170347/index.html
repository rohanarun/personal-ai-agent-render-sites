State needs a return path to intent.

Run a scenario to see how working state can outgrow the task contract. A checkpoint is a chance to reconcile what changed, why it changed, and whether it is still allowed.

  • Mutation is not failure: untracked mutation is what creates hidden divergence.
  • Checkpoints should compare current state to the original goal, not merely confirm that the process is alive.
  • When drift exceeds tolerance, reconcile or pause before using the state to make a consequential decision.
