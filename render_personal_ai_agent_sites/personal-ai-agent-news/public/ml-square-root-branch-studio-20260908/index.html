The principal root is a choice with a guarantee

A square root satisfies X times X = A, not entrywise squaring. For this symmetric positive definite A, the unique symmetric positive definite root uses positive square roots of its eigenvalues.

A = Q diag(4, lambda) Q transpose
X = Q diag(sign1 * 2, sign2 * sqrt(lambda)) Q transpose
X squared = A

With distinct eigenvalues, the four sign choices give four roots. When both eigenvalues equal 4, infinitely many roots exist; these controls show only the branches in the selected orthonormal basis. Mixed signs can then change X as the basis rotates, even though A remains 4 I.

ml-matrix performs the matrix products and residual calculation. The chosen orthonormal eigenbasis is explicit, keeping branch identities stable at repeated eigenvalues. This is matrix multiplication, not a Cholesky factor convention.
