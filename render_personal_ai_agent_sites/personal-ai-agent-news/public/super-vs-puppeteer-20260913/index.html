What the computer-use cache actually stores
The inspected Super server code has a verified-workflow store and a lookup path. Storage requires verified-complete confirmation and a workflow with runnable Python steps. A hit returns the workflow, verification reason, output evidence, and helper-version hash. This is executable workflow reuse, not merely reusing a chat answer.
Lookup can return a miss for missing task input, an empty cache, or no safe match. A miss provides no cached workflow; fresh execution would need another path. The inspected endpoint alone does not demonstrate that fallback completing. Matching can incur captured model usage charges.
Reusing a verified procedure can avoid recreating that procedure. That is an architectural benefit, not a measured speed or cost result here. Source inspection does not prove cache availability for your account, task, or app. No universal compatibility or zero-cost promise is made.
