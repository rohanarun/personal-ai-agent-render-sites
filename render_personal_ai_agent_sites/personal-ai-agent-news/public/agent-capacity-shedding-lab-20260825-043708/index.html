Protect the useful work

A capacity policy should preserve important work and make rejected or delayed work observable.

Continue when stable

Accept normal flow when downstream headroom can absorb it without turning latency into hidden queue growth.

Shed with intent

Delay or reject low-value work when pressure rises, and record the reason so the system can recover honestly.

Admit the narrow slice

When capacity is scarce, preserve high-value tasks and make the remaining work wait for a clear retry window.

This simulation is a teaching model, not a production capacity policy. It demonstrates a contract-first pattern: measure pressure, protect headroom, and preserve value deliberately.
