f(u,z) = (a/2)u2 + u bTz + (1/2)zTCz - hu - gTz
u*(z) = (h - bTz)/a
f(u,z) = f(u*(z),z) + (a/2)(u - u*)2
Setting the derivative in u to zero gives its best value for each z. Substitution produces S = C - bbT/a and reduced force q = g - bh/a. Solve Sz* = q, then recover u*. Solving Cz = g instead imposes u = 0; it solves a different constrained problem.
minu f(u,z) = (1/2)zTSz - qTz - h2/(2a)
A controlled coupling experiment
Here a = 2, C = diag(1,2), g = [0.2,-0.2], and b = sqrt(2) rho [cos(phi),sin(phi)]. Therefore S = C - rho2vvT. Its smallest eigenvalue is at least 1 - rho2 > 0 over the allowed range. The full Hessian is positive definite, so both minima are unique.
With no coupling, S equals C and the remaining-coordinate optimum agrees with the fixed-u optimum. A nonzero hidden force still lowers the minimized objective by h2/(2a). This is partial optimization, not integration over a probability distribution.
The orange point is shared by both plots. Contour lines use the same absolute objective levels: the reduced global minimum plus 0.2, 0.5, 1, 2, 4, 8, 16 and 32. The displayed window is z in [-4,4]2; contours are clipped to it. Linear solves and eigendecompositions use ml-matrix.
