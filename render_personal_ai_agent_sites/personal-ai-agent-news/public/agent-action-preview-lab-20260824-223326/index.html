What to notice

Fidelity beats ceremony.
A preview that omits the destructive detail can create false reassurance instead of informed consent.
Attention is a resource.
Users need a clear moment to inspect what will happen before a click becomes an irreversible event.
Impact sets the standard.
High-impact actions need richer previews and stronger cancellation than low-impact ones.
