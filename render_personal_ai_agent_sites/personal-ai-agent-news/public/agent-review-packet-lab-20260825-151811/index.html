Review is a communication protocol.

A review packet is not a decorative summary. It is the smallest shared object that lets a human understand what the agent saw, what it inferred, what it wants to do, and how to undo it.

This is a compact teaching model. Production systems still need provenance, explicit permissions, audit logs, and human review for consequential work.
