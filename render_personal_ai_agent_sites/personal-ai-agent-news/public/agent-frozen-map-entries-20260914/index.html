A Frozen Map Still Accepts Entries

An illustrative agent job registry stores string statuses in a Map. Freeze the Map, then try changing an entry and an ordinary property. No nested objects are involved.

Registry mutations

Changing this setting creates a fresh registry. All operations execute in strict mode.

registry = new Map([['job-a', 'queued']]);
registry.label = 'draft';
Object.freeze(registry); // when selected

    Frozen does not mean every kind of state is immutable
    Object.isFrozen(registry) can remain true while registry.size and its entries change. The ordinary label property stays protected. This is a difference between property integrity and Map entry storage, not a failure to freeze a nested value.
    Two write paths, two outcomes
    Object.freeze makes existing own data properties non-writable and non-configurable, and prevents new own properties. In this strict-mode example, assigning a new label throws TypeError when frozen. Map.set, Map.delete and Map.clear operate on the Map's internal entry list instead. Freezing the object does not disable these methods.
    Successful call or changed state?
    Setting job-a to done twice completes both times, but the second call changes no value. Deleting a missing key returns false. Clearing an empty Map also completes without changing its entries. The experiment reports both the native return value and whether its before/after snapshot differs; those are not interchangeable claims.
    A job registry is not a permission boundary
    Illustrative scenario: an orchestrator shares this registry with a helper and assumes Object.isFrozen proves the job statuses cannot change. A helper holding the Map can still use its entry methods. Decide which state must be immutable before choosing a representation. For this narrow string-to-string example, a frozen plain data record could protect its own values; it is not a universal Map replacement and has different key semantics.
    Another design is to keep a mutable Map private and expose only the reads consumers need. Merely freezing the same Map or omitting a mutation button from an interface is not that separation. This page demonstrates JavaScript semantics, not sandboxing, authorization or concurrent execution.
