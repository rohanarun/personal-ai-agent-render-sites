A summary is a control surface.

Run a scenario to see how context loss compounds. A useful summary preserves goals, constraints, and evidence; a merely shorter one can make the next action look safer than it is.

  • Compression pressure is not neutral when the removed detail changes what an action means.
  • Recall checks are checkpoints for freshness, not a rewind button.
  • When critical context is missing, retrieve it or defer instead of guessing.
