You cannot debug an invisible decision.

When an agent makes a mistake, the most useful question is often not “why did the model fail?” but “which part of the path could nobody see?” Missing tool inputs, hidden retries, and unrecorded state changes turn recovery into guesswork. Observability gives the system a chance to notice what it is doing while it is doing it.

This lab makes that tradeoff visible. Trace coverage and signal quality create visibility. Sensitive actions consume it because unseen errors are more expensive. A latency budget creates room to add a check, but urgency can make instrumentation feel optional. The score is a teaching device, not a monitoring SLA.
