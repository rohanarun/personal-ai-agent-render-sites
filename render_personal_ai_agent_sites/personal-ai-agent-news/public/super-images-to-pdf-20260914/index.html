How to turn images into a PDF without a document editor

One image per A4 portrait page, in the order you choose. A useful handoff for sketches, project snapshots or an illustrated brief. The sample pages below are artificial examples.

Up to 8 images; 8 MiB each and 16 megapixels each. Images are normalized to PNG on white, with a maximum 2,400-pixel long edge. No OCR or searchable text layer.

Keep the document honest

This is a new PDF made from image pixels, not an archival conversion of an original document. It does not preserve editable text, source metadata, signatures or forms. Transparent areas become white, large images are downsampled, and the browser's image decoding determines orientation and color rendering.

Before sharing, inspect the first and last page and any small text at full size. A correct page count is not proof of legibility. Keep the source images when resolution matters. Do not use an image-only export when the recipient needs selectable text or accessible document structure.

Each image fits inside 24-point margins without cropping. Blank space is expected when its aspect ratio differs from an A4 page. Reordering changes only this export, not your original files.

Implementation and limits

PDF creation uses the locally bundled pdf-lib version 1.17.1 with its license. PNG/JPEG decoding and resizing use browser APIs. Failed additions leave the existing page list intact. No content-generation API is used. Reloading clears this session's pages.
