What to notice

Alignment is a moving state.

An agent should preserve the user's goal, not merely preserve its first plan.

Drift

Context can change the meaning.

New messages, tool results, constraints, or timing can make a once-reasonable plan diverge from the intended outcome.

Impact

High-cost actions deserve a pause.

When an action is hard to undo, the agent should spend more effort confirming that the current plan still serves the user's goal.

Confirmation

Ask a focused question.

A good clarification preserves momentum by asking about the one ambiguity that changes the action, rather than restarting the entire task.

Handoff

Uncertainty can be the correct output.

If the agent cannot resolve drift safely, hand off with a compact explanation of the goal, the changed context, and the decision waiting.
