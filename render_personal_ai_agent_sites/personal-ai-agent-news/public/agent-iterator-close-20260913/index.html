The generator under test

function* work() {
  try {
    yield 'inspect';
    yield 'plan';
    yield 'report';
  } finally {
    trace.push('finally: cleanup ran');
  }
}

The finally block logs cleanup; it does not actually release a browser, file, or network connection. In production, put the appropriate resource-release operation there and test its failure behavior.

Three different exits

Early break: leaving this for...of loop invokes the generator's return method through iterator closing. The finally block runs, and the next call is done.

Manual pause: calling next once and then doing nothing leaves this generator suspended. No cleanup log appears until it is resumed to completion or explicitly closed. Merely abandoning consumption is not a reliable cleanup strategy.

Full consumption: all three values are yielded; advancing past the last yield reaches finally and completes naturally. This example's explicit return closes after the first value instead.

These outcomes concern this synchronous generator. They do not cancel remote jobs, establish async-stream shutdown, or cover generators that yield inside finally. Agent orchestration needs a separate cancellation and resource-ownership contract at those boundaries.

Carry the invariant into an agent

When taking only the first result from a resource-backed producer, decide who closes it. Record both the last consumed item and the cleanup acknowledgement. A missing next call is not that acknowledgement.
