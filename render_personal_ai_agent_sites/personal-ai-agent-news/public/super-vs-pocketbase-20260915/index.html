Choose by the job, not a universal winner
PocketBase
A self-contained backend with an embedded database, authentication, files, a dashboard and APIs. It fits a developer building an application around stored records. Go and JavaScript hooks support custom logic. You still build the frontend and operate the deployment.
Product overview
Super Powers AI
An assistant with cloud apps, browsers and sandboxes. It fits a person delegating a task and reviewing the outcome. That is not evidence that Super replaces a database's schema, access rules, migrations or recovery plan.
Product overview and current plans
Deployment and cost
PocketBase's own FAQ says it is self-hosted only: the project does not provide hosting. It is a volunteer open-source project; budget for your server, backups and maintenance rather than treating software access as a zero-cost deployment. Its FAQ describes single-server vertical scaling and embedded SQLite, not an interchangeable managed database service.
Super lists pay-as-you-go wallet usage, plus optional 10-device and 100-device plans at $199 and $999 per month. These are device plans, not comparable database hosting tiers. No workload-normalized price or performance test is claimed here.

What the real realtime API adds
PocketBase documents SSE connections and subscriptions to a record or a collection, with create, update and delete events. Record subscriptions use ViewRule; collection subscriptions use ListRule to determine access. Our local demonstration omits authentication, transport, reconnection, deletion and access enforcement. A connected checkbox is not a security mechanism.
PocketBase realtime reference
Reusable execution is a different layer
Super's public cache release describes reusing successful responses for exact repeated requests. Misses go to the upstream provider. A hit avoids another upstream model call, but execution and infrastructure costs can remain.
The separately inspected workflow-cache route requires task context and verified-complete runnable steps for storage. Lookup may return a workflow, helper version and output evidence, or a miss when context is missing or no safe match exists. The caller must handle that miss; matching itself may incur usage. This implementation is not proof of live eligibility for your account, a PocketBase integration or measured savings.
For an app backend, start with PocketBase's documentation and a deployment plan. For delegated work, describe the task to Super and specify what evidence you will review.
