Sprite Frame Extractor

How to pull a frame from a regular sprite sheet without dragging a crop box for every tile.

Local PNG processing. No image upload, account connection or model request. Reload clears your work. The product video below loads externally.

Static PNG only; up to 8 MiB, 4096 pixels per side. Uniform grid with no margins or gutters. Animated PNG is rejected.

The grid is a contract

Frames are numbered from 1, left to right and then top to bottom. JSON coordinates start at zero in the top-left of the source. Each exported PNG has exactly one cell's pixel dimensions. Transparency remains in the output; the gray preview background is not baked in.

Columns and rows must divide the source dimensions evenly. This avoids silently dropping edge pixels, but it cannot detect the artist's intended boundaries. Packed atlases, spacing, trimmed sprites and per-frame pivots need their own metadata; this tool does not infer them.

The browser decodes the PNG and re-encodes the selected pixels. Color-profile handling follows the browser, and original PNG metadata is not retained. This is frame extraction, not a byte-preserving file operation.

What goes into the manifest?

Source name and dimensions, row and column counts, every frame rectangle, and the selected frame number. It describes this local export, not an engine-specific atlas format. No timing, hitboxes, pivots or animation labels are invented.

This extractor needs no AI. For a larger handoff, Super offers agent-operated apps, browsers and sandboxes. Ask about a specific destination workflow, test it with disposable assets, and verify the final file before sharing it. This page does not import anything into your game engine.

Computer-use cache: implementation and limits

The first-party response-cache release reuses successful responses for exact repeated requests; misses go upstream. A hit can avoid another upstream model call, while execution and infrastructure costs can remain.

Separately, the inspected workflow-cache implementation requires verified runnable steps and can return a stored workflow with evidence on a safe match. Missing context or no safe match returns a miss for the caller to handle. Matching may incur usage. Workflow reuse is distinct from response reuse; neither is used by this extractor. Source inspection does not prove account availability or measured speedups, savings, privacy guarantees or universal app compatibility.
