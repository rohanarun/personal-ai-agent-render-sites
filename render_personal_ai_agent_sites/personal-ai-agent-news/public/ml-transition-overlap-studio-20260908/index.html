The least overlap sets the limit

Total variation is TV(μ, ν) = ½Σ|μᵢ − νᵢ|. For a row-stochastic P, Dobrushin’s coefficient is δ(P) = ½ maxᵢⱼ Σₖ|Pᵢₖ − Pⱼₖ| = 1 − minᵢⱼ Σₖ min(Pᵢₖ, Pⱼₖ). It satisfies TV(μP, νP) ≤ δ(P) TV(μ, ν).

Starting from point masses on a maximizing row pair attains the one-step ratio. Iterating gives the rose bound. Computing the coefficient of Pᵗ gives the gold bound, which is never worse; neither must equal the actual distance for your chosen pair at later times.

One is not a verdict

The delayed-overlap example has disjoint rows when ε = 0, so δ(P) = 1. Its one-step bound proves no strict contraction. Yet longer paths can overlap, and δ(Pᵗ) becomes smaller than one. A coefficient of one does not by itself prove that a chain fails to mix.

The refresh model is P = (1 − ε)B + ε11ᵀ/3. Shared uniform mass cancels in row differences, giving δ(P) = (1 − ε)δ(B). At ε = 1 every row agrees, so all initial distributions coincide after one transition.

This finite-state example illustrates loss of initialization information in stochastic systems. It is not an empirical MCMC convergence diagnostic. Matrix powers use ml-matrix; all displayed values are floating-point calculations.
