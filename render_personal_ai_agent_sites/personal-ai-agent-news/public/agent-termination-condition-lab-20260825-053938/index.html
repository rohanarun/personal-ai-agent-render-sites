Stop and report

The task is far enough along and the next step adds little value. Return a clear result and name what remains uncertain.

Loops need exit criteria

Without a bounded stopping rule, an agent can turn caution into endless checking. Define what “enough evidence” means before the loop begins.

Progress is not completion

A task can be close to done while still missing one consequential check. Let marginal value and risk decide the last step, not elapsed effort alone.
