ISBN Handoff

How to prepare an identifier list without confusing ISBN-10 and ISBN-13 repeats. A local review desk for librarians and book-club organizers, not a catalog search or an inventory system.

Up to 50 lines and 5,000 characters. ASCII digits, spaces, hyphens, and a final X for ISBN-10. No titles, prefixes, or URLs.

Identifier equality is not copy equality

The illustrative list includes an ISBN-10 and its equivalent ISBN-13, another valid identifier, and an invalid entry. Equivalent identifiers are grouped by the library's normalized ISBN-13. Only the first occurrence enters the unique list; every submitted nonblank line remains in the audit with its original line number.

A repeated ISBN is not proof that two physical books are the same copy. A valid identifier is not proof of assignment, publication, title, edition availability, ownership, or stock. Verify bibliographic and holdings information in your authoritative catalog before changing records.

Validation boundary

This page applies a strict character/length check, then uses the pinned MIT-licensed isbn3 2.0.11 library for ISBN parsing and normalization. Spaces and hyphens are removed and x is uppercased before parsing. The tool does not silently remove arbitrary letters or repair failed check digits.

Library acceptance depends on its bundled range data as well as identifier structure. Rejected entries need review; this is not an authoritative registry lookup. No identifiers are sent to a model or catalog service by the tool code.

Export boundary

The text export contains unique accepted ISBN-13 values, in first-occurrence order, with one per line. Invalid inputs are excluded from that list but retained in the JSON audit. Changing input invalidates both exports until a fresh review. Neither download modifies a library catalog.
