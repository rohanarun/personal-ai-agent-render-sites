MixUp: between examples,
off the manifold.

A valid convex combination need not be a real observation. Watch a soft training target rise while its input travels through the interior of a circle.

WebGL is unavailable. The controls and exact numerical results below remain active.

Gray circle: possible original inputs. Blue A and pink B: training examples. Green: mixed input and target. Black: its input-plane projection. Vertical axis: target probability for class B, not a model prediction.

Two examples, one invented target

MixUp trains on convex combinations of pairs of inputs and their labels. The original paper motivates this as regularization toward simpler behavior between training examples. Here we isolate the construction, not train a network or reproduce the paper's benchmarks.

Assume the original inputs lie on a unit circle in two dimensions. Set A = (1, 0), with class-A label (1, 0). Set B = (cos θ, sin θ), with class-B label (0, 1). These are two assigned example labels, not a definition of the true class everywhere on the circle.

x(t) = (1 - t) A + t B
y(t) = (1 - t, t),   0 ≤ t ≤ 1

Our slider is the weight on B. Some descriptions call the weight on A lambda instead: the convention changes, not the operation. In a training pipeline the mixing weight is typically sampled; this experiment selects it directly. Input coordinates and label probabilities must use the same weight.

The scene adds a third coordinate, t, to show the class-B target. The green point therefore follows a straight segment in joint input-target space. Its black projection follows a chord in the input plane. The circle is only a geometric support assumption; it does not supply ground-truth labels for interior points.

Why the chord leaves the circle

Both endpoints have norm one and A dot B = cos θ. Expanding the squared norm gives an exact identity:

||x(t)||² = (1-t)² + t² + 2t(1-t) cos θ
= 1 - 2t(1-t)(1 - cos θ)

For distinct endpoints and 0 < t < 1, this is less than one. The mixed input lies inside the disk, off the assumed circle. Its Euclidean distance to the nearest point on that circle is 1 - ||x(t)||. At the origin, every circle point is equally near; the distance still equals one.

That departure is not automatically a defect. Synthetic examples deliberately impose behavior away from observed samples. The question is whether the imposed behavior is a useful inductive bias for your data and task, not whether the interpolation arithmetic is correct.

Three checks to try

  1. 120 degrees, halfway. The input is (0.25, 0.433013), radius 0.5, distance 0.5 and target (0.5, 0.5). A half-and-half label is a chosen training target, not measured uncertainty.
  2. 180 degrees, halfway. Opposite inputs cancel to the origin. The target is still (0.5, 0.5), but this input is as far from the circle as possible. The visual retains the vertical target even when the input vanishes.
  3. Either endpoint weight. At t = 0 or 1, the mixed sample returns to an original input, distance zero and a one-hot target. Endpoint separation does not change that invariant.

Soft labels change the loss, not reality

For a binary model predicting class-B probability p, the cross-entropy for the mixed target is -(1-t) log(1-p) - t log(p), with p strictly between zero and one. At t = 0.5, either confident extreme receives a large penalty. The target asks the model for balanced output at that synthetic input.

This does not mean the model must interpolate its predictions exactly, nor that the blend is semantically halfway between classes. A nonlinear network, finite data and optimization all matter. For images, blended pixels may not look like a natural image. For structured fields, mixing arbitrary numeric encodings can be meaningless.

Use validation on the original task to choose augmentation strength. Compare against a no-MixUp baseline with the same training budget, and inspect failures by class. This scene cannot estimate accuracy, calibration, robustness or the best mixing distribution. It also does not implement Manifold Mixup, which mixes hidden representations rather than these raw inputs.
