Momentum Can Oscillate Too

If momentum smooths gradients, why can adding it make an optimizer swing past the minimum?

A gradient plus a memory

Ordinary gradient descent uses only the current gradient. Heavy-ball momentum also retains the last displacement. In the convention used here:

xₖ₊₁ = xₖ − η∇F(xₖ) + β(xₖ − xₖ₋₁)

η is the learning rate; β controls how much previous motion survives. We initialize x₋₁ = x₀, so the first step has no inherited velocity. Setting β to zero gives gradient descent exactly. This is classical heavy-ball momentum, not Nesterov's look-ahead update, Adam, or a stochastic minibatch method.

The loss is F(x) = ½xᵀHx, with H = Q diag(1,12) Qᵀ and Q a 30° rotation. Its unique minimum is x = (0,0), and the initial point is (−1.5,1). The rotation makes the valley oblique but does not change its eigenvalues. Every displayed loss and iterate is calculated from this matrix, using ml-matrix for matrix operations and eigendecomposition.

Read the motion one direction at a time

Express the error in an eigenvector direction with curvature λ. The multidimensional update becomes a scalar recurrence:

zₖ₊₁ = (1 + β − ηλ)zₖ − βzₖ₋₁

The previous two states determine the next state. Searching for a solution proportional to rᵏ gives the characteristic equation r² − (1+β−ηλ)r + β = 0. The two roots describe the long-run behavior of this mode. Both must have magnitude below one for every initial state to decay. A root on the unit circle is a boundary, not strict convergence.

If the discriminant is negative, the roots are a complex-conjugate pair. Their magnitude is √β. Such a mode rotates in its position-and-velocity state while its envelope decays when β is below one. Oscillations can therefore be perfectly compatible with convergence. Real negative roots can also produce alternating signs. Complex roots are not the only way a trajectory can cross the minimum.

Three settings, three different stories

No memory: choose ηL = 1.5 and β = 0. Since L = 12, η = 0.125. The low-curvature factor is 0.875; the steep-direction factor is −0.5. One direction shrinks steadily and the other alternates. The loss still decreases at every step on this exact quadratic because each squared factor is below one.

Memory with oscillation: keep ηL = 1.5 and set β = 0.8. Both modes have complex roots with magnitude √0.8, about 0.8944. The trajectory converges, but stored motion can carry it uphill on individual steps. Scrub the iteration control or export the sequence and compare consecutive losses. Stability constrains the eventual behavior; it does not promise monotonic descent.

Too much step: set ηL = 3.8 with β = 0.8. The steep mode has polynomial r² + 2r + 0.8. Its roots are about −0.5528 and −1.4472. The second has magnitude greater than one, so a component grows while alternating. Increasing the number of iterations cannot repair those fixed settings.

The stability boundary is a joint condition

For this positive-definite quadratic, with 0 ≤ β < 1, each mode is strictly stable precisely when 0 < ηλ < 2(1+β). Because the largest curvature is L, the full system is stable when 0 < ηL < 2(1+β). The controls display ηL so the boundary is easy to test without mental unit conversion.

For β = 0.8, that upper boundary is 3.6. Compare 3.5, 3.6 and 3.7. At 3.6 the steep mode has a root −1: it is not strictly stable. At 3.5 it eventually decays, potentially slowly; at 3.7 it grows. The table computes roots directly, and the classification treats floating-point values within 1e−9 of unit magnitude as boundary cases.

A larger admissible step range does not automatically mean a better convergence rate. For example, increasing β toward one increases √β for complex modes, slowing their asymptotic envelope decay. The best choice must account for both curvatures and transient behavior. This article intentionally exposes the trade-off instead of labeling a single preset “best.”

What to carry into real training

When loss rises after adding momentum, inspect the combination of learning rate, memory and curvature rather than assuming momentum always damps movement. Distinguish a finite transient from an unstable mode, and compare more than the final number from a short run. The mathematical table here can make that distinction because H is known and fixed.

Neural-network curvature changes during training; gradients can be noisy, saddles can have negative curvature, and adaptive optimizers introduce additional state. This quadratic is an exact experiment, not measured neural-network training or a universal hyperparameter recipe. The scene shows only coordinates within ±3 and loss below 60.
