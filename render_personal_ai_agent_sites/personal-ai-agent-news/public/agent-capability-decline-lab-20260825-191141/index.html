Make decline intentional

Capability reduction should be observable. Tell the user what the agent can still do, what it will not do, and what evidence would restore the wider action.

  • Move from execution to preview as uncertainty rises.
  • Use reversible drafts before irreversible side effects.
  • Restore capability only with a stated condition.

Try the trap

Raise reversibility while keeping consequence and uncertainty high. A recovery path helps, but it should not be used to justify an oversized action.

Reversible is not risk-freeA rollback path reduces harm; it does not erase the need for a bounded permission.
