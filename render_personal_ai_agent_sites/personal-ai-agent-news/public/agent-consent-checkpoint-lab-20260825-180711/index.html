Confirmation is a boundary.

A user can authorize an objective without authorizing every consequential step. Adjust user intent clarity, action consequence, scope match, and review time to see when an agent should ask before it acts.

Consent posture

Proceed without a new prompt

proceed = min(intent, consequence, scope, review)

Why the minimum?

Clear intent cannot erase a high-consequence side effect. A matching scope cannot replace a chance to review. The minimum makes confirmation predictable at the boundary where assistance becomes commitment.
