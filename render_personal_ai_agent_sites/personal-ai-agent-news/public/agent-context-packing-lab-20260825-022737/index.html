What the simulation teaches

Context management is a policy decision, not a storage detail. A useful agent preserves constraints, permissions, uncertainty, and the evidence that justifies its next action.

Replayable design question

When the tool output grows, should the agent compress it, ask for a narrower result, or pause and request human review? The best answer depends on what would be unsafe to lose.
