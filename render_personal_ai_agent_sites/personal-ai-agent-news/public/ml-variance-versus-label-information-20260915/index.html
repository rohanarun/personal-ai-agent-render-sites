High variance is not useful information

Can a one-number representation preserve almost all the variation in your data and lose everything needed to predict its label? Yes, if the variation is mostly irrelevant to the task.

Learn what PCA optimizes, distinguish reconstruction quality from predictive usefulness, and identify information that no downstream classifier can recover after it is discarded.

Predict which direction matters

The cloud has two equally common labels, teal and rose. Horizontal spread is a nuisance feature; vertical position carries the label. A third, small depth coordinate is also irrelevant. Before projecting, predict whether the longest direction will keep the colors distinguishable.

What survives in one coordinate?

Run the counterexample

  1. Start at s = 8 and use PCA. The first component is horizontal. It retains more than 95% of the variance. Press “Project points”: opposite-label points collapse onto the same x coordinates. Even the best threshold fits only 50%.
  2. Keep the label direction. At 90°, the retained coordinate is the vertical feature. The labels separate perfectly, although this direction retains only about 4% of the variance. Reconstruction gets worse while the label task gets easier.
  3. Rotate between them. An intermediate angle mixes signal with nuisance. Observe the overlap in the label strip, not just the cloud's apparent shape. The best threshold score measures one restricted classifier family; below-perfect threshold fit alone does not prove that all classifiers fail.
  4. Reduce nuisance half-width to 1, then recompute PCA. Vertical variance now dominates. PCA chooses the useful direction. The method did not become supervised; the data's scale changed which variation was largest.

At exactly the horizontal projection, the claim is stronger than “a linear classifier fails.” For every retained coordinate there are equally many examples of both labels. A classifier given only that coordinate must give the same answer to these indistinguishable inputs, so it cannot exceed 50% on this balanced empirical distribution.

A small dataset with no hidden randomness

There are 84 points: take every combination of 21 horizontal values, two labels and two depth values. The cloud is exactly centered by symmetry. No noise seed, fitting trick or train/test split is hidden.

x = s k / 10, k ∈ {−10, …, 10}
y ∈ {−1, +1}, label = y
z ∈ {−0.3, +0.3}
Every (k, y, z) combination appears once.

Because the coordinates vary independently in this full Cartesian grid, all cross-covariances are zero. Using the population normalization 1/N, the covariance matrix is diagonal:

C = diag((11/30)s², 1, 0.09)
At s = 8: C = diag(23.466667, 1, 0.09).

The first principal component maximizes uᵀCu over unit vectors u. We compute the covariance eigenvectors using ml-matrix and select the largest eigenvalue. For this dataset, the optimum switches between x and y when (11/30)s² crosses 1. At equality, the leading direction is not unique.

For the direction slider, u = (cos θ, sin θ, 0). A point p becomes the scalar t = uᵀp and reconstructs as p̂ = tu.

retained fraction = (uᵀCu) / trace(C)
mean squared reconstruction distance = trace(C) − uᵀCu

At s = 8, keeping x loses variance 1 + 0.09 = 1.09 but discards the entire label-bearing coordinate. Keeping y instead loses 23.466667 + 0.09 = 23.556667. Thus the direction that minimizes geometric reconstruction error is not the direction that best supports the task.

Two objectives, two different questions

ObjectiveQuestion it answers
PCA reconstructionWhich linear subspace preserves the greatest squared variation in these features?
Label predictionWhich retained information helps distinguish the outcomes we care about?

PCA never sees labels. Its objective can be appropriate for compression, visualization or denoising, but explained variance is not a certificate of downstream predictive quality. In an embedding pipeline, verify the task after dimensionality reduction rather than assuming that a large retained-variance percentage protects it.

Feature scaling is part of the modeling choice. Standardizing all three coordinates here gives equal variances and removes the unique dominant direction; it does not tell PCA which feature carries the label. A supervised representation method can use labels, but it must be fit and evaluated without leaking test labels.

How the threshold score is computed

We sort projected coordinates, group exact ties, and test each gap plus both constant-prediction extremes. For each split, we test both label orientations and report the greatest fraction correct on the same 84 points. Tied coordinates always receive the same prediction. This is an in-sample diagnostic, not cross-validated accuracy, a trained neural network, or a population performance estimate.

Limits of the lesson

The labels are deliberately encoded in one coordinate. Real tasks may depend on many directions, nonlinear combinations, noise and distribution shift. Arbitrary rotations can give nonlinear classifiers information that a single threshold cannot exploit. Only the exact x-axis collapse supports the stronger impossibility statement here. This example does not establish that PCA is generally harmful or that supervised compression always wins.

Practical takeaway: select a representation using the objective you actually need. Report reconstruction and task metrics separately, use held-out evaluation for real decisions, and inspect what information the compression removes.
