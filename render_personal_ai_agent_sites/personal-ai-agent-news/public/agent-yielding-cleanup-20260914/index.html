Cleanup can yield.

An agent work iterator is asked to stop. Its cleanup starts, pauses, and only finishes when the consumer resumes it. Observe the distinction in a real synchronous generator.

function* work() {
  try {
    yield 'work item';
  } finally {
    trace.push('cleanup started');
    yield 'cleanup checkpoint';
    trace.push('cleanup finished');
  }
}

A return request is not a completion receipt

Start the generator to reach its work item. The return request then enters finally, but that block contains another yield. The returned record has done: false and the value "cleanup checkpoint". Cleanup has started; the generator is still suspended.

Resume with next(). Cleanup finishes, and the pending return completes with the value "stopped" and done: true. One more next() returns done: true with an undefined value. The export explicitly labels undefined because JSON alone would omit that value field.

Why the consumer matters

The Generator.return documentation describes how a yield inside finally can interrupt a return. This fixture deliberately has one cleanup yield and no nested resource operations. It demonstrates a control-flow boundary, not a recommended resource-management pattern.

A consumer that stops after requesting return has not reached the final marker in this example. Code that equates "finally entered" with "cleanup completed" would overstate what occurred. For an agent wrapper, record an explicit completion observation for the resource you actually own.

Keep the scope precise

These local strings represent work and cleanup checkpoints; no remote task, browser action or file is running. Generator completion does not itself prove that external work was canceled or persisted. This is not an async-generator or network-stream demonstration.

The buttons follow one constrained path so each call has an unambiguous predecessor. This does not claim that all generators should be drained after cancellation: cleanup code can throw, yield indefinitely or perform unwanted work. Choose a resource-specific shutdown contract rather than applying this fixture as a universal cancellation loop.
