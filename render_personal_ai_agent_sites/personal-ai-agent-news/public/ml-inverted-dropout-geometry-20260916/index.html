Dropout preserves
a mean, not a sample.

Inverted dropout stretches the surviving coordinates to compensate for the missing ones. The center of probability stays put, but the possible activations move apart.

Read the experiment
The input is fixed at x = (1, 1.5, 2). Each coordinate is independently retained with probability q = 1 - p. The scene includes all eight masks, not eight random draws. Gray marker sizes are fixed; they do not encode probability. A zero-probability selected mask is explicitly identified in the readout. The coordinate extent automatically fits the outcomes as p changes.
At p = 0.5, the selected mask (1, 0, 1) produces (2, 0, 4), not the original input. Each of the eight masks has probability 1/8. Their probability-weighted mean is nevertheless exactly (1, 1.5, 2). At p = 0.8, keeping all three is rare: probability 0.008, with output (5, 7.5, 10).
  1. Start at p = 0. Only the all-retained mask has nonzero probability. Other displayed masks are counterfactual outcomes, not events that training can sample at this setting.
  2. Return to p = 0.5. Switch retained coordinates. The selected output jumps, but the mean does not.
  3. Increase p. Survivors grow as 1/(1-p), and expected squared distance from the mean increases. Compensating the mean is not removing the noise.


The compensation, derived
Let each mask coordinate mi be Bernoulli(q), independent of the others, with this input held fixed. Inverted dropout gives:
Y_i = m_i x_i / q
E[Y_i] = q (x_i / q) + p (0) = x_i
E[Y_i^2] = q (x_i / q)^2 = x_i^2 / q
Var(Y_i) = x_i^2 / q - x_i^2 = x_i^2 p / q
Summing the coordinate variances gives E[||Y-x||²] = (p/q)||x||² = 7.25p/q. This is an expectation over masks for one fixed activation, not an observed error rate or a training loss. The display independently enumerates the masks and weights their squared distances.
A particular mask retaining k coordinates has probability q^k p^(3-k). Only at p = 0.5 can you average the eight outputs equally. At other probabilities, equal weighting gives the wrong mean.
PyTorch's Dropout documentation specifies training-time scaling by 1/(1-p) and identity behavior during evaluation. This experiment uses that convention, not the alternative convention of scaling at test time. The slider excludes p = 1 because these formulas divide by q.


A nonlinear layer breaks the shortcut
Consider a downstream scalar f(Y) = max(0, Y_x - 1). This is a ReLU with a bias, using only the first coordinate. With our input x1 = 1:
f(E[Y]) = max(0, 1 - 1) = 0
E[f(Y)] = q max(0, 1/q - 1) + p max(0, -1)
        = p
At p = 0.5, the two answers are 0 and 0.5. Preserving a layer's expected input does not imply that the evaluation network exactly equals the average training-time network. The nonlinear gap in the readout comes from exact enumeration, not a Monte Carlo approximation.


What this does not demonstrate
The original dropout paper investigates regularization by randomly dropping units during training. This small geometry experiment isolates scaling and moments; it does not train a network, prove better generalization, choose a good dropout rate, or measure uncertainty calibration.
We assume independent elementwise masks, fixed activations, and 0 ≤ p < 1. Channelwise dropout, correlated masks, changing activations, and full-network losses require their own analysis. In actual training, a mask is sampled. Here you select one for inspection while all expectations still include the full distribution.
