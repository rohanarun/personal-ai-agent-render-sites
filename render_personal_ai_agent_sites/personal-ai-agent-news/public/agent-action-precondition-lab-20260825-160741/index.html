A side-effect readiness simulator

Check the condition that makes the action safe now.

An agent may have gathered good evidence earlier, but a side effect is only safe when its preconditions still hold at the moment of action. Tune freshness, scope match, and expiry pressure to see the right next move.

Evidence has a time and a target.

A precondition is not a permanent fact. It is a claim about a specific object at a specific moment, and the agent should revalidate it when the cost of being wrong is high.

Bind evidence to the target

An approval for one resource does not authorize a neighboring resource just because the names look similar.

Revalidate near the edge

Freshness matters most immediately before the side effect, especially when permissions or windows can change.

Let expiry change the plan

When time is closing, the agent may need to ask for a new approval rather than squeezing an old one into the last seconds.
