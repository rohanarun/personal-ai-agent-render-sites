Mixture entropy minus within-source entropy

M = w P + (1 - w) Q
JS = H(M) - w H(P) - (1 - w) H(Q)
JS = I(label; outcome) = H(label) - H(label | outcome)
0 <= JS <= H(label) <= 1 bit

Weighted Jensen-Shannon divergence is the average information an outcome reveals about its source label. Identical sources reveal nothing. Disjoint supports reveal the label perfectly when both sources have positive prior probability. A certain prior has zero label entropy, even when the sources differ.

Posteriors follow Bayes' rule. The outcome-specific information gain is KL(posterior || prior); averaging it over the mixture gives JS. A zero-probability outcome has no defined posterior. All logarithms use base 2, with zero-mass terms contributing zero.

The standard symmetric JS uses w = 0.5. Unequal weights encode a prior and do not preserve symmetry when only P and Q are swapped. ml-matrix computes the joint label-outcome distribution; the entropy identities are evaluated directly.
