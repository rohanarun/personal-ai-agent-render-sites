More budget can improve a constrained fit. The multiplier tells you how much the optimal loss changes locally, not how much every finite increase will save.

The minus sign is the point

The Lagrangian uses μ(x₁+x₂−b) − ν₁x₁ − ν₂x₂, with nonnegative multipliers. Because increasing b relaxes the constraint, V′(b) = −μ here. The displayed numerical slope uses a centered difference with step 0.00001.

Strong duality gives V(t) ≥ V(b) − μ(t−b). This is a global supporting bound; the derivative describes an infinitesimal change. A large budget increase can cross an active-set transition, so multiplying the current μ by that increase is not an exact prediction.

For this target family, x₂ first becomes positive at b = a−1. Both coordinates then grow until b = a+1 reaches the target. Beyond that point, the budget is slack and μ = 0. At the transition itself a tight constraint may have zero multiplier. V is differentiable here even where its curvature changes.
