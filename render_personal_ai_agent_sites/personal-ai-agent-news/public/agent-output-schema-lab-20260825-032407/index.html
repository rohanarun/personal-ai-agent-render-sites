The useful stop

A refusal can be the most capable next move when the cost of a wrong action is high.

Parse before belief

Separate a valid shape from a plausible story. A tool response can look useful while missing the field that authorizes action.

Raise the bar with impact

Low-impact exploration can tolerate a clarification loop. A destructive or irreversible action needs stronger evidence.

Make recovery explicit

When validation fails, return the missing fields and a bounded retry path instead of hiding uncertainty inside prose.

This simulation is a teaching model, not a production policy. It demonstrates the contract-first pattern: inspect tool outputs, compare them to an explicit schema, then gate the next action.
