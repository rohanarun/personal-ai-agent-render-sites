What changes, what stays
The illustrative example mixes CRLF, LF, and CR. A CRLF pair counts as one line break. This tool replaces only those three break forms and your chosen leading UTF-8 BOM. Blank lines, text, and whether the document ends with a break are preserved. Unicode line and paragraph separators remain untouched.
Files are decoded with a fatal UTF-8 decoder; malformed bytes are rejected instead of being replaced. A leading UTF-8 BOM is detected separately. UTF-16 files are not supported, and NUL-containing text is rejected. This is not a binary-file editor, encoding detector, or repository-wide migration. Downloads are new files; the source file is not overwritten.
The selected file is read by this page's browser code, not sent to an AI service. The page also loads a remote product video; this is not a claim that the whole page makes no network requests.

Reuse is implemented, not just a prompt
The public response-cache release stores successful responses for exact repeated requests. A miss goes upstream. Avoiding another upstream model call does not eliminate execution or infrastructure costs.
Separately, inspected workflow-cache source requires owner and task context, verified completion, and runnable Python steps before storage; portability checks can decline a workflow. A hit returns the workflow, helper version, and verification evidence. Missing context, an empty cache, or no safe match produces a miss for the caller to handle. Matching may itself incur usage.
Source inspection establishes an implementation, not live availability for every account, measured savings, automatic fallback by every caller, or compatibility with every app. No speedup or cost benchmark was run here.
