What the inspected implementation stores

The local-execution cache accepts a verified-complete confirmation and a workflow containing runnable Python steps. A hit returns the workflow with verification and output evidence. It is a procedure-reuse path rather than a cache of answer prose.

Eligibility and misses

Lookup requires an owner and task context. Missing context, an empty cache, or no safe match returns no cached workflow. That endpoint alone does not prove that a fresh fallback completes. Matching may incur model-usage charges.

What is not established

Source inspection on September 13, 2026 establishes implementation, not availability for every account or workshop task. Reuse can avoid reconstructing a procedure; no measured time savings, zero-cost promise, or universal compatibility is claimed here.
