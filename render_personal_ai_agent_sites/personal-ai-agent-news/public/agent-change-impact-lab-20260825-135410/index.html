A useful mental model

Rollback is part of the change, not the apology after it.

An agent should know the recovery path before it takes the action. That makes experimentation bounded and keeps a wrong result from becoming a second emergency.

Estimate impact

Count the systems, users, and permissions that may change together.

Test recovery

Verify that the rollback is executable, observable, and smaller than the original change.

Stop with evidence

When dependencies are unknown, stop and return the missing proof. A pause is a useful output when the change cannot yet be bounded.
