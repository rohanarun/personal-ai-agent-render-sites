Same line, different chance

Each update adds (b_i - a_i dot x) a_i / ||a_i|| squared. Multiplying a row and its right-hand side by the same nonzero scale leaves this projection unchanged. Norm-weighted sampling, however, selects that row with probability ||a_i|| squared / ||A||F squared, so its chance changes with the square of the scale.

For a consistent full-column-rank system, Strohmer and Vershynin, Algorithm 1 and Theorem 2 bound the expected squared error of independent norm-weighted projections. Here the conditional one-step bound is:

E[||next - solution|| squared | current] <= (1 - smallest singular value(A)^2 / ||A||F^2) ||current - solution|| squared

The expected value above is calculated exactly over the three possible next projections. It is not a Monte Carlo estimate or a bound on every individual draw. Manual row choices still reduce or preserve squared distance to the shared solution, but do not obey the randomized selection law.
