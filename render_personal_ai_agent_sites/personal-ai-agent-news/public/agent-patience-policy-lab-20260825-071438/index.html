Waiting is also a decision.

Four graceful exits.

Latency becomes manageable when the interface preserves momentum without pretending the work is done.

Keep waiting

Use when remaining value is high, urgency is bounded, and the wait is still legible to the person.

Return partial value

Share progress, caveats, or a useful subset when a complete result is not ready yet.

Hand off or stop

Move work async when recovery is real; stop clearly when neither value nor recovery justifies more waiting.
