What the simulation teaches

Decomposition is not about making more steps. It is about placing a useful checkpoint before a consequential choice, so the agent can explain what it knows and what it needs next.

A useful design move

Name the outcome, define the next observable action, and stop at the first decision that changes external state. That makes correction cheaper than replay.
