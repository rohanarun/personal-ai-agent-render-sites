Choose the boundary.

An agent should not ask for help because a task is hard, or keep going because a task is familiar. Intervention belongs where the cost of autonomous error overtakes the cost of a human decision.

A good boundary preserves momentum without pretending uncertainty is harmless.

Act with a visible checkpoint.

Confidence and reversibility support progress, but the agent should make the decision easy to inspect.

The boundary should be legible before the action, not explained after the harm.

Price the downside

Confidence is not enough when an error has a large or irreversible impact. Make consequence part of the control signal.

Protect reversibility

Prefer autonomous actions that can be undone, previewed, or paused before they cross a consequential boundary.

Ask usefully

Human intervention should arrive with context, options, and a clear decision request, not an empty “what should I do?”
