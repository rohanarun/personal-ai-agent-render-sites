Budget for different units
Baserow's Cloud pricing lists Free at $0, Premium at $10 per user/month billed yearly ($12 monthly), and Advanced at $18 billed yearly ($22 monthly). The listed workspace row limits are 3,000, 50,000 and 250,000 respectively. Advanced lists role-based permissions and audit logs; Enterprise is quoted. Self-hosting is a separate pricing view. What the computer-use cache actually reuses
The first-party release describes a response proxy that reuses successful responses for exact repeated requests. Misses go upstream. A cache hit can avoid another upstream model call, while execution and infrastructure costs can remain.
Separate workflow-cache implementation
In the inspected local-execution code, storing a workflow requires an owner, task context, verified-complete confirmation and runnable Python steps. A portability check can decline a save. Lookup returns workflow and verification evidence on a safe match, or a miss for the caller to handle; matching may incur usage charges.
This is workflow reuse, distinct from the exact-request response proxy. Source inspection does not prove availability for your account, automatic recovery, or measured savings. No speedup, privacy guarantee or universal compatibility is claimed.
A pilot that can fail usefully
Use synthetic records in the chosen product. Write down what should happen to a task when its project is removed: reject the deletion, clear the link, or cascade. Then test that actual policy and inspect the resulting records. A button label or this local rehearsal is not backend evidence.
For Baserow, verify the schema, permissions and deployed application's behavior. For Super, specify the exact allowed action and verify the destination state after execution. Test a denied operation too. Export identifiers with the handoff so display-name changes do not silently redirect work.
