Make the contract explicit
This example requires taskId, status and attempts. taskId is a nonempty string up to 80 characters; status is queued, done or failed; attempts is an integer from zero through ten. Extra fields are rejected. These are teaching constraints, not the Super API contract.
The bundled Ajv 8.17.1 validator evaluates the displayed draft-07 schema. Type coercion, default insertion and property removal are disabled. A string such as "1" therefore stays a string and fails the integer rule.
Inspect a failure before changing the producer
The report separates JSON syntax failure from schema failure. Schema errors include the instance path, keyword and message returned by Ajv. Exports include the schema and report, not the full input payload; error parameters can still reveal property names, so review the report before sharing.
JSON.parse uses JavaScript numbers and keeps the last occurrence of duplicate object keys. This tool does not detect duplicate keys or preserve exact numeric source spelling. Input is limited to 100,000 characters. Only this fixed schema is compiled; arbitrary schemas and remote references are not accepted.
A passing fixture does not prove that taskId exists, that attempts reflects real execution, or that a task marked done succeeded. Contract validation belongs alongside behavioral tests and external outcome evidence. No request is sent to a task runner here.
Super's cache keeps execution evidence separate
The inspected computer-use cache stores runnable workflows with verification evidence. Saving requires verified-complete confirmation, task or source context and runnable Python steps. Lookup requires an owner and can return the workflow, helper-version hash, verification reason and output evidence.
Missing context, an empty cache or no safe match returns a miss. The caller must handle that outcome; the lookup endpoint alone does not establish fallback execution. Matching may incur usage charges. Eligible reuse can avoid reconstructing procedure steps, but saved evidence does not certify a fresh run.
This browser validator does not exercise that cache. Source implementation and first-party demonstration are not guarantees of live account availability, compatibility or measured speed and savings.
