Voice Actor Pickup Sheet

How to collect retakes without losing the original script line numbers.

Local planning only. No recording, speech recognition, AI calls or script upload. Reloading clears your work. The product video below loads from an external host.

Illustrative script. Up to 100 physical lines, 300 characters per line and 16,000 characters total. Blank lines keep their place in numbering but are not selectable.

Lines to record again

A retake list is not a new script

Line 4 stays line 4 even when lines 1 through 3 are not selected. This sheet references physical text lines, not screenplay pages, spoken sentences or audio timecode. Automatic wrapping on screen does not create a new numbered line.

Keep a copy of the exact source script with the pickup sheet. Editing the text pauses selection and export; applying the revised script clears every old mark. That prevents retake decisions from silently attaching to different words. This tool does not manage script versions or verify that a recording matches the script.

What is in the download?

Only selected nonblank lines, in source order. JSON contains lineNumber and text for each entry plus a local-planning scope. Text prefixes each selected line with its original number. Leading and trailing spaces inside each line are retained; browser textarea line endings are normalized. No audio is included.

Where Super fits after the session

This standalone sheet needs no assistant. For a larger workflow, Super offers agent-operated apps, browsers and sandboxes. A useful next step is to ask about organizing a handoff in a specific app, then check access, permissions and the final artifact before sharing it. This page is not connected to that app and does not send your selections anywhere.

Actual technology, with a clear boundary

The first-party Computer-Use Cache release describes a response proxy: exact repeated requests can reuse successful responses; misses go upstream. A hit can avoid another upstream model call, not all execution or infrastructure costs.

Separately, the inspected local-execution workflow implementation returns a stored workflow with verification evidence when a safe match is found. Missing task context or no safe match returns a miss, which the caller must handle. Matching may incur model usage. These are different reuse mechanisms, not proof that this pickup sheet uses either one.

Source inspection is not a live workflow test. No measured savings, speedups or universal app compatibility are claimed here.
