Read the destination, not the resemblance
In the first example, the parent segment moves up from the base directory. A leading double slash instead supplies a host while retaining the base scheme. The default HTTPS port is normalized away.
The user-information example puts a familiar name before the @ character. The actual hostname is elsewhere.example. Look at the parsed hostname, not a substring match.
An agent still needs an action policy
This lab compares origins only for HTTP and HTTPS URLs. Equal origins do not establish that a page is trusted, a purchase is approved, or a later redirect stays there. Different paths on the same origin can have very different consequences.
Illustrative handoff: resolve a link from a research page, inspect the resulting destination, then apply the agent's actual navigation and action permissions. This inspector is not an allowlist, network filter, redirect checker or SSRF defense.
Parsing is not validation of intent
A parser can accept and normalize text that a person did not intend. Non-HTTP schemes are displayed but excluded from this lab's origin comparison. A parse error leaves no exportable result.
