Spend time where it buys safety

Verification is not a virtue by itself. It is useful when it changes what the agent will do next.

Make impact explicit

An agent cannot choose the right speed if the consequence of a wrong move stays hidden in the prompt.

Preserve a way back

Rollback and confirmation can make a faster first move safer than a slow move with no recovery path.
