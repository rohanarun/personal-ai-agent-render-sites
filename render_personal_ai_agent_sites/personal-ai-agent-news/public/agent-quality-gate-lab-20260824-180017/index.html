Urgency can choose a deadline, not a truth.

Quality gates are easy to bypass when a task feels urgent. But a fast release does not remove change risk; it only reduces the time available to learn about it. A good agent keeps the gate explicit so a person can see which evidence is strong, which is stale, and which assumption is doing the work.

This lab makes the tradeoff visible. Test coverage and fresh evidence create release margin. Risk consumes it. Urgency can make a review more valuable, not less. The score is a teaching device, not a production checklist; use it to ask what evidence would change the decision.
