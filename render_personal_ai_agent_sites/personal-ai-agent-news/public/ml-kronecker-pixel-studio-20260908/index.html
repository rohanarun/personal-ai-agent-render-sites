Where the transpose comes from
Y[i,j] = sum over p,q of A[i,p] X[p,q] B[q,j]
For column-first vectors, the input index is p + 3q and the output index is i + 3j (zero-based). The coefficient is A[i,p]B[q,j], exactly entry (i + 3j, p + 3q) of BT tensor A. Row-first vectors instead use A tensor BT. Swapping the ordering without changing the operator generally produces a different result.
veccolumn(AXB) = (BT tensor A) veccolumn(X)
vecrow(AXB) = (A tensor BT) vecrow(X)
A separable, cyclic mixer
In this experiment A = (1-r)I + rP and B = (1-c)I + cP, where P has rows [0,1,0], [0,0,1], [1,0,0]. Left multiplication blends each row with the next row; right multiplication blends each column with the previous column. Both wrap around the boundary. At zero mixing the image is unchanged; at full mixing it is shifted, not smoothed.
The nonnegative weights in each output sum to one. These particular mixers also preserve the sum of all pixels. They are a small demonstration of separable linear image processing, not a trained model or a general-purpose blur.
A and B store 18 numbers; the expanded operator stores 81. For n by n images those counts become 2n squared versus n to the fourth. Larger implementations can apply the two factors without constructing the large matrix. Pixel values and all operator products are computed using ml-matrix; the displayed weights are rounded.
