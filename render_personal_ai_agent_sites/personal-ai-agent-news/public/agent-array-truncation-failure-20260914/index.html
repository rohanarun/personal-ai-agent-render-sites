A failed write can still delete work.

Investigate a four-item local queue. Reducing array length is not an all-or-nothing transaction when an index cannot be deleted.

Operation

const queue = ['A', 'B', 'C', 'D'];
// Protected mode only:
Object.defineProperty(queue, '2', { configurable: false });
const accepted = Reflect.set(queue, 'length', requestedLength);

Predict before you run

With index 2 protected, request length zero. Does false mean the original queue is intact? Compare the remaining slots with the initial A, B, C, D sequence.

Then request length three. Index 2 is still within the target range, so no deletion of that index is needed. Switch to ordinary mode and try zero again. Each run starts from a new four-item array, not the previous result.

Why the partial result happens

The ECMAScript ArraySetLength algorithm removes indices from the high end while shrinking. If a deletion fails, it sets length just above that index and reports failure. Earlier deletions are not restored. Here D can disappear before protected C stops the shrink.

The general array length behavior also means length is an index boundary, not a count of every property on an array. This fixture uses four present indexed elements and no custom metadata fields.

Controller design consequence

If an agent controller uses an array for pending work, checking only the write's boolean result is insufficient to prove its state stayed unchanged. This experiment does not lose real jobs: the letters are illustrative values in memory.

A real controller needs an explicit failure policy and evidence of the resulting queue state. This page demonstrates language behavior, not a durable queue, rollback implementation or recommended persistence strategy. It runs native Reflect.set; it does not simulate success or call an LLM.

The export includes the policy, requested and actual length, result, deleted original indices, and remaining values. Only integer requests from zero through four are accepted here. Editing a control invalidates the previous export.
