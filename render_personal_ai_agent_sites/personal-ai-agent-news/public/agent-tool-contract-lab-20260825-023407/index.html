What the simulation teaches

A tool schema is an executable boundary: it tells an agent what can be requested and gives the runtime a way to reject malformed intent before side effects.

A useful design move

Validate arguments, version the contract, and return actionable errors. “Invalid request” is a dead end; “field `location` must be a city ID” gives the agent a path back to a valid action.
