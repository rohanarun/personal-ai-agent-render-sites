What the simulation teaches

Event logs are evidence, not a ready-made story. An agent needs clocks, sequence information, or causal links to distinguish “seen later” from “happened later.”

A useful design move

Persist event time, observed time, source, and correlation ID separately. When the order is ambiguous, preserve uncertainty instead of inventing a clean timeline.
