The Jacobian is a local promise

Which small input change moves the output most? And when does a derivative stop predicting the result well?

A derivative for every output
A scalar gradient describes one output. For a vector-valued function F, collect partial derivatives into a matrix J: one row per output, one column per input. The first-order prediction is F(p+δ) ≈ F(p)+J(p)δ. We subtract F(p) and inspect changes, not absolute positions.
F(x,y) = (x + 0.5y², 0.3x + 0.5y, 0.4xy)

At p = (a,b):
J(p) = [ 1      b   ]
       [ 0.3    0.5 ]
       [ 0.4b   0.4a]

δ = r (cos θ, sin θ)
This smooth polynomial is not a trained neural network. We choose it because its derivative and approximation error can be calculated exactly. The third output depends on both inputs; the three-dimensional geometry is part of the map, not decoration.


A circle becomes an ellipse, locally
Apply J to every unit input direction. The image is an ellipse in J's column space, embedded in three output dimensions. Its semiaxis lengths are the two singular values σ₁ and σ₂. The right singular vectors give the corresponding input directions.
For Euclidean norms and a unit vector v, σ₂ ≤ ||Jv|| ≤ σ₁ in this two-input example. The gain buttons select those singular directions using ml-matrix. They maximize or minimize the linear prediction, not necessarily the exact nonlinear change at a finite radius.
Opposite directions have opposite linear outputs with equal lengths. Nonlinear terms can break that symmetry. The pink curve at a larger radius need not share the green ellipse's axes.


Know exactly what was left out
For δ=(u,v), direct expansion gives the exact remainder:
F(p+δ) - F(p) - J(p)δ = (0.5v², 0, 0.4uv)
||remainder||² = 0.25v⁴ + 0.16u²v²
Hold the direction fixed and halve r. Both u and v halve, so the remainder vector and its norm become one quarter as large, unless already zero. On our normalized plot, the separation halves because all plotted coordinates are divided by r.
Moving the base point changes J and its ellipse, while this polynomial's remainder at fixed δ is independent of the base point. That independence is specific to this example, not a general property of neural networks.


A worked case
Select Worked example: p=(0,0), θ=90°, r=0.6. The displacement is (0,0.6). The prediction is (0,0.3,0), but the actual change is (0.18,0.3,0), giving error norm 0.18.
Set r=0.3. The actual change is (0.045,0.15,0), giving error 0.045: one quarter. The normalized horizontal gap falls from 0.3 to 0.15. At θ=0°, the remainder is zero at every allowed radius because y does not change. Exactness in one direction does not make the map linear everywhere.


What this tells you about a model
An input-output Jacobian can diagnose local amplification in a representation. Its meaning depends on the input point, chosen outputs, units and norm. Rescaling an input changes what a unit perturbation means; singular values are not comparable without agreeing on that scaling.
A large output change is not automatically a wrong classification or an adversarial example. Those claims need a decision rule and threat model. A small Jacobian at one input does not bound faraway behavior. Nonsmooth networks also require care when a perturbation crosses an activation boundary.
For a real system, compare derivative predictions with measured perturbations at multiple radii and inputs. Keep output change, local gain and approximation error separate. This experiment illustrates that diagnostic logic; it neither certifies a model nor estimates a robustness rate.
