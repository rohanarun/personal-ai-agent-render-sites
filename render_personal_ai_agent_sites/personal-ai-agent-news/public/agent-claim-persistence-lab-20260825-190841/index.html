Make reuse honest

Store the source, observation time, scope, and invalidation rule with the claim. This turns a fluent memory into an inspectable artifact.

  • Keep provenance attached to the statement.
  • Do not widen scope during summarization.
  • Set a stricter refresh rule for high-consequence uses.

Try the trap

Raise provenance while keeping scope fit low. A reputable source can still be the wrong source for the claim you want to reuse.
