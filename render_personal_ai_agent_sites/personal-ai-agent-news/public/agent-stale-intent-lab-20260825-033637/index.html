Respect the moment

Confirmation is a capability when it is precise, timely, and tied to the actual action.

Show what changed

Tell the user the action, the time elapsed, and the new context that makes the old request less certain.

Confirm the action

Ask about the consequential operation, not a vague “still okay?” that hides what will happen next.

Keep low-risk work moving

Freshness gates should be proportional: a draft can proceed while an irreversible action waits.

This simulation is a teaching model, not a production authorization policy. It demonstrates a contract-first pattern: preserve request time, compare it to action risk, and confirm before stale intent becomes silent permission.
