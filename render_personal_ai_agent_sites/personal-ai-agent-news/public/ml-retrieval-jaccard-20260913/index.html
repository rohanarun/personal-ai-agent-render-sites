Shared Retrieval

Two retrieval runs return document IDs from the same miniature collection. A result can belong to A, B, both, or neither. How much of their combined evidence is shared?

Shared, divided by combined

Jaccard is the intersection size divided by the union size. Each document counts once, even when both runs retrieve it. Red is A-only, green is shared, and blue is B-only. The strip partitions the union, not the entire collection.

Containment is not similarity

When A contains two documents and B contains those two plus six more, A is 100% covered by B. Jaccard is only 25%, because six of the eight union members are not shared. Directional coverage answers a different question.

What this cannot evaluate

These are synthetic, unordered IDs. Swapping ranks or repeating a document does not change a set. No relevance labels are supplied, so none of these values is retrieval precision, recall, or answer correctness. Two equally wrong retrievers can agree perfectly.

Empty-set convention

Both empty gives 0/0 for Jaccard; this experiment displays Undefined. Coverage of an empty set is also undefined. One empty and one nonempty set gives Jaccard zero. Software may offer alternative zero-division conventions; always state yours.
