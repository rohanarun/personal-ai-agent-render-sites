From links to a count

For this simple, undirected, unweighted graph, each diagonal entry of L is the node's degree. A present link gives -1 in its two off-diagonal positions; missing links give zero. Every row sums to zero, so the determinant of the full Laplacian is zero.

Kirchhoff's matrix-tree theorem removes the same row and column and takes the determinant of the remaining matrix. The result is the number of spanning trees. Deleting a different node gives the same count; it does not delete that node from the original network or change the trees.

A count is not a guarantee

A spanning tree reaches every node with no cycles. Disconnected graphs have none. A connected four-node graph with just three edges has one. The complete four-node graph has sixteen. Adding a link cannot remove an existing tree, though it may add many new ones.

For inspection, this studio tries every available three-link subset and retains those whose reduced Laplacian determinant is one. The highlight shows one retained subset, not an optimized routing plan. Tree count is a combinatorial redundancy measure, not a probability of network survival; failure probabilities require a separate model.
