Description is not identity

Symbol.for retrieves a registry symbol for a string key, creating one if absent. Two fresh Symbol calls instead create distinct values even when their descriptions match. A readable label is not a lookup guarantee.

This experiment registers one local Map entry. Fresh mode creates two independent symbols; registry mode calls Symbol.for for each input. Retained mode passes the original symbol directly, so the lookup label is ignored. The chart joins the identities only when strict equality succeeds. No handler performs an external action.

Choose a plugin contract

For explicitly shared internal tokens, pass the symbol object itself. For independently loaded code that agrees on a registry name within a shared runtime registry, a namespaced key can coordinate identity. Different names remain different keys; letter case matters. This page does not demonstrate cross-process, worker or network identity transport.

Registry names are not secrets and symbols are not an authorization check. Decide separately who may register or invoke a privileged handler. Reconstructing a key cannot prove that a request has permission.
