Why reflection stays nonexpansive

Euclidean projection onto a closed convex set is a proximal operator and is firmly nonexpansive. Let d = v−w and e = P(v)−P(w). Firmness gives ‖e‖² ≤ ⟨d,e⟩.

For the reflection R = 2P−I, the squared output distance is ‖2e−d‖² = ‖d‖² + 4(‖e‖²−⟨d,e⟩), so it cannot exceed ‖d‖². For 0 ≤ η ≤ 2, Tη = (1−η/2)I + (η/2)R is a convex combination of nonexpansive maps.

Nonexpansive means distance never increases, not that every distance strictly decreases or every repeated iteration converges. An example beyond η = 2 can expand without contradicting the theorem.
