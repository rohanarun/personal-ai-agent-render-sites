What was removed?

The control matrix C contains an intercept and z. First fit x on C and keep r_x = x - fitted x. Separately fit y on the same C and keep r_y. Regressing r_y on r_x gives the same x coefficient as fitting y jointly on an intercept, z, and x, when the coefficient is identifiable. The residualized fit passes through the origin because the intercept was already removed.

Why both sides matter

Removing z from y alone and then regressing that residual on the original x keeps shared variation in the denominator. In this constructed example, it shrinks beta toward zero rather than reproducing the full coefficient. Residualizing only x can reproduce the coefficient with the appropriate regression setup, but double residualization also makes the plotted geometry explicit.

A deliberate sign reversal

These twelve synthetic observations use centered, mutually orthogonal vectors z, u, and e, each with mean square one. The construction is x = rho z + s u and y = beta x + gamma z + noise e. Therefore the raw slope is beta + gamma rho / (rho squared + s squared), when x varies. The partial slope is beta whenever s is positive. Orthogonal noise changes the scatter without changing these exact coefficients; this is a designed demonstration, not a random sample.

At s = 0, x is fully explained by the controls. There is no residual x variation, so its separate coefficient is not identified. A pseudoinverse can still choose a minimum-norm coefficient vector, but that arbitrary allocation is not displayed as an identified partial slope.

Regression is not a causal guarantee

This is an algebraic equivalence for ordinary least squares on the same observations and controls. It does not establish that z is an appropriate causal adjustment, remove unmeasured confounding, or imply that coefficients from a nonlinear or regularized model obey the same identity.

Robin Evans, Oxford: Frisch-Waugh-Lovell theorem, section 19.1 states the equivalence of joint and double-residual OLS coefficients. The finite orthogonal design here provides a directly checkable example.
