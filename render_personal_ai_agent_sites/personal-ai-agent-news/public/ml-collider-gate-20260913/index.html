A shared effect opens a path

The assumed graph is Coding → Selected ← Writing. Selection is a common effect, called a collider. Restricting analysis to selected models can associate the two skills even though the original population makes them independent.

The equal-prevalence example

With both prevalences at 50%, each of the four skill combinations has probability 25%. The either-skill gate removes only the neither-skilled group. Among selected models without coding skill, everyone has writing skill. Among selected models with coding skill, half have writing skill. That is a minus 50 percentage point difference created by selection.

Exact arithmetic

Independence gives P(A,B) = P(A)P(B). Each admitted cell is divided by total admitted probability. The displayed difference is P(B=1 | A=1, selected) minus P(B=1 | A=0, selected).

When a group has no admitted probability, its conditional probability and the difference are undefined. The both-skills gate illustrates this lack of comparison support.

What this says about machine learning

This synthetic example is a warning about evaluating only benchmark winners or successful agent runs. It is not evidence that real model skills are independent, or that every observed tradeoff is selection bias. The graph and selection process must be justified for the actual dataset.
