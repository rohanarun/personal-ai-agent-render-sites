What to notice

Agreement is a signal, not a guarantee.

The useful question is not “how many sources agreed?” It is “how much independent evidence did the agent actually receive?”

Reliability

Every source can be wrong.

Reliability is the chance that one source is directionally correct. Raising it improves both quorum policies, but does not repair duplicate or copied evidence.

Correlation

Copies count once.

If multiple pages share a retrieval path, dataset, or upstream claim, their errors are coupled. A majority can confidently repeat one mistake.

Policy

Quorum trades misses for mistakes.

A stricter rule reduces false accepts but can reject good answers more often. Agents need a policy matched to the cost of each error.

Operations

Record why the vote passed.

Persist source identity, independence signals, timestamps, and the quorum decision. This turns a confident answer into an inspectable decision trace.
