A boundary for agent outputs
Use this when examining a serializer before forwarding tool results. A global name list may remove useful nested fields or preserve a same-named field you did not intend. It cannot express a path-specific policy such as retaining one object's status but dropping another's.
For production, define the intended output structure explicitly and validate the resulting payload. Do not treat this experiment as a security sanitizer or schema validator. All input here starts as JSON, so it excludes functions, cycles, and custom toJSON methods.
The byte counts compare compact JSON before and after serialization, not token counts or model cost. Whitespace in the input does not affect the compact baseline. No model, network request, or user-written code is executed by the controls.
