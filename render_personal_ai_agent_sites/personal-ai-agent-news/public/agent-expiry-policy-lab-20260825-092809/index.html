Set an expiry that means something.

Evidence expiry is not a calendar ritual. It is a policy about how quickly the world can change relative to the consequence of trusting an old observation.

A useful expiry rule is specific about what can change, how fast, and what happens next.

Expiry is a control for future uncertainty, not a punishment for old data.

Tie expiry to change

Evidence should expire when the conditions that made it reliable could have changed, not merely when a timer feels tidy.

Make the fallback clear

When evidence expires, define the next step: refresh, ask, or stop. Silent reuse is not a policy.

Separate read from write

A stale observation may inform a low-impact read while failing to authorize a consequential mutation.
