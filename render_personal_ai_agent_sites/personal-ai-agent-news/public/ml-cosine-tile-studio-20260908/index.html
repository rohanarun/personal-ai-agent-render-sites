One image, a different basis

The orthonormal type-II discrete cosine transform changes coordinates without losing information. With the cosine basis matrix C, this two-dimensional transform is F = C X C transpose. Its inverse is X = C transpose F C.

Here only coefficients with u + v at most the chosen cutoff survive. This triangular low-frequency mask is an experiment, not a JPEG quantizer or an encoded file-size estimate. Keeping all 64 modes recovers the input up to floating-point error.

Orthogonality makes squared pixel error equal discarded coefficient energy. Division by 64 gives mean squared error. Sharp edges can ring after truncation: raw reconstructed values may leave [0, 1]. The displayed grayscale is clipped, but error metrics and exported values use the raw reconstruction.
