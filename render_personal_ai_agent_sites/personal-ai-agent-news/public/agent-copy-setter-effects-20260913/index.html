What the experiment creates

The source has properties in this order: before, value, after. Its value is either a data property or an instrumented getter. The target starts with a getter/setter pair for value, backed by the string "initial". Only source getter calls and target setter calls are counted.

Assignment can execute a setter

Object.assign reads source values and sets target properties. A target setter can run and throw. Earlier writes are not rolled back: with the throwing setter enabled, before remains copied while after is never assigned. The accessor itself remains an accessor.

Spread creates data properties

This spread expression creates a new object. It reads the target's value first, then the source's value, and defines ordinary data properties. It does not invoke the target setter, but it can invoke source getters. This does not make arbitrary object copying side-effect free.

Agent integration boundary

Before swapping one form for the other, decide whether the caller expects mutation, setter behavior or a fresh object. This fixture is an observable regression case, not a complete configuration validator or a transaction system.
