A yielded request travels out. A later next(value) sends a response back in. They are different directions.

Body events and calls
Start is not a response
Creating this generator produces an iterator without executing its body. The first next call starts the body and reaches the first yield. Its argument is not assigned to a waiting yield because no yield was suspended yet.
The second call supplies a string to the first suspended yield. The body records it and yields a second request. The third call supplies the second response and returns the assembled pair with done true. Further next calls return done true with an undefined value; they do not restart this generator.
An agent-shaped protocol
The fixture requests a source label and then an observation. These names are illustrative. No source is fetched, no model runs, and no observation is verified. The point is the transport contract: the value returned from next is an iterator result, while the argument passed into next resumes the body.
An orchestrator built around a generator needs to distinguish starting the iterator from answering a yielded request. Passing a tool response into the initial next call loses that response in this fixture. Each later response belongs to the yield where execution is currently suspended.
Keep representation explicit
This lab accepts strings, including the empty string. An empty string is not undefined. The export represents undefined using a type tag so JSON does not silently omit it. It records sent strings, iterator results, and body events in order, with no timing or performance claim.
The progress blocks mark creation, first suspension, second suspension and completion. They are not a scheduler or a persistence mechanism. A generator held in this browser is not a durable task checkpoint. Reset creates a new instance and clears the old trace; the lab caps history at 20 calls.
