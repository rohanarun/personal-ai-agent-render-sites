    Read the sequence
    The synchronous start and end surround the scheduling calls. Promise reactions and queueMicrotask callbacks run at a microtask checkpoint before this timer callback. A microtask added by another microtask joins the queue behind microtasks already waiting.
    An agent integration example
    Illustrative scenario: an agent UI schedules a status timer, then queues a local state update through a resolved promise. The state update can run before the timer even though the timer was registered first. A timer is not a completion barrier for an external tool.
    For a real dependency, await the promise that represents the operation you need. This lab's resolved promise does not represent a fetch, a model response, or a remote job. A local ordering trace cannot prove remote work has finished.
    Boundaries
    This records one window's controlled callbacks, not all browser tasks or paint events. It does not benchmark latency, predict network arrival order, or describe Node.js scheduling. The nested microtask is bounded to one callback; recursively producing microtasks can postpone other work.
