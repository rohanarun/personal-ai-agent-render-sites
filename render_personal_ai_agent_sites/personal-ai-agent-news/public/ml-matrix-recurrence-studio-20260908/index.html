Two terms are enough

The Cayley-Hamilton theorem, Altman and Kleiman, Section 10.1 says a matrix annihilates its characteristic polynomial. For a two-by-two matrix, that polynomial is z squared - trace(A) z + det(A). Consequently:

A^2 = trace(A) A - det(A) I

Start with alpha(0) = 0 and beta(0) = 1, so A^0 = I. Multiply alpha A + beta I by A and replace A squared using the identity above:

alpha(n+1) = trace(A) alpha(n) + beta(n)
beta(n+1) = -det(A) alpha(n)

Every subsequent power stays in the span of A and I. No inverse or eigenvector basis is required. The quarter-turn example repeats every four powers; the nilpotent example becomes zero at power two; the Jordan block keeps ones on the diagonal while its upper-right entry grows with n.

The theorem is exact algebra. Floating-point evaluation can still accumulate rounding or cancellation errors; this is not a blanket numerical-speed or stability guarantee. The reported error is ||direct - reduced||F / max(1, ||direct||F). Only nonnegative integer powers are included.
