A decision ledger simulator

A recommendation needs an expiry date.

An agent’s decision is a bundle of assumptions, evidence, and time. Tune how well each part is recorded to see whether the recommendation can still guide an action later.

Change the ledger

Imagine an agent recommends pausing a customer refund while it checks a duplicate order. A later worker must decide whether that recommendation still applies.

Ledger fields are control surfaces.

A decision ledger is not bureaucracy for its own sake. It exposes the conditions that let a later agent inherit a recommendation without mistaking history for current truth.

Name the assumption

Write the condition that would make the recommendation wrong, not only the conclusion that feels right.

Attach the evidence

Carry source, time, and scope so another worker can inspect the basis instead of trusting a summary.

Set a renewal point

Every decision that depends on changing state should say when it must be re-evaluated or retired.
