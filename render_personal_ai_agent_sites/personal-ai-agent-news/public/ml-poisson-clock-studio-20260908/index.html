The clock may tick without a move

Q = [[-1, 1, 0], [1, -1.5, 0.5], [0, 0.5, -0.5]]
P = I + Q / rate
p(t) = sum exp(-rate t) (rate t)^k / k! p(0) P^k

The initial row distribution is (1,0,0). A clock rate at least the largest exit rate, 1.5, makes P a valid transition matrix. Its diagonal entries represent virtual events that leave the state unchanged. Raising the clock rate changes P and the count weights, but not the exact continuous-time distribution.

Ward Whitt's continuous-time Markov chain notes, equation 3.30 and Theorem 3.4, establish this uniformization representation.

Every term is nonnegative and each p(0) P^k has total mass one. Therefore truncating after count M loses exactly the Poisson tail in L1 distance. The displayed truncated vector is intentionally not normalized; doing so would hide this direct error certificate.

The reference uses a symmetric eigendecomposition of this particular Q to evaluate exp(t Q). Small numerical differences near zero are floating-point effects. Clock events are not necessarily actual state changes. This is a finite-state numerical demonstration, not a simulation of an observed system.
