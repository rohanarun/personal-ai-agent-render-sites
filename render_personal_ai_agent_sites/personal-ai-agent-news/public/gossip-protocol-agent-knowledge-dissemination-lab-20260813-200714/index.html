Why rumors converge.

No coordinator knows the whole topology. Repeated random contact turns local knowledge into cluster knowledge with high probability.

1

Seed one local fact.

An agent learns a new task result, membership update, or cache invalidation. Initially, every other agent is unaware.

2

Contact a small fanout.

Informed agents select a few peers each round. Push-pull also lets uninformed agents ask selected informed peers, often accelerating late-stage convergence.

3

Repeat through loss and failure.

Independent paths carry duplicate evidence. A lost packet or failed agent delays some paths without becoming a single point of failure.
