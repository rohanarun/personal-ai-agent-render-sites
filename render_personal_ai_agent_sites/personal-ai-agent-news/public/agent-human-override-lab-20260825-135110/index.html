A useful mental model

Human control works best before the point of no return.

The agent should preserve operator choice when consequences are meaningful, uncertainty is high, or reversal is expensive. A clear handback is a productive system state.

Continue carefully

Low-risk work can remain autonomous when scope and recovery are clear.

Ask precisely

A good question states the action, consequence, and smallest decision a person must make.

Hand back with evidence

When the boundary is reached, stop the action and preserve the context needed for a human to resume. Never make the person reconstruct what the agent already knew.
