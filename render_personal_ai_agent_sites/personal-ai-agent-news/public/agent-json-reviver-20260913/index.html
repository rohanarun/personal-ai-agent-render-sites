Callback order

    Each row records the key and incoming type at callback time. Repeated keys can occur at different depths. The final empty key is the root wrapper; an actual empty property key can also appear earlier.

    Children before their container

    The reviver visits nested values before their containing object. Returning a replacement changes that value. Returning undefined deletes the property. The final callback can replace the entire parsed result.

    Try deleting key 1: the array retains its length but loses that own index. The JSON display turns that hole into null, so the slot report below it matters. A serialized preview is not a complete picture of JavaScript state.

    Agent integration checkpoint

    Keep the raw response separate from the transformed value. Apply your schema checks after transformation, and distinguish a missing property from an explicit null. This local experiment is not schema validation, sanitization, or evidence that a tool succeeded.
