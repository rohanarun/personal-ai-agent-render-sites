Resolve the disagreement.

When observations conflict, an agent should not average them into comfort. It should compare provenance, independence, recency, and the cost of choosing wrong.

Conflict is information about the observation process before it is information about the world.

Inspect provenance before choosing.

The disagreement may be explained by stale or dependent observations. Compare how each source was produced.

Two sources are not two votes when they share the same blind spot.

Trace provenance

Ask how each observation was produced, what it could not see, and whether the sources actually fail independently.

Prefer discriminating checks

When conflict remains, choose the next observation that can separate the explanations instead of collecting another duplicate.

Scale caution to impact

Unresolved conflict can be tolerable for a draft and unacceptable for an irreversible action. Let consequence set the threshold.
