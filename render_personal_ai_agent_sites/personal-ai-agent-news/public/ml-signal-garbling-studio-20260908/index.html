Randomization cannot create decision value

The original signal has probabilities [0.7, 0.2, 0.1] in state 0 and [0.1, 0.3, 0.6] in state 1. With probability g, replace it by an independent draw from [0.25, 0.5, 0.25]. Otherwise retain it. The replacement event is hidden.

G = (1 - g) I + g 1 rT
K_g = K G
Best loss = sum_y min((1-p) K_g[0,y], c p K_g[1,y])

Blackwell's comparison says a garbled experiment cannot lower optimal expected loss. Someone with the original signal could simulate the garbling and then copy any downstream policy. Equality is possible: extra information need not change the best action for this particular cost and prior.

The curve reoptimizes the policy at every point; your selected policy stays fixed until edited. At ties either action is optimal; the preset chooses 0. ml-matrix computes the channel composition. This is a finite decision experiment, not a trained classifier.
