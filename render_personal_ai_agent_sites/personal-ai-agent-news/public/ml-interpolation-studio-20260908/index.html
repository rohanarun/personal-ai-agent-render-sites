Placement changes the polynomial

A degree-n interpolating polynomial passes through n+1 distinct nodes. The Runge function is smooth, yet high-degree interpolation at equally spaced nodes can oscillate badly near the interval ends. Clustering nodes near the endpoints, as Chebyshev extrema do, can reduce this effect.

A stable evaluation algorithm cannot remove oscillation intrinsic to the interpolating polynomial. SciPy recommends a barycentric representation for numerical stability. This small lab instead exposes monomial coefficients from a QR solve, using ml-matrix, and reports the node residual so solver error remains visible.

What the numbers measure

Degree n means n+1 samples on [-1,1]. Chebyshev extrema are -cos(i*pi/n), including both endpoints. The displayed maximum and RMSE use 801 evenly spaced evaluation locations, not an exact continuous maximum or a statistical test set. The probe evaluates the polynomial separately at its selected location.

Changing degree also changes the sample positions. This is a comparison of interpolation designs, not a controlled experiment that adds features to one fixed dataset. The target values contain no measurement noise.

A lesson for learned approximations

Zero fitting error alone does not establish useful behavior away from observations. This example isolates one mechanism: sample placement interacting with a global polynomial representation. It does not imply that all high-capacity models behave like these polynomials, or that Chebyshev sampling is available in a real learning task.

The degree cap limits numerical conditioning problems in the monomial solve; it is not a claim about the maximum useful polynomial degree. Export includes ascending-power coefficients, nodes, grid predictions, and error measurements. No extrapolation outside [-1,1] is shown.
