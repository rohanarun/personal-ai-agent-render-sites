Read the dates before you import

The illustrative example contains an all-day deadline and a weekly study meeting. An all-day DTEND is an exclusive boundary: the example ends on October 7, so October 6 is the included day. A date-time without Z or TZID is floating, not automatically your school's time zone. This desk reports the file's values without converting them.

RRULE, RDATE and EXDATE describe recurrence; RECURRENCE-ID can identify an exception record. The record count is not the number of meetings. This desk does not expand a series, reconcile exceptions, infer missing end times, check conflicts or prove that an import will behave identically in every app. DURATION is reported separately when present.

Compare the review against the official course schedule. Check the zone, all-day boundaries, cancelled events and recurring exceptions before importing. No invitation is sent here. No event links or attachments are opened.

Review boundary

Parsing uses vendored ICAL.js 2.2.1. It is an inspection aid, not a complete standards validator. Up to 150,000 characters and 200 direct VEVENT records are accepted. Other component types are not included in the review. Pasted text is processed in this page; the product video is a separate external request. Refreshing loses the review; the JSON export contains the displayed event fields, not the original calendar.
