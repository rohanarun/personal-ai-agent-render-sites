What the simulation teaches

Delegation is not free. Each layer can widen the action surface and make it harder to know whether the original intent still applies to the current task.

A useful design move

Pass narrow capabilities, attach expiry and audience, and re-evaluate access when roles or tasks change. Inherited permission should be a hypothesis, not a permanent fact.
