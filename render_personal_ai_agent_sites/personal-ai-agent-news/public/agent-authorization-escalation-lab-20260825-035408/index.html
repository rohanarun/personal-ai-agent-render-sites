Escalate honestly

A good permission failure is legible, bounded, and easy for an authorized person to resolve.

Name the missing right

Return the exact permission needed and the action it would enable instead of asking for broad access.

Ask the owner

Route approval to the authority that can grant it. The agent should not infer consent from urgency or context.

Keep a safe fallback

Offer a read-only, draft, or simulation path so useful progress can continue without unauthorized side effects.

This simulation is a teaching model, not a production authorization policy. It demonstrates a contract-first pattern: compare requested privilege with current authority and gate high-impact escalation.
