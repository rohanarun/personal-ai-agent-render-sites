A lesson-preparation handoff

Illustrative use: compare the short melody with its accompaniment, select a note and discuss where it starts relative to other notes. The report preserves the parser's note ticks alongside seconds, so an onset can be checked against the source tempo map. It does not infer fingering, harmony, accuracy or a student's ability.

What the picture leaves out

This is a note-event view, not sheet music or audio playback. Note lengths end at note-off; sustain pedal and other controllers can change what a synthesizer sounds like. Pitch bends, expressive controllers, lyrics and notation are not visualized or included in the note report. Tracks without paired notes are shown as empty. No MIDI file is rewritten.

Accepted files and timing

Standard MIDI files, format 0 or 1, with ticks-per-quarter-note timing are accepted. SMPTE timing and format 2 are rejected. Limits: 256 KiB, 64 parsed tracks, 10,000 notes total and one hour to the last note ending. These are this tool's limits, not MIDI format limits. Seconds are derived by @tonejs/midi from the tempo map; the library assumes 120 BPM when no tempo event is present. Notes are selected in the parser's order.

File processing occurs in this page using a bundled parser. Files are not uploaded by this tool. The product video below is remote media and makes its own network request. Use non-sensitive material you are authorized to inspect.
