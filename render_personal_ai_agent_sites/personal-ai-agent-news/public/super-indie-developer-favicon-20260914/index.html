A small product needs a recognizable browser-tab icon. Build a simple monogram, inspect the tiny versions and export an opaque PNG without opening an image editor.

Matching HTML



One icon, one explicit handoff
Each export renders directly at the selected pixel size using your browser's Arial bold font. The small previews are displayed at their actual CSS sizes, not enlarged thumbnails. Font rasterization can differ between operating systems.
PNG is not an ICO bundle
This tool exports a single opaque PNG. It does not produce multi-resolution ICO files, SVG, Android manifests or a full platform icon package. The generated relative filename belongs beside the HTML page; adjust its path if your asset directory differs. A 180-pixel export includes an additional apple-touch-icon tag.
Inspect before shipping
Download every size you intend to reference. Only tags for the selected export are generated. Test the deployed icon in your target browsers: cached favicons can obscure updates. Two letters can be hard to distinguish at 16 pixels; one letter and strongly contrasting colors may be clearer. This is not an automated contrast or trademark review.
The illustrative SP monogram is editable. No text is sent to a model, and this workbench does not publish files or alter your website.

What the implementation actually reuses

A hit returns the workflow, helper-version information and evidence, rather than just a finished answer.
Missing context, an empty cache or no safe match returns a miss. The caller must handle that outcome; the lookup endpoint alone does not prove automatic fallback. Matching may incur model usage. This code inspection is not a live account-availability check or a measured speedup, savings or compatibility claim.
The public product page also describes a separate exact-request response proxy: it replays cached responses and sends misses upstream. That is distinct from the verified-workflow path above. Neither mechanism is used by this local PNG renderer.
