Context is a liability with a clock.

A well-designed agent does not merely collect more text. It records when a fact was observed, how it was supported, what disagreed with it, and when to ask again.

A working rule
Confidence should decay before the user notices the world changed.

Age is not proof of falsehood. It is a reason to lower certainty, surface the timestamp, and prefer a refresh when the action is costly.
