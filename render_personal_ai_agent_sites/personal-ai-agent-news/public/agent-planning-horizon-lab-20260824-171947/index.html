What the model shows

A plan needs an expiration date.

Run a scenario to see how a route becomes stale. Replanning is not indecision; it is the mechanism that lets an agent respond to new evidence without pretending its original assumptions still hold.

  • Plan depth expands the number of assumptions that can become wrong.
  • Uncertainty is a property of the world, not a flaw to hide in the plan.
  • When staleness rises, replan before the next irreversible step.
