Robot Framework: explicit reusable automation

Robot Framework is open source and covers both test automation and robotic process automation. Its keyword-oriented syntax is extensible through libraries in Python, Java, and other languages. The project states there are no licensing fees; that is not the same as zero infrastructure or maintenance cost.

For a team that wants to own reusable keywords and acceptance scenarios, it is a candidate worth evaluating. Which applications it can operate depends on the chosen libraries and environment. Do not assume that a natural-language scenario is already an implemented keyword.
