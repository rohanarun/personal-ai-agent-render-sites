Keep ownership explicit

Time is part of the contract.

A lease gives one agent temporary ownership of work. Renewal extends that claim only while the worker is healthy; expiry lets another worker recover without two agents acting at once.

Shape the lease

Increase heartbeat freshness and renewal margin. Longer work duration increases the chance that a stalled worker keeps a stale claim.

Ownership is current

The worker is renewing before expiry, so recovery can wait without creating a duplicate owner.
