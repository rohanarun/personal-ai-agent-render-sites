A duplicate is a decision

The example is an illustrative chapter-heading list. Repeated headings may be intentional. Keep the original and review the removal ledger before replacing any editorial source. This desk treats each line independently; it is not a CSV parser or a paragraph similarity detector.

Comparison keys can ignore outer whitespace and use JavaScript lowercase conversion. The first original line is retained verbatim, in its original order. Case conversion is not locale-aware collation, and visually similar Unicode sequences are not normalized. Output uses LF line endings, so this is not a byte-preserving file round trip.

The browser's Map collection records the first line number for each comparison key. Text is processed here without a model or upload request. This page also loads a first-party demonstration video; that is separate from text processing.
