Trace the alignment

Three operations, one objective

Insert a character, delete one, or substitute one for another: each costs 1. Matching characters cost 0. Levenshtein distance is the smallest total cost over all such transformations. Swapping adjacent characters is not a separate one-cost operation here.

Each matrix cell is the distance between two prefixes. From a cell, a diagonal step consumes both characters, a downward step deletes a source character, and a rightward step inserts a target character. The highlighted path includes zero-cost matches, so its number of steps can exceed the number of edits.

The runtime library computes every prefix distance. The display traces one minimum-cost alignment, preferring a diagonal step, then deletion, then insertion when costs tie. Other optimal alignments can exist.

String similarity is not meaning

The meaning-contrast example changes "safe" to "unsafe" with just two insertions, despite reversing the claim. A longer paraphrase may express the same meaning with many edits. Character-level distance measures surface changes, not truth, instruction-following, or semantic equivalence.

For LLM evaluation, specify the comparison unit and normalization before interpreting a score. This lab performs no tokenization or normalization and does not compute word error rate. Its examples are illustrative, not a model benchmark.
