What Attention Cannot Average Into

Can making attention sharper produce a value that none of its inputs can average into?

Explore one attention head with four fixed values. Learn how queries choose weights, how temperature changes concentration, and why the output stays inside a geometric boundary even when the largest weight approaches one.

Keys decide; values contribute

Attention uses two different kinds of vectors. A key is compared with a query to determine compatibility. A value is the content being combined. In this experiment the keys are two-dimensional: A points east, B north, C west and D south. The query is the unit vector at your selected angle. The values are three-dimensional and need not point in the same directions as their keys.

Our fixed values are A=(1,1,1), B=(1,−1,−1), C=(−1,1,−1), D=(−1,−1,1). They form a tetrahedron. This choice makes the averaging geometry visible; these are not embeddings extracted from a trained language model.

With key dimension two, we calculate sᵢ = qᵀkᵢ/√2. Temperature T is an additional experimental scale. The attention weights and output are:

aᵢ = exp(sᵢ/T) / Σⱼ exp(sⱼ/T)
o = Σᵢ aᵢvᵢ

The table shows s before division by T. The implementation subtracts the largest active logit before exponentiating, which leaves the ratios unchanged and avoids unnecessary overflow. Masked A receives exactly zero weight; the remaining weights are renormalized. There is no dropout, sampling, output projection or residual connection in this calculation.

The boundary follows from two simple facts

Every active weight is nonnegative and the weights sum to one. A sum with those properties is a convex combination. By definition it lies in the convex hull of the participating values. This is an algebraic restriction, not a trend inferred from the animation.

For the orange target, an even simpler proof works: every available value has first coordinate between −1 and 1. Its weighted average must also lie in that interval. The target's first coordinate is 1.6, so no choice of these nonnegative normalized weights can reach it. Changing a query or temperature changes the weights, not this bound.

With all four values active and finite logits, all weights are strictly positive in exact arithmetic. The output is then inside the tetrahedron rather than exactly on a vertex or face. Very small weights can become visually indistinguishable from zero. The display rounds percentages, but the export retains the numerical values.

Sharp does not always mean one winner

At a query angle of 0°, A has the unique largest score. As T tends toward zero, A's weight tends toward one and the output approaches A. At T=0.05 it is already very close, but this positive temperature is not the mathematical zero-temperature limit.

Now press “Test a tied maximum.” At 45°, A and B have equal largest scores. As T tends toward zero, they each receive half the weight, while C and D vanish. The limiting output is the midpoint (A+B)/2 = (1,0,0), not either winning value. A softmax does not randomly resolve a tie here; there is no sampling step.

With this preset, the two top unnormalized weights are proportional to exp(10), while the lower pair are proportional to exp(−10). Each top weight is 1/[2(1+exp(−20))]. The first output coordinate is tanh(10), about 0.999999996, and the other coordinates are zero up to floating-point error. This is a worked numerical prediction you can verify in the export.

Flattening and masking change different things

As temperature tends to infinity, all finite active scores become negligible relative to T. With four values the weights approach one quarter and the output approaches their centroid, the origin. The slider stops at four, so it demonstrates movement toward that limit without pretending to reach infinity.

Mask A and the green tetrahedron becomes the triangle through B, C and D. The output now lies on that triangle. At high temperature it approaches their centroid, (−1/3,−1/3,−1/3). Masking changes which values can participate; temperature redistributes weight among those still available.

Try the tied-max preset, then exclude A. B becomes the unique best remaining key, so the cold output moves close to B. The query did not change, but the normalization set did. In sequence models, masks similarly remove disallowed positions before normalization; this example uses one explicit exclusion rather than a full causal mask.

A convex hull is an outer bound, not a reachability promise

Staying inside the hull does not mean these particular controls can reach every interior point. Our unit query has one angular degree of freedom, and temperature adds one scale. The key arrangement restricts which score patterns arise. For example, opposite-key scores sum to zero, so before masking the weights satisfy aA·aC = aB·aD. Arbitrary tetrahedral barycentric coordinates need not satisfy that relation.

The gray curve is even more restricted: it varies only temperature while keeping the query fixed. It shows how concentration moves the mixture for that query, not a map of every output the head can produce. This distinction prevents a geometric enclosure from being mistaken for an exact characterization of model capacity.

Where this statement stops

The result applies to the raw normalized weighted sum of these fixed values. A Transformer also learns value projections, combines multiple heads, applies an output projection and includes residual and feed-forward computations. Those operations can produce representations outside the hull of the original displayed values. A linear projection still maps a convex combination to a convex combination of the projected values, but that is a different hull.

Nor are attention weights automatically an explanation of a model's final decision. The value content and all downstream operations matter. Here the entropy is only the Shannon entropy of four mixture weights, in nats; lower entropy is not a measured improvement in accuracy, factuality or confidence calibration.
