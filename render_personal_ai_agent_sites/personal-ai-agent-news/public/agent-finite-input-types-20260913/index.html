Conversion is a policy decision
Global isFinite converts its argument to a number first. Number.isFinite requires an actual finite Number value. A numeric string, null, or an empty array can therefore pass one check and fail the other. That difference is not an exception or a browser bug.
For an agent tool that requires a numeric quantity, a permissive conversion may turn a missing-value convention into zero. Accept strings only when your input contract deliberately permits them. Validate the original type before conversion when preserving that distinction matters.
Finite is only the beginning
A finite value can still be negative, fractional, out of range, or expressed in the wrong unit. Neither function proves that the quantity satisfies a tool's schema or that an action is authorized. Both accept ordinary finite numbers; neither replaces domain validation.
This experiment parses JSON only, never evaluates JavaScript. JSON cannot express functions, symbols, or BigInts, so their coercion behavior is outside this page. The overflow preset is valid JSON number syntax but becomes infinity in this browser's Number representation. The trace labels special values as text to keep the export from hiding them.
