Use permission while it is true.

Authorization is not a timeless property of a task. Scope, time, actor, and environment all shape whether an agent may still take the action it planned.

A permission check at the beginning does not authorize a different world at the end.

Recheck permission at the edge.

The scope is useful, but time and environmental change make a fresh authorization check prudent.

Authorization should travel with a boundary, not a vague intention.

Scope the action

Permissions should name the actor, resource, operation, and conditions. Broad intent is not a safe substitute for scope.

Respect time

As time passes, state and authorization context can drift. Short-lived actions should have short-lived permissions.

Reconfirm consequence

A low-impact read and a high-impact mutation should not share the same authorization threshold or refresh cadence.
