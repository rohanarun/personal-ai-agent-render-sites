Make failure legible

A degraded mode is a product decision, not just an exception handler. The user should know what failed, what the fallback can still do, and what requires a retry or human decision.

  • Reduce permissions with the capability.
  • Preserve a truthful explanation of missing data.
  • Escalate when the fallback could create a new side effect.

Try the trap

Set fallback quality high and side-effect risk high. A polished response can still be a dangerous fallback if it takes action without the missing tool’s evidence.

Do not simulate successA safe fallback says what it cannot verify instead of filling the gap with confidence.
