Keep the search focused

A few branches have enough expected payoff to justify exploration. Stop when new routes stop changing the plan.

Branching compounds

Every extra option multiplies later work. A planner should ask whether the next branch changes the decision, not merely whether it is possible to generate.

Pruning is a feature

Useful agents keep a stopping rule: a budget, a score threshold, or a decision that is already good enough to execute.
