The constraint gate

Make the plan carry its limits.

A constraint is not a note at the edge of a prompt. It is a condition every plan step must satisfy before a tool call or side effect begins.

A useful mental model

Constraints compose across every step.

A plan can be locally reasonable and globally invalid. Propagation keeps the original boundaries attached while the agent decomposes the task.

Carry forward

Put the constraint in the plan state, not only in the initial request.

Check each step

Reject a tool argument that spends more budget or scope than remains.

Stop on violation

When a limit cannot survive, stop and report it. A smaller plan is safer than silently changing the user's boundary.
