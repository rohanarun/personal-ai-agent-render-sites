Rollback is a design decision.

A compensating action is not a magical undo button. It is a second, explicitly designed operation that attempts to restore an invariant after a partial change. The more state an agent mutates without checkpoints, the more uncertainty its recovery must absorb.

Try a high failure chance with low checkpoint coverage, then raise coverage while keeping the failure chance fixed. The same tools become easier to recover because the agent has preserved a trustworthy boundary.
