A good agent treats time as part of the evidence.

Confidence is not a single number. It is confidence that survives the cost of acting, the cost of asking, and the decay of the context that produced it.

Bound the wait

A request for “more information” needs a stopping condition. Otherwise caution becomes an unowned loop.

Re-score the plan

When new evidence arrives, compare it with the action, not just with the previous belief.

Separate uncertainty from urgency

A low-confidence action can still be correct when the alternative is a rapidly expiring opportunity. The right question is whether waiting changes the expected outcome.
