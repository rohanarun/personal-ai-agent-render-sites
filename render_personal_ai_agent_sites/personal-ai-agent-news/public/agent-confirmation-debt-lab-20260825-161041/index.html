A confirmation debt simulator

Unanswered questions compound interest.

An agent can keep moving while a confirmation is pending, but each new side effect makes the original uncertainty more expensive. Tune the debt, urgency, and cost of asking to see when the agent must stop.

Pause is a workflow state, not a failure.

Confirmation debt grows when an agent treats pending authority as background noise. A deliberate pause can preserve drafts while preventing new commitments from inheriting the same unknown.

Count coupled actions

One unresolved fact can affect many drafts, recipients, permissions, or records. Measure the blast radius before continuing.

Preserve reversible work

Keep drafts and analysis, but label them as blocked so they do not quietly become commitments.

Ask one answerable question

Debt is paid by resolving the dependency that unlocks the next safe action, not by collecting broad reassurance.
