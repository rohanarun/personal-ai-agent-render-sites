Same cosine. Different gradient.

Multiplying a nonzero embedding by a positive number leaves its cosine similarity unchanged. Yet the gradient with respect to that embedding becomes smaller. The score ignores radius; the sensitivity to a fixed-size coordinate change does not.

Change length without changing the score
Keep the angles fixed and increase r from 1 to 2. The input arrow and reference sphere grow. Cosine similarity stays fixed, while the gradient arrow becomes half as long. It is drawn from the tip of x, at the same world-unit scale, rather than from the origin. The disk marks directions perpendicular to x.
Now choose Perpendicular. With x = (0, r, 0), the score is zero and the gradient is (1/r, 0, 0). At radius 0.5 its length is 2; at radius 2 its length is 0.5. A fixed coordinate displacement rotates a short vector more than a long one. That geometric fact explains why scale can matter during optimization even when it does not affect the current score.


Differentiate the normalization
Fix a unit target u. Write r = ||x||, n = x/r and c = u dot n. This experiment uses the ordinary cosine for r > 0, with no epsilon modification. From dr = n dot dx, differentiating n gives dn = (I - nn^T) dx / r. Therefore dc = u^T dn, and:
c(x) = (u dot x) / ||x||
gradient c = (u - c n) / r
x dot gradient c = 0
||gradient c|| = sqrt(1 - c*c) / r
The matrix I - nn^T removes the radial component. What remains is the target's projection onto the tangent plane, divided by radius. The implementation uses Three.js vector projection for this operation; the numerical checks compare it with the explicit component formula and finite differences. The rose arrow points toward increasing similarity. For a loss of 1 - c, its negative is the loss gradient, so gradient descent moves along the rose direction.


A zero gradient is not always the desired answer
Aligned gives c = 1 and a zero gradient: every positive multiple of u is a maximum. Opposite gives c = -1 and also a zero gradient. That is a minimum of similarity, not a successful alignment. At the exact antipodal point, first-order information vanishes even though nearby angular perturbations can improve the score.
This is why “small gradient” alone does not establish that an embedding objective reached the intended solution. The example isolates one vector and one fixed target. Real objectives combine many examples and terms; this visual is not a claim that a particular training run will get trapped at this exact point.


Tangent does not mean a finite step stays on the sphere
Let g be the displayed gradient. A raw ascent step x' = x + eta g satisfies ||x'|| squared = r squared + eta squared ||g|| squared because x dot g = 0. Unless the step or gradient is zero, the radius increases. Tangency is a first-order statement, not a promise that a straight segment follows a curved surface.
If an algorithm requires unit vectors after each update, it needs a separate normalization or manifold-aware update. Momentum, preconditioning and additional loss terms can change the update direction too. The scene shows the derivative of this score with respect to x, not an entire optimizer.


Scope and sources
The origin is excluded because ordinary cosine is undefined there. Libraries often stabilize denominators: PyTorch documents an epsilon-clamped norm. Behavior in that small-norm region is not represented by this experiment. Positive rescaling is assumed; multiplying by a negative number reverses direction and changes the sign of the score.
The renderer and vector operations use Three.js Vector3. The gradient formula above follows directly from differentiating normalization. Angles parameterize the input, but the displayed gradient is with respect to its three Cartesian coordinates, not with respect to the angle sliders. No learned model or network request is needed for the experiment.
