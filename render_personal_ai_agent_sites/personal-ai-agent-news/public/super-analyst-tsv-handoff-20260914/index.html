A deliberate handoff

The sample uses inventory identifiers such as 0012 and quantities such as 03. They are text, not numbers to normalize. A quoted cell may contain a tab or newline; splitting on tabs manually would break that cell.

Papa Parse 5.5.3 reads a fixed tab delimiter with double-quote escaping. Empty lines are skipped; tab-only rows are retained. Uneven row widths or parser errors block export. This is a rectangular matrix check, not validation of business meaning. JSON export includes all parsed cells, not just the preview.

Use non-sensitive examples. Pasted text is processed in this page; this tool does not send it to an AI service. The demonstration video below loads from an external host. JSON strings can still become spreadsheet formulas if later imported into other software; this is not a formula-sanitization tool.
