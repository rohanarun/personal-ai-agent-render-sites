A state lease simulator

A snapshot can expire before the action does.

An agent may hold a correct view of a system, but time and mutations can invalidate it. Tune snapshot age, mutation impact, and refresh cost to see when the state lease must be renewed.

Freshness is part of authorization.

A state read is not just information. When it permits a scarce or irreversible mutation, its age and invalidation conditions become part of the permission boundary.

Age the snapshot

Record when a state was observed and what kinds of events could invalidate it.

Match freshness to impact

A stale read may be fine for a preview and unsafe for a reservation, permission grant, or deletion.

Use conditional writes

When possible, make the mutation assert the version it read so the system rejects a changed world safely.
