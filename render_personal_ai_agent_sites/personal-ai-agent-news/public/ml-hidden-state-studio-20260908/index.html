Recover the initial state, not the last state

x(k+1) = A x(k), A = [[cos(theta), -sin(theta)], [sin(theta), cos(theta)]]
y(k) = [1, 0] x(k) + e(k)
O[k,:] = [cos(k theta), -sin(k theta)]
Estimate = pseudoinverse(O) y

Stacking measurements gives y = O x(0) + e. Two independent columns in O identify both initial coordinates in the noiseless case. At zero rotation every row is [1, 0]: changing x2 cannot change any observation. The pseudoinverse returns the minimum-norm answer, with x2 = 0, rather than recovering the invisible coordinate.

Identifiable does not mean insensitive

For a small nonzero angle, the measurement lines are nearly parallel. They still identify a unique state without noise, but their intersection can move substantially when the readings change. The smallest singular value measures the weakest measured direction.

For full column rank: ||estimate - x(0)||2 <= ||e||2 / sigma_min(O)

Extra samples add constraints and cannot decrease the smallest eigenvalue of O-transpose O. That does not guarantee a smaller realized error for this particular alternating error sequence. The sensor error here is deliberately deterministic: e(k) = amplitude times (-1)k, not a random draw or a confidence interval.

ml-matrix supplies the SVD and pseudoinverse, with singular values at or below 1e-10 discarded. The model has no input, process noise, damping, or unknown dynamics. This batch least-squares demonstration is not a Kalman filter. Canvas clicks and arrow keys also change the true initial state; JSON preserves the observations, factors and errors.
