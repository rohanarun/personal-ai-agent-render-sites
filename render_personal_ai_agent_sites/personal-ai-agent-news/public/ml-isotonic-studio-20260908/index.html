When neighbors disagree, pool them

The six x positions stay ordered. The model minimizes the weighted sum of squared distances between observed and fitted y values, with a nondecreasing or nonincreasing constraint. It preserves the x order: sorting the observed y values would pair them with the wrong observations.

In the reset example, the local fall from 5 to 3 is replaced by their average, 4. The next observation is already 4. Later, 8 and 6 pool at 7. The fitted sequence is 1, 4, 4, 4, 7, 7, with weighted squared error 4 when all weights are 1.

Weight is influence, not certainty

Within a pooled region, higher-weight observations pull its weighted average closer to themselves. All weights here are positive. They are synthetic importance weights, not measured confidence. The solver can merge a larger region when a changed average violates another neighbor.

A shape assumption is still an assumption

The bundled PAVA solver fits the observations; straight segments connect its fitted levels between x positions. This is not a forecast or evidence that the true relationship is monotonic. Monotonic fits can be useful in calibration, but a valid calibration study also needs held-out predictions and outcomes. These six synthetic values are only an algorithm demonstration.
