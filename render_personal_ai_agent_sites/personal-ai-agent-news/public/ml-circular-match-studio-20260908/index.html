A peak is not always an identity

The observation is y[j] = x[(j - s) mod 16] + a u[j]. The noise draw u stays fixed while the controls change. Each sample is uniform on [-1, 1].

For real sequences, r[k] = (1/16) sum x[j] y[(j + k) mod 16]. The correlation theorem computes the same values with inverse FFT(conj(FFT(x)) FFT(y)) / 16. This page uses fft.js and checks against the direct sum.

Shifting preserves reference energy, so candidate MSE equals mean(x squared) + mean(y squared) - 2r[k]. Maximizing correlation therefore minimizes this circular alignment error. It is not a centered Pearson coefficient.

A period-four reference cannot distinguish shifts four samples apart, even with this additive observation noise. A constant reference cannot distinguish any shift. Peaks within 10-9 of the maximum are displayed as ties. Noise can move the best lag away from the applied shift; a peak is not a confidence probability.

Indices wrap at sixteen. This is a periodic matching experiment, not a zero-padded linear correlation or a learned recognition model.
