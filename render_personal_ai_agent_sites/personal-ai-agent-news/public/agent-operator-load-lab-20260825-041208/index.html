Spend attention well

Human review works best when the agent makes the question, evidence, and uncertainty easy to scan.

Escalate a decision

Send cases where human judgment changes the outcome, not every case where the agent feels uncertain.

Package the question

Include the decision, evidence, uncertainty, and safe options so review time produces a useful answer.

Defer with a reason

When the lane is overloaded, preserve state and schedule a bounded follow-up instead of creating noise.

This simulation is a teaching model, not a production human-review policy. It demonstrates a contract-first pattern: rank escalation value, package the question, and protect reviewer capacity.
