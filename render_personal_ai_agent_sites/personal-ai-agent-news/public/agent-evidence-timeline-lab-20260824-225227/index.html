What to notice

Freshness changes meaning.
A correct source can become misleading when it describes a world that no longer exists.
Volatility sets the clock.
Stable domains tolerate older context; fast-changing ones require shorter evidence lifetimes.
Order reveals causality.
The latest observation should not automatically win, but its place in the timeline must be explicit.
