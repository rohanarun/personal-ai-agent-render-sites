A useful mental model

Freshness is a claim with a clock and a source.

A fast answer is not necessarily a good answer. Cache policies should preserve the source context and make staleness visible instead of turning yesterday's confidence into today's fact.

Measure age

Know when the answer was produced and when the underlying source last changed.

Compare meaning

Match the new question to the cached intent, not only a similar string.

Refresh deliberately

When trust falls, re-run the source path and record why the cache changed. A refresh is a controlled update, not a silent fallback.
