The transform is a parity test

H[k,x] = (-1)popcount(k AND x)
H r = (H p) times (H q), entry by entry
r = H ((H p) times (H q)) / 8

Here H is the unnormalized, natural binary-order Walsh-Hadamard matrix, with H H = 8 I. The zero mask always has expectation one for a probability distribution. The inverse division by eight restores total probability one.

The paper linked below uses a normalized transform and an averaged dyadic convolution. This page instead uses ordinary probability sums and the unnormalized H, so the scaling above is different but consistent. ml-matrix constructs the transform by Kronecker products and performs the matrix multiplications.

Independent flips can erase structure

Each noise bit flips independently with probability t. Its signed expectation is 1 - 2t. For a parity mask selecting multiple bits, the noise expectation is the product of their signed expectations. A fair flip at t = 0.5 erases every parity involving that bit.

With all three flips fair, the output is uniform regardless of the input. With no flips, the output equals the input. A deterministic mask only permutes the input probabilities. The linked preset has correlated input bits; the independence assumption applies to the noise bits and to the noise versus the input, not to the input bits themselves.

This is an exact finite-distribution demonstration of a binary corruption channel used in reasoning about noisy features. It is not a learned model, a security guarantee, or a simulation of dependent noise. Displayed values are rounded; JSON retains full double precision.
