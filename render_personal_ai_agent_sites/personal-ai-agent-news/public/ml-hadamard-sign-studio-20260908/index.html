Equal lengths do not guarantee independent directions

Hadamard's determinant inequality bounds absolute determinant by the product of column lengths. For this 4 by 4 sign matrix, every column length is 2, so the bound is 16.

|det(A)| <= product_j ||column_j|| = 2^4 = 16
At equality: A transpose A = 4 I
All four singular values then equal 2.

A sign matrix with mutually orthogonal columns is a Hadamard matrix. Parallel or redundant directions lose volume. The normalized determinant measures the fraction of the length-based bound attained, not prediction accuracy.

ml-matrix computes the determinant, Gram matrix and singular values. The example uses the recursive Sylvester construction. Flipping a whole row or column preserves absolute determinant; flipping one entry need not. Random signs are generated locally, and no optimization or model API is used.
