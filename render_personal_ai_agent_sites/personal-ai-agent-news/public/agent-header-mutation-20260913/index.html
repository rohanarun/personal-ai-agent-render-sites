Try an accidental duplicate
The example starts with X-Task: fetch. Append "verify" to produce "fetch, verify"; set "verify" to replace it. Change the name to x-task and observe that casing does not create a separate field. Delete removes that field.
Local acceptance is not delivery
Headers normalizes names and trims surrounding value whitespace. Invalid names or values can throw TypeError. Real requests have additional restrictions; this unguarded object does not test CORS, forbidden request headers, or server interpretation.
Not every HTTP field has list semantics. Do not infer from this custom-header example that joining arbitrary values is correct. The displayed entries are the browser's iterable representation, not a raw wire capture.
