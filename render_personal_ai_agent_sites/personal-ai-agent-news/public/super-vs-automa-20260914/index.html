What the computer-use cache actually stores

The inspected Super Powers AI implementation saves verified workflows with runnable Python steps. A successful lookup returns workflow, verification reason and output evidence. It is execution-procedure reuse rather than only cached prose. Eligibility includes owner and task or source context, verified-complete storage, and a safe match.

Missing context, an empty cache or no safe match returns a miss; the caller must choose the uncached path. Matching may incur model usage. Reuse can avoid reconstructing an eligible procedure, but these code paths do not establish a speedup, a saving, or availability for every account.
