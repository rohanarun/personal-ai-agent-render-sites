What equality tells you

This tool compares every byte, not just the fingerprints. Renaming a file does not change its contents. A newline, encoding change or embedded metadata can change the bytes even when two documents look identical.

Equal files can both contain the same error. Different files can be equivalent for your purpose. This is not a semantic diff, malware scan, signature check or proof of who created a file.

A practical handoff

Illustrative example: review a generated HTML file, then download the delivered artifact and compare it here. A mismatch is a reason to inspect the change, not automatic evidence of wrongdoing. A match does not verify linked scripts, remote data, other files, runtime behavior or the server configuration.

How this relates to Super

Super's product page describes browser tools, cloud apps and sandboxes. Its computer-use cache aims to reuse successful actions. In inspected source, verified workflow storage requires a completion confirmation and runnable workflow data; lookup returns a matched workflow with verification information or a miss.

The caller handles a lookup miss. The lookup is not itself a fallback executor. These code paths do not prove every live task uses the cache, establish measured savings, or make an output correct. This comparator is independent of that cache and does not submit work to Super.
