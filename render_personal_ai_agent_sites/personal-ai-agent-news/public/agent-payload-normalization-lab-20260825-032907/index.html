Useful distinctions

A robust contract makes these states visible instead of relying on a guess.

Missing is not empty

An absent field can mean a producer failed to send it. An empty list can be a valid, complete result.

Null is a signal

Null may encode “not applicable,” “not loaded,” or “unknown.” Preserve the reason when the next action depends on it.

Annotate the loss

If a lossy transform is necessary, attach what changed so the agent can gate high-impact actions on the original evidence.

This simulation is a teaching model, not a production parser. It demonstrates a contract-first pattern: transform deliberately, preserve provenance, and validate before acting.
