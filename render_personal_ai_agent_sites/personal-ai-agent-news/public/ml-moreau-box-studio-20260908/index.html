One point, two optimization problems

p = argminᵤ { λ‖u‖₁ + ½‖u−v‖₂² }
q = argmin|zᵢ|≤λ ½‖z−v‖₂²
v = p + q

The box projection is solved by quadprog, a constrained quadratic-programming library. The remainder p = v−q is the L1 proximal point. A coordinate with |vᵢ| ≤ λ disappears from p; larger coordinates shrink toward zero by λ.

Duality, not necessarily a right angle

For f(u) = λ‖u‖₁, the convex conjugate f* is the indicator of the box [−λ,λ]². Moreau's identity splits v into proxf(v) and proxf*(v). An indicator's proximal operator is a projection.

In this example p · q = λ‖p‖₁. It is positive whenever p is nonzero. Thus the decomposition should not be mistaken for an orthogonal projection onto complementary subspaces.

The primal objective at p equals the dual objective v · q − ½‖q‖₂². The displayed gap tests their agreement, up to floating-point error. This is a two-coordinate L1 proximal step, not a complete Lasso model.
