Back off cooperatively

The state matters and the lock is crowded. Add jitter, a lease, or a queue so workers stop competing blindly.

Locks need leases

A lock without expiry can turn a crashed worker into a permanent blocker. Make ownership, duration, and recovery explicit.

Yielding is progress

When contention is high, a bounded pause can improve throughput. A worker that keeps colliding is spending budget without advancing state.
