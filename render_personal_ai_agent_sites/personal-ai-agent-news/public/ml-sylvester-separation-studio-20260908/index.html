Four-variable operator K

Column-major order: X11, X21, X12, X22. K = I ⊗ A - B^T ⊗ I.

Why the eigenvalue gap is not enough

The Sylvester equation A X - X B = C has a unique solution for every C exactly when A and B share no eigenvalue. Vectorization turns it into an ordinary linear system K vec(X) = vec(C).

Separation is the smallest singular value of K. Its reciprocal bounds the change in X per unit change in C, using Frobenius norms. For nonnormal matrices, separation can be much smaller than the nearest eigenvalue gap. Increase coupling while keeping shift fixed to see the distinction.

At a shared eigenvalue, K is singular: a right-hand side may have no solution or many. This studio withholds a unique answer rather than silently selecting a pseudoinverse solution. The numerical singularity threshold is 10^-10.

Read the perturbation, not just the colors

The selected basis entry receives epsilon, so the size of the input change is |epsilon|. The observed output change is ||Xperturbed - Xbase||F; it cannot exceed |epsilon| / separation when a unique solution exists. A single basis perturbation need not attain that worst-case bound.

The two panels display solutions, not probabilities or model confidence. Their shared color scale changes with the controls, so compare the printed numbers across different settings. The four-variable construction is deliberately small: ml-matrix SVD measures separation and QR solves both systems. Large production Sylvester solvers typically exploit matrix structure rather than explicitly constructing this operator.
