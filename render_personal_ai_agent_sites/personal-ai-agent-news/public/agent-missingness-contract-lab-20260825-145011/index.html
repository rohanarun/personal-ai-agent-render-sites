Honest uncertainty needs a shape.

An agent that collapses “no results” and “no observation” will sound confident precisely when it should ask for another measurement. A missingness contract keeps the state visible and makes retries and escalation explainable.

This is a compact teaching model. Production systems still need explicit schemas, timeouts, provenance, access controls, and human review for consequential decisions.
