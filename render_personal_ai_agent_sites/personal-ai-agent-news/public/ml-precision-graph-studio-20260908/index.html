Missing edge, surviving association

In the chain preset, variables 1 and 3 are correlated. But their partial correlation given variable 2 is zero. For this jointly Gaussian model, that zero means conditional independence. It does not mean marginal independence or establish a causal direction.

Sigma = inverse(K)
r(i,j) = Sigma(i,j) / sqrt(Sigma(i,i) Sigma(j,j))
partial r(i,j) = -K(i,j) / sqrt(K(i,i) K(j,j))

K is the precision matrix. We construct K(i,i) = 1 + sum of incident absolute couplings, and K(i,j) = -coupling(i,j). This symmetric, strictly diagonally dominant matrix is positive definite, so it defines a valid nonsingular Gaussian covariance for every allowed setting.

The scikit-learn covariance documentation explains how sparse precision matrices represent conditional relationships. Here the matrix is specified directly, not estimated with graphical lasso.

All values are exact model quantities up to floating-point arithmetic, not sample estimates or significance tests. Outside a jointly Gaussian distribution, a zero partial correlation alone does not generally imply conditional independence. Export includes K, Sigma, both correlation matrices, and the inverse residual.
