Square roots turn overlap into an inner product

Using the normalized convention, squared Hellinger distance is half the squared Euclidean distance between square-root probability vectors. Their inner product is the affinity B.

B(P,Q) = sum_x sqrt(P(x) Q(x))
H squared = 1 - B(P,Q)
B for n independent observations = B(P,Q)^n

The product identity follows by factoring the sum over all independent outcome sequences into n identical sums. Hence H squared becomes 1 - B^n. This derivation requires independent observations under each model; correlated repeats do not justify this formula.

For these Bernoulli models, all sequences with the same count have equal probabilities. Grouping them by count therefore preserves affinity exactly. jStat evaluates the binomial probabilities; the table independently compares their square-root overlap with the product identity. Some references omit the factor one-half; this page uses the normalized convention throughout.
