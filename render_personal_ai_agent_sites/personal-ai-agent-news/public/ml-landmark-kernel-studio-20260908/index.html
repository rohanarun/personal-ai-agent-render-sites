The overlap corrects double counting

Let S be the selected indices, C = K[:, S], and W = K[S, S]. The approximation is C W pseudoinverse C transpose. The overlap W tells us how the selected columns relate to one another; simply adding their outer products would ignore this relationship.

This implementation retains singular values of W above an absolute 1e-10 cutoff, without ridge regularization. Repeated locations make some columns redundant. The pseudoinverse handles that rank loss; selecting another copy need not add information. Selecting all points reconstructs K up to numerical cutoff and rounding. With no landmarks, the explicitly defined approximation is zero.

Approximation is not a fitted predictor

This is a matrix reconstruction experiment, not a trained classifier. A broad kernel shares similarity over longer distances; a narrow one needs more local coverage. We construct the full K here to measure error, so this small demonstration does not realize the memory savings of a large-scale implementation. No random-sampling error guarantee is claimed for manual landmark choices.

Drineas and Mahoney, JMLR (2005) describe the selected-column, overlap-pseudoinverse form and analyze a randomized method. Our eight-point arrangements and manual selections are separate worked examples.
