Object identity and outcome are separate
Every run constructs one native base promise. Both wrapper calls return access to that same underlying result. In async mode, each call produces a new promise object that adopts the base promise's outcome. Neither wrapper promise is strictly equal to the base or to the other wrapper.
A plain function returning base preserves the object. Promise.resolve(base) also returns this same native promise in the shown case. The two returned values therefore occupy one Set entry in those modes and two in async mode.
The async function reference documents this identity distinction. The result comparisons here are native JavaScript observations, not simulated identities.
What a task registry might get wrong
An illustrative agent registry uses the returned promise as a key. Adding an async wrapper around an existing shared promise can make two callers appear to hold different operations. But the counter in this lab shows one base executor invocation, not two independent jobs.
The opposite inference is also unsafe: equal fulfilled values do not prove two operations were the same. This fixture intentionally uses one shared base. A real registry needs a task identity and lifecycle contract suited to the work, including when an entry expires or is replaced.
Read the evidence boundaries
Identity checks occur before resolving the base. The lab then awaits both results, which are the same plain string. No timer, browser action or remote call is involved. The base-executor counter is local instrumentation, not a count of external requests.
The Promise.resolve case uses a native promise from this realm with the ordinary constructor. Subclasses, cross-realm promises, thenables and modified constructors can introduce other behavior. This is not a general promise-equivalence test or a performance comparison.
Every run creates a fresh base and wrappers. Controls remain disabled during settlement; changing the wrapper clears old evidence. No model API is called. Published September 14, 2026 by Super Powers AI.
