Justification should travel with the write.

When an agent separates evidence from action, the operation can look more certain than the observation beneath it. A proof-carrying action keeps its scope, support, and rollback path together at the decision boundary.

This is a compact teaching model. Production systems still need provenance, explicit authorization, rollback paths, and human review for consequential work.
