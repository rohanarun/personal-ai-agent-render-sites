Handoff is a capability, not a confession.

An agent can be highly capable and still be the wrong decision-maker for a moment. A request may be within its tools but outside its confidence, or technically easy but personally consequential. An escalation threshold makes that boundary explicit before momentum turns into overreach.

This lab turns the boundary into four visible signals. Uncertainty and user impact raise the need for a person. Autonomy scope creates room to act, while time pressure can tempt an agent to skip a handoff. The score is a teaching device, not a policy engine; use it to ask which value should win.
