Try the broken boundary
The high-surrogate example contains an unmatched code unit. JSON preserves it as an escape, but encodeURIComponent throws URIError. Pair it with a low surrogate and URI encoding succeeds. Reverse the pair to see two replacements instead of one.
Replacement is not recovery
toWellFormed replaces lone surrogates with U+FFFD and preserves valid pairs. Two different malformed inputs can therefore produce the same result. Keep the original evidence when diagnosing a failed handoff; silently replacing input may hide its cause.
This differs from Unicode normalization, which addresses equivalent representations. Neither operation verifies an agent's answer. This tool runs native browser string and encoding methods, not a tokenizer or model.
