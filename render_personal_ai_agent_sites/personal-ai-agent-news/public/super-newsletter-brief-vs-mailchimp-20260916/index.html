A workflow for a small association
  1. Define the issue. Name the audience and the one action you want readers to take. Use an audience description in the research brief, not a copied subscriber list.
  2. Collect original references. Prefer the organizer's announcement for event details and the original publication for a research item. Record the date checked; a source can change after drafting.
  3. Separate facts from decisions. Keep “confirmed event date,” “suggested headline” and “question for the editor” as different fields. A fluent summary must not silently remove “may” or “proposed.”
  4. Approve the content, then test the campaign. Move reviewed copy into the email platform. Check the actual links, rendering and recipient selection there; the brief is not the campaign.
Illustrative Super request: “Prepare three candidate items using only these approved sources. For each, provide a proposed summary, original reference, uncertainty and a question for the editor. Preserve conditional wording. Do not send email, import contacts or claim approval.”
If a deadline arrives before a date is confirmed, omit the announcement or explicitly state the uncertainty if the editor decides that is useful. Do not let a tool turn a deadline into evidence. This is authored workflow guidance, not a demonstrated customer outcome.
