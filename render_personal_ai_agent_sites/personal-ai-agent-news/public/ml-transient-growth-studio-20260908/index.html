Coupling changes the transient

The update is x at t+1 = A x at t, with A = [[r, k], [0, r]]. Both eigenvalues are r. When k is nonzero, the matrix is nonnormal: it does not commute with its transpose. The second coordinate feeds the first, allowing temporary growth that eigenvalue magnitudes alone do not describe.

For r strictly below one, every trajectory eventually tends to zero. Yet a nonnormal matrix can amplify a perturbation before that decay. The uncoupled case k = 0 gives A = rI, so every unit initial direction has norm r to the power t.

Direction matters

The teal curve follows one selected initial vector (cos(angle), sin(angle)). The pink curve computes the Euclidean operator norm of each matrix power using ml-matrix SVD. It is an upper bound for the teal curve at every step. The maximizing initial direction can differ between steps; the pink curve is not generally one fixed-vector trajectory.

At angle zero, the second coordinate vanishes and the coupling has nothing to transfer. At 90 degrees, it is fully excited. This makes a useful counterexample to treating eigenvalue stability as a bound on short-run hidden-state magnitudes in a recurrent linear model.

Separate the limits

At r = 1 and k = 0, the state is constant. At r = 1 with k nonzero, some trajectories grow linearly rather than decay. Above one, growing eigenvalues preclude asymptotic stability. At r = 0, this matrix squares to zero and every trajectory vanishes after at most two steps.

The display covers steps 0 through 60, not an infinite-time peak. Log mode floors plotted norms at 1e-8; exported values and inspected norms are not floored. No nonlinearity, external forcing, training, or gradient computation is simulated. Real neural systems can depart from this fixed-matrix model, and this experiment does not diagnose any deployed model.
