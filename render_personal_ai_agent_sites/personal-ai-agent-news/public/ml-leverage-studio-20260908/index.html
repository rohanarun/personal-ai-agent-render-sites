Position is not error

For ordinary least squares, the hat matrix H maps observed responses y to fitted responses Hy. Its diagonal h measures leverage: how much a response influences its own fitted value. It depends on the input positions and design columns, not the response values. Moving point 6 vertically changes its residual but leaves leverage unchanged.

This model has an intercept and one slope. Its six leverage values sum to two, the number of independent design columns. An unusual x position can have high leverage while lying close to the trend. Leverage alone is not evidence of a mislabeled or invalid observation.

Training can conceal a disagreement

The fitted residual is y minus the all-points prediction. The leave-one-out residual predicts that observation using a fit to the other five points. For full-rank ordinary least squares it equals residual / (1 - leverage), when the omitted fit is also full rank. Near-one leverage can magnify the difference dramatically.

The table uses six actual refits, one for each held-out observation. Export also contains the shortcut calculation and the hat matrix. Both routes should agree up to floating-point error. QR decomposition from ml-matrix performs the solves.

A diagnostic, not a deletion rule

These six synthetic observations are a controlled demonstration. A large leave-one-out error can flag sensitivity worth investigating, but does not establish a causal problem or justify deleting a real observation. If a distant point is held out, predicting it may require extrapolation beyond the remaining inputs.

The reported training and leave-one-out RMSE use six residuals each. Neither is a guaranteed future error estimate for a real deployment, especially with dependent observations or distribution shift. All displayed fits remain full rank because the five fixed observations span multiple input positions.
