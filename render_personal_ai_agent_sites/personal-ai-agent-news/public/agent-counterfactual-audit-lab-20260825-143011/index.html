A useful mental model

One changed premise can reveal a hidden policy.

Counterfactuals are not predictions. They are audits of what the plan depends on, and a way to make those dependencies legible to the next operator.

Name assumptions

State the condition that makes the planned action look safe.

Perturb one

Change a single meaningful input and compare the result.

Keep the finding

If the action changes, preserve that sensitivity as part of the decision record. A brittle plan should not look robust merely because the original case was convenient.
