Structured generation

Validation after generation is already too late.

A model may know JSON and still sample a missing quote, unknown key, or wrong value type. Constrained decoding checks the current prefix before each token and sets every grammar-breaking token’s probability to zero.

The decoding loop

Compile. Mask. Sample.

Compile the schema

JSON Schema becomes a grammar or automaton whose states represent valid prefixes and whose transitions represent legal terminals.

schema → grammar → automaton

Intersect with tokens

At each step, the decoder tests vocabulary tokens against valid continuations. Impossible tokens receive negative-infinity logits.

logit(t) = −∞ if transition(t) fails

Sample normally

Softmax and temperature still rank the surviving choices. The model retains semantic freedom inside a syntactically safe corridor.

sample softmax(masked logits / T)

Prefix validity

A valid final document is not enough. Every partial prefix must still be extendable into a document accepted by the schema.

Tokenizer boundaries

Tokens can contain multiple characters or partial literals. Practical decoders must match token byte sequences, not assume one token equals one grammar symbol.

Semantic limits

A schema guarantees shape, not truth. A valid tool name and argument type can still encode the wrong action, entity, or value.
