Keep three values apart

“True,” “false,” and “unknown” are different operational states. A reliable agent makes the missing observation visible instead of converting absence into a confident claim.

  • Record what was observed and when.
  • Calibrate confidence against actual coverage.
  • Use a safer default when the cost of guessing is high.

Try the trap

Raise model confidence while keeping coverage low. Notice that a confident answer can still have a large unknown surface.
