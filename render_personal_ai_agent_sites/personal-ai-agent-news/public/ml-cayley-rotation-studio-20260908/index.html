The state follows x prime = Sx, where S = [[0, -w], [w, 0]]. S is skew-symmetric. The exact solution rotates by wh radians per step and preserves length. Euler uses E = I + hS. The Cayley update solves (I - hS/2) C = I + hS/2; no explicit inverse is formed here.

An orthogonal matrix preserves Euclidean length. The Cayley transform of a real skew-symmetric matrix is orthogonal, as is its exponential. Here C is that transform with the sign and scale chosen to approximate forward rotation.

Preserving one property is not exact simulation

For this two-dimensional family, let q = wh. Direct substitution gives Euler's length multiplier sqrt(1 + q squared) and angle atan(q). Cayley's multiplier is 1 and its angle is 2 atan(q/2). The exact angle is q. Both discrete methods lag for positive q, but only Euler grows in radius.

After N steps, Euler's radius is (1 + q squared) to the power N/2. Cayley's accumulated lag is N times [q - 2 atan(q/2)]. Reducing h while holding N fixed also reduces the simulated time; compare at the same Nh when judging convergence.

This is a synthetic linear state-update experiment, useful for inspecting repeated transformations in numerical and learning systems. It does not train a network or establish that a particular neural architecture will be stable. Length preservation alone does not guarantee accurate dynamics.

The analytic formulas above follow from this displayed 2-by-2 system. Matrix solves and trajectory products use ml-matrix. Values are computed in floating-point arithmetic; tiny norm errors are expected. Play advances N only and stops at 20.
