A useful mental model

Semantic drift is a safety signal.

When an agent's plan quietly changes the objective, the problem is not only quality. It is authority: the agent is choosing a different action than the user asked for.

Restate the goal

Keep the intended outcome visible before selecting a tool or sequence.

Compare the plan

Check whether each step serves the goal and stays within the requested scope.

Rewrite before acting

If the plan has drifted, do not patch the mismatch with extra effort. Return to the goal, ask for the missing decision, and build a new bounded plan.
