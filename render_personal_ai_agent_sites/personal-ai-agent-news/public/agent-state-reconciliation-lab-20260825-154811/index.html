A state transition needs one source of truth.

Working memory helps an agent reason, but it should not outrank the service that owns the state. Reconciliation is the pause that prevents a plausible note from becoming a false mutation.

Separate memory from authority

Notes, summaries, and cached context are useful inputs. They are not automatically the state owner.

Measure mismatch impact

A disagreement matters most when it changes the next tool call, recipient, permission, or user-facing claim.

Re-plan after refresh

Refreshing the record is not the end of the workflow. It is the point where an agent should recompute the safe next action.
