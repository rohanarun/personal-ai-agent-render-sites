Exploration has an endpoint

A plan does not become safe because every possibility was checked. Define the evidence threshold and the next fact that would change the decision.

Commitments need escape hatches

When a plan closes options, keep a rollback, checkpoint, or review trigger so the agent can adapt without pretending the first choice was final.
