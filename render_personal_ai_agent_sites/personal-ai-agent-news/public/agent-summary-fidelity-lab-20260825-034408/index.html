Summarize with care

Good compression makes the next decision easier without making the evidence invisible.

Keep decision facts

Retain the constraints, exceptions, and values that would change the agent’s next action.

Keep uncertainty visible

Use caveats and confidence markers when the source is incomplete or the summary is an inference.

Keep a path back

Attach citations, timestamps, or a raw-record pointer so a later step can audit the compressed claim.

This simulation is a teaching model, not a production summarizer. It demonstrates a contract-first pattern: compress deliberately, preserve decision-critical facts, and make the source recoverable.
