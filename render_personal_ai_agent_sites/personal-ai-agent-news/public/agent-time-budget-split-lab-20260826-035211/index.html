Budget the uncertainty, not just the steps.

Some work reduces uncertainty before a side effect. Some work creates the side effect itself. A useful time budget recognizes that those steps have different failure costs.

Make the allocation observable. When the agent is slow, the question is not only “how long did it take?” but “which uncertainty did the extra time resolve, and what did it leave unfinished?”
