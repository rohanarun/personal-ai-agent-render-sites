The claim is plausible, not proven.

A tool acknowledgement shows that a request was received. It does not yet establish the resulting state for the partner.

ClaimThe agent says it acted.
AcknowledgedThe tool accepted the request.
Proven stateThe environment confirms the outcome.
Recommended posture: report the request as accepted, not the delivery as complete.

Confidence should stop at the last proven layer.

Observability is a chain. When the chain ends at a tool acknowledgement, an agent should preserve that boundary in its language, recovery logic, and handoff packet.

Name the layer

“Requested,” “accepted,” and “completed” are different states. A trustworthy agent does not collapse them into one verb.

Prefer the record

Independent state evidence can resolve the gap without trusting the same agent claim that created it.

Make uncertainty useful

When proof stops early, tell the next operator exactly which layer is known and which state still needs confirmation.
