The checkpoint is useful, but validate the volatile parts before resuming a sensitive action.

A saved plan is not a saved world.

Agents pause for many reasons: a user closes a tab, a tool times out, a process restarts, or a task waits for approval. A checkpoint lets work continue, but only if the saved state still describes the world it will touch. Otherwise, resuming can turn stale assumptions into fresh side effects.

This lab makes the tradeoff visible. Coverage and restoration confidence create integrity. Volatility and sensitive actions consume it. The score is a teaching device, not a storage guarantee; use it to decide which facts must be re-read before the next tool call.
