What the controls mean

Approval window sets how long the agent pauses. Action risk raises the cost of a late intervention. Operator availability estimates whether a reviewer can actually respond in time.

Human-in-the-loop is system design.

An approval button does not create meaningful oversight by itself. The timing, context, and consequence of an intervention determine whether it can change the outcome.

Make the boundary measurable: when does the pause begin, what evidence does the reviewer see, and what happens if no one responds? Those answers belong in the agent's operating contract.
