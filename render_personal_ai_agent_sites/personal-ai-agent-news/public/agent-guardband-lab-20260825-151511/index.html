Margins make uncertainty actionable.

A plan can be plausible and still be too close to its failure boundary. Keeping a measurable band gives an agent a reason to preview, narrow, or stop before the impact is already real.

This is a compact teaching model. Production systems still need explicit permissions, rollback paths, provenance, and human review for consequential work.
