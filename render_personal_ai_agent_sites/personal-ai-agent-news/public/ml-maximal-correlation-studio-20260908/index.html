Search over functions, not just straight lines

Maximal correlation maximizes E[f(X)g(Y)] over zero-mean, unit-variance recodings. For finite variables with positive marginals, it equals the second singular value of the normalized joint matrix:

B[x,y] = P(x,y) / sqrt(P(x) P(y))
rho_max = sigma_2(B)

Here P(X) = [0.25 + s, 0.5, 0.25 - s]. At s = 0, symmetry makes ordinary correlation zero. Yet the squared value predicts Y unless the flip probability is 50%. Since Y is binary, optimizing f alone suffices up to a sign change.

ml-matrix computes the normalized matrix and its SVD. The displayed optimal scores standardize E[Y | X]; at independence any nonconstant recoding is optimal, and standardized X is shown. Scores are computed from the exact distribution, not fitted to samples. The leading singular value is the constant mode and is excluded.
