Which operation matches your intent?
Append adds another pair. Set keeps one value for that name and removes its other occurrences. Get returns the first matching value; getAll returns every match. Delete here removes every pair with that name.
An agent request example
Illustrative task: an agent filters a library by two tags. If that API expects repeated tag parameters, converting the query to a plain object can discard a value. But another API may expect a comma-separated string or a JSON array. Follow the destination's contract, not the appearance of the URL.
Try setting tag to tools, then resetting and appending tools. Compare the entry count and getAll result. An empty string is a present value; a missing name produces null from get and an empty array from getAll.
Encoding is not validation
In this form-style parser, a plus in an input query decodes to a space. An appended literal plus is encoded as %2B. The serialized spelling may differ from what you typed while retaining the parsed values.
This does not decide whether a server accepts duplicates, whether order matters to that server, or whether a request is authorized. It is not a request-signature canonicalizer. Do not paste credentials or private query data.
