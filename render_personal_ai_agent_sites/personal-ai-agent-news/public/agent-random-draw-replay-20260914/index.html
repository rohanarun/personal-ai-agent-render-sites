      Same seed, different position

      Draw in both lanes: the two independent generators advance together. An extra draw in B consumes one value even though A stays still. The next paired draw now compares different positions in the same sequence. Restarting both lanes from the same seed restores their starting state.

      This illustrative agent routes a trial to one of four actions: inspect, compare, summarize or verify. The action is selected by floor(value × 4). Equal actions do not prove equal draws: different numbers can land in the same bucket. The full decimal value and draw index are therefore retained in the record.

      What a replay needs

      A seeded pseudorandom generator makes this local experiment repeatable. In a larger agent, record the generator and version, seed, draw order, inputs and relevant code. A branch, retry or concurrent task can consume additional randomness. A seed alone does not reproduce changing tool responses, external services or model outputs.

      These are synthetic choices, not an LLM sampling implementation. No model is called. This predictable generator is not suitable for secrets or security tokens. Each lane is a local seedrandom instance; the page does not replace Math.random globally.

      Read the evidence

      The pinned seedrandom 3.0.5 source and documentation describe repeatable local generators. The export includes all button actions, both draw histories and the active seed. Editing the seed takes effect only when both lanes restart; the status always shows the active seed. A session is limited to 100 draws per lane to keep the trace inspectable.
