    Keep the reference, not just the hex

    Each sample includes its pixel coordinates and RGBA values. Use an image you have permission to work with. Larger images are downscaled to fit within 1200 pixels on the longest side; exported coordinates refer to that working image.

    The sampler reads the browser-decoded canvas, not a print-proof color measurement. Resampling, transparency, and color conversion can affect values. A transparent pixel's RGB is not its appearance against a background. This tool does not evaluate contrast or accessibility.

    The file is processed in this page and not uploaded by the sampler. A new image clears previous samples; reload resets the page. Export retains the sample list, not the image itself.
