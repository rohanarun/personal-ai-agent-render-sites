The optimal noise points backward

h(a) = -a log2(a) - (1-a) log2(1-a)
R(D) = h(p) - h(D), 0 <= D <= min(p,1-p)
R(D) = 0 beyond that threshold

For the optimal joint distribution, imagine Z first, then independently flip it with probability D to obtain X. Choosing P(Z=1) = (p-D)/(1-2D) preserves the required source marginal. This gives H(X|Z)=h(D), attaining the lower bound I(X;Z) >= h(p)-h(D).

Flipping X forward instead produces P(Z=1)=p+D-2pD and information h(p+D-2pD)-h(D). For a biased source this is generally larger. At the zero-rate threshold, a constant reconstruction suffices. For p=D=1/2, this page uses independent fair X and Z to avoid the indeterminate fraction.

R(D) is an asymptotic compression limit for long blocks under average distortion, not an implemented compressor or an exact finite-file size. Both tables are single-letter test distributions. ml-matrix constructs their joint probabilities; logarithms are base two.
