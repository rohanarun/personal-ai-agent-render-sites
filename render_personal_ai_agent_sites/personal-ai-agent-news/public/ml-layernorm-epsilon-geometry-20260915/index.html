Layer normalization:
the epsilon geometry

Centering removes a shared offset. Scaling does not quite put every vector on the same circle: epsilon pulls low-variance inputs inward. This three-feature experiment makes both operations visible.

First remove one direction
Here one point represents three feature values, not three training examples. The diagonal direction (1, 1, 1) changes all features equally. Subtracting their mean projects the point onto the plane x1 + x2 + x3 = 0. Blue-to-green is that projection; green-to-rose is rescaling along the centered direction.
Layer normalization computes statistics within an example rather than across a batch. The original formulation also applies learned per-feature gain and bias afterward. We hold those at one and zero to isolate normalization. Ba, Kiros and Hinton, 2016.
Drag the scene to orbit. Change the shared offset while keeping everything else fixed: the blue point moves, while the centered and normalized points stay in place up to numerical rounding. The three gray axes are the individual feature coordinates; the colored plane is the zero-sum plane.


Then divide by more than the standard deviation
mean = (x1 + x2 + x3) / 3
variance = sum((xi - mean)^2) / 3
yi = (xi - mean) / sqrt(variance + epsilon)
The denominator uses population variance, dividing by three, not two. Epsilon is inside the square root. These conventions match the documented PyTorch LayerNorm definition.
Let a be the length after centering. Then variance = a^2 / 3. Our algebra gives:
length(y) = a / sqrt(a^2 / 3 + epsilon)
variance(y) = variance / (variance + epsilon)
For nonconstant input with epsilon zero, length(y) would equal sqrt(3). The gold circle is that reference. With positive epsilon, the output lies inside it. This is why "LayerNorm always gives unit variance" is not exact, even before learned affine parameters.


Three experiments worth trying
  1. Keep the direction, shrink the signal. Select near-constant input. With a = 0.01 and epsilon = 0.1, input variance is about 0.0000333 and output length is about 0.0316. Epsilon dominates, so the output stays close to the origin.
  2. Make epsilon small. Set a = 1, then epsilon = 0.00001. The normalized point nearly reaches the circle. Positive rescaling is approximately invisible only when variance is large compared with epsilon.
  3. Erase every difference. Select constant input. All features equal m, centering returns zero and positive epsilon keeps division finite. Setting epsilon to zero here would make the expression undefined; this experiment deliberately excludes that setting.


What this does not prove
A real hidden state usually has many more than three features. Its zero-mean space has dimension d - 1 and its zero-epsilon reference radius is sqrt(d). Per-feature learned gains and biases can change both the mean and radius after normalization. This forward-pass geometry does not measure training stability, model quality, gradients or a speedup, and it is not RMSNorm, which does not subtract the mean.
The computation uses locally bundled TensorFlow.js 4.22.0 CPU operations, including tf.moments, in float32. Small residual sums and offset-dependent rounding are numerical effects. Three.js 0.180.0 renders the same computed coordinates; there are no inference requests or remote model calls.
