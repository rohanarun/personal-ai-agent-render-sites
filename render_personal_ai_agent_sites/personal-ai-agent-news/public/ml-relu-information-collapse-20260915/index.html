Where ReLU loses information

Different inputs can become the same point. A small leak prevents that exact collision, not every numerical problem.

A coordinate map, not a trained network

For each scalar coordinate t, the activation is f_a(t) = t if t >= 0, otherwise a t. Apply it independently to x, y and z. At a = 0 this is ReLU; at a = 1 it is the identity. This experiment restricts a to [0, 1]. The definitions are documented by PyTorch ReLU and LeakyReLU.

The gray reference is the cube [-1, 1]3. The rose lattice samples five values per coordinate, making 125 input points. It is not a data distribution or a probability model. At zero slope, all negative coordinates become zero: the output cube is [0, 1]3, while entire input regions collapse onto its faces, edges and origin.

Follow an actual collision

The tracked inputs are A = (-0.8, 0.5, 0.3) and B = (-0.2, 0.5, 0.3). Their distance is 0.6. Only their first coordinate differs, so the output distance is 0.6 a. At ReLU, both become (0, 0.5, 0.3). There is no inverse function that can tell which of these inputs produced that output without additional information.

The sampled lattice has only 27 distinct outputs at a = 0: each coordinate has the three possible values 0, 0.5 and 1. Any positive slope keeps all 125 sampled outputs distinct in exact arithmetic. That count describes this chosen lattice, not a universal number of neural-network states. The two larger teal markers may visually overlap at small slopes even when their numerical distance is positive.

Invertible is not the same as robust

For a > 0 the scalar inverse is y on the nonnegative branch and y/a on the negative branch. A perturbation in a negative output coordinate is therefore magnified by 1/a when inverted. At a = 0.01, an error of 0.0001 within that branch becomes an input error of 0.01. No exact collision is required for reconstruction to be sensitive.

Inside the strictly negative octant the Jacobian is a times the identity, with determinant a3. At a = 0.1 its local volume scale is 0.001. This is not the volume ratio for the whole input cube. Other octants have different numbers of negative coordinates, and the map has a kink on coordinate planes for a different from 1.

Start at Identity, switch to Leak 0.10, then ReLU. Compare the reported output separation with the visual overlap. Return to 0.01 and ask which distinction is exact and which would be difficult to recover after rounding.

What this does not prove

A positive leak does not make an entire network invertible: earlier projections can already have lost information, and later layers can discard it. Nor does this experiment establish that LeakyReLU trains better. There is no learned weight matrix, optimization, loss function, quantization or dataset here. ReLU can also preserve distinctions on restricted input sets, such as the nonnegative octant.

The activation is evaluated by TensorFlow.js 4.22.0 on its CPU backend, with Three.js 0.180.0 rendering the geometry. Values are floating-point approximations. The inverse-sensitivity and lattice-count arguments above are direct derivations from the stated map, not benchmark results.
