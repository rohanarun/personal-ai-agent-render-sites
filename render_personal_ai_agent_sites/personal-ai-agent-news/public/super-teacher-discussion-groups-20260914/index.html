Discussion Group Desk

For teachers preparing a discussion: anonymous labels in, balanced random groups out. Review the arrangement before sharing.

No groups assigned.

2–100 labels, up to 40 characters each. Blank lines ignored; outer whitespace trimmed. Duplicate labels are rejected. Use anonymous labels, not student records.

A balanced size is not a balanced classroom

The example uses fictional labels P01–P11. A copied roster is shuffled with D3's shuffle implementation, then dealt cyclically into the selected number of groups. Every label appears once and group sizes differ by at most one. Larger groups occur first when the division has a remainder.

Random placement does not account for accessibility, language, conflicts, learning needs or classroom relationships. Make those decisions separately. This is not a student-scoring model or a claim of educational effectiveness. A fresh shuffle can repeat the same arrangement; it does not guarantee new partners or cryptographic randomness.

Export preserves the current assignment as plain text. Editing the roster or group count clears stale results. No roster is saved across reloads. Grouping runs locally without a model request; the separate first-party video below loads from remote storage.

Beyond a single preparation task

Super Powers AI offers an assistant with browser and app capabilities. A teacher evaluating repeated preparation work should start with non-sensitive material and a specific output to review. This desk is standalone and does not invoke the assistant.
