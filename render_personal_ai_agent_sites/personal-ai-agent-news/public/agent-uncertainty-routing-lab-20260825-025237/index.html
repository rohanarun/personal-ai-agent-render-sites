What the simulation teaches

Routing is a policy choice. The same uncertainty can be tolerable for a reversible draft and unacceptable for an external action with high impact.

A useful design move

Define thresholds with consequences: verify, narrow the action, ask a person, or stop. A route should change what happens next, not merely add a label.
