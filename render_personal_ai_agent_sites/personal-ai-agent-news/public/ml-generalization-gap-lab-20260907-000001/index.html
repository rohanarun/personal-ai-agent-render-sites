A small gap alone does not establish useful predictions: both errors can remain high. Increasing capacity can improve fit while widening the difference between training and validation. Validation guides model selection; a separate untouched test set is needed for a final estimate after tuning.

Illustrative model and limits

Capacity c ranges from 1 to 10; n is the training sample count. Constants are chosen for teaching. No estimator is trained here.

bias = 0.8 / c; variance = 0.015 * c * c * sqrt(20 / n); training = 0.08 + bias; validation = training + variance; gap = variance.

The model assumes independent samples from an unchanged distribution. It excludes noisy estimates, dataset shift, double descent, leakage, and cases where validation error is below training error. More data reduces only its variance term. These error levels are not predictions for a real model.
