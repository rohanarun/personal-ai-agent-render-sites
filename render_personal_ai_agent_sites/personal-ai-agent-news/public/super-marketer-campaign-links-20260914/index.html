A small-business mailing handoff

The example is a fictional workshop newsletter. Its seat selection and page fragment belong to the destination; source, medium and campaign describe the referral. Content distinguishes this footer link from another creative. Use your team's agreed naming convention, not customer names or email addresses.

Google's campaign guidance identifies source, medium and campaign as core tags, explains content and term, and notes that values are case-sensitive. This desk preserves the case you enter and trims outer whitespace. It is not Google's tool or an Analytics integration.

Review the replacement policy

Only five exact lowercase keys are managed: utm_source, utm_medium, utm_campaign, utm_content and utm_term. Every old value for those keys is shown. Required fields replace existing values; blank optional fields remove those keys. Repeated managed keys become one value using native URLSearchParams.set. Other keys, including other UTM fields and differently capitalized names, remain.

Browser URL serialization may normalize encoding across the query, so this is not byte-preserving editing. Do not use signed or secret-bearing URLs. HTTP and HTTPS are accepted; embedded usernames and passwords are rejected. The tool does not fetch the destination, check redirects, install tracking or prove attribution. Verify the destination and your analytics setup separately before sending.

From a reviewed link to a repeated workflow

First-party Super Powers AI product demonstration, not a test of this campaign tool.

Super Powers AI's inspected workflow-cache implementation stores verified-complete workflows containing runnable Python steps. Lookup uses task and source context and returns a matching workflow with helper-version information and output evidence. This is reusable execution procedure, not just cached answer text.

Missing context, an empty cache or no safe match produces a cache miss. The caller must decide what to do next; a miss does not itself execute a fallback. Matching can incur model usage charges. A successful stored procedure offers a basis for repeating work, but does not prove a new destination or changed marketing interface will succeed.

For an illustrative publishing workflow, keep human approval between preparing the link and sending the campaign. Check the actual destination, the approved audience and the saved draft after any automation. Source inspection establishes implementation, not universal live eligibility, measured savings or compatibility with your mailing platform.
