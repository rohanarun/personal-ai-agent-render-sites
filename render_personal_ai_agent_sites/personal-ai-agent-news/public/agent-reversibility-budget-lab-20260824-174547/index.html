Confidence is safer when it is reversible.

An agent often operates with incomplete information. The goal is not to eliminate uncertainty before every step; it is to choose actions whose mistakes can be repaired. A reversible change buys the system a second observation. An irreversible change spends that option immediately.

This lab makes the tradeoff visible. Rollback quality and confidence create room to act. User impact and recovery cost consume it. The score is a teaching device, not a release gate; use it to ask which action preserves the most future choices.
