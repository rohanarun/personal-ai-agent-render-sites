What to notice

Freshness is part of truth.

Agents should treat context as a time-bound observation whose usefulness depends on the decision it supports.

Age

Old retrievals lose authority.

A source can be accurate when retrieved and still become unsafe later if the underlying world changes.

Volatility

Fast worlds shorten the shelf life.

Prices, permissions, availability, and schedules need stronger freshness checks than stable background knowledge.

Refresh

Re-query before the costly step.

Refreshing at the right boundary keeps the loop efficient while reducing the chance that stale facts drive an external action.

Evaluation

Measure stale-context failures.

Track whether facts changed between retrieval and action. That evidence can set practical expiry policies better than a universal timer.
