One layer, no rendering

The illustrative sample contains an ampersand, an em dash reference, and escaped angle brackets. A nested reference such as &amp;lt; becomes &lt; after one pass, not an opening angle bracket. Repeating the button always starts from the original input.

Text and attribute contexts can treat ambiguous references differently. For example, &copy=1 decodes in text context but remains unchanged in attribute context. This tool uses he 1.2.0 with browser-like, non-strict decoding; it is not an HTML validity checker.

Decoded markup remains literal text here. It is not sanitized HTML and may be unsafe if inserted into an HTML sink elsewhere. Decoding is not URL decoding, Unicode normalization or removal of tags. Do not use this as an XSS filter.

Up to 100,000 characters are processed in this page, without sending the copy to a model. The download contains the full decoded text. Use non-sensitive examples; the separate video below loads externally.
