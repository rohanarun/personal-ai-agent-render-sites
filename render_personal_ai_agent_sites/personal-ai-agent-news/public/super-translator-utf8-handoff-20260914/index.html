Translator Text Handoff

Prepare a UTF-8 text delivery with explicit line endings and an optional byte-order mark. No retyping into a second editor just to change the export format.

Agree on the receiving format
A UTF-8 BOM is the three-byte signature EF BB BF. It is optional in UTF-8 and is not an endianness switch. Some receivers expect it; others reject it or treat it as content. Follow the recipient's specification, not a universal default.
This export normalizes CR, LF and CRLF line breaks to your selected style. A leading U+FEFF in pasted text is removed before the optional signature is applied, preventing a doubled BOM. Other text and trailing line breaks remain. There is no translation, Unicode normalization or encoding detection. Empty input cannot be exported.
Open a test delivery in the actual destination before sending the final file. The editor runs locally in this page; it does not upload its text. External product video and links still make network requests. Reloading discards edits.
Repeatable work, beyond text export
Illustrative workflow: prepare approved copy, export the agreed file format, place it in the destination application, then verify the imported text. This utility handles only the export step.
