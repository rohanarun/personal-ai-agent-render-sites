A safe continuation makes its assumptions testable before it changes anything.

Bind the token to state

Compare the token’s expected version, owner, and permissions with the current run before using its cursor.

Re-check the world

External data can change while the agent is paused. Refresh the facts that matter to the next action.

Invalidate cleanly

When the token is stale, return a reason and safe restart path instead of silently replaying old work.

This simulation is a teaching model, not a production resume policy. It demonstrates a contract-first pattern: treat continuation as a claim, compare it with current state, and gate high-impact actions.
