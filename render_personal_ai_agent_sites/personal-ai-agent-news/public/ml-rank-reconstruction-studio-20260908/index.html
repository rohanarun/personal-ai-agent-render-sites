A matrix as a sum of components

Singular value decomposition expresses A as U S V-transpose. Each singular value scales an outer product of a left and a right singular vector. Keeping the largest k singular components forms a reconstruction of rank at most k; zero singular values do not add rank.

The stripe pattern repeats one row, so one component can reconstruct it up to numerical roundoff. The diagonal pattern has six equal singular values: no single component captures most of its squared energy. Tied singular values can yield different component directions, so the partial image is not uniquely determined in that case.

Energy is not importance

The retained fraction is the sum of kept squared singular values divided by the sum of all squared singular values. Squared reconstruction error sums the squared differences over all 36 raw entries. At k = 0, the reconstruction is zero; at k = 6, all components are kept.

A small reconstruction error does not guarantee that a feature important for a downstream task survives. This demonstration neither trains an LLM nor performs low-rank adaptation. It decomposes an uncentered synthetic matrix; unlike a centered PCA workflow, the mean pattern is not removed.

For the all-zero matrix, the energy fraction is undefined because both numerator and denominator are zero. The reconstruction and its error are still zero. Grayscale clipping is only a display choice and cannot be used to infer the raw matrix's rank.
