An eigenproblem chooses the samples

J has zero diagonal and off-diagonal J[k-1,k] = k / sqrt(4k squared - 1)
x_i = eigenvalue_i(J)
Probability weight_i = first component of normalized eigenvector_i squared

The eigenvectors supply positive weights that sum to one. The usual integral weights are twice these probability weights. ml-matrix solves the symmetric tridiagonal eigenproblem; nodes and weights are not taken from a lookup table.

An n-node Gauss-Legendre rule integrates every polynomial of degree at most 2n-1 exactly in exact arithmetic. That guarantee does not extend to all functions, and floating-point roundoff remains. Symmetry also makes odd powers integrate to zero even beyond the guaranteed degree.

Test the boundary of the guarantee

For n = 3, x to degree 5 is guaranteed exact, while x to degree 6 is not. The exact expectation of x to even degree d is 1/(d+1); for odd degree it is zero. Exponential and oscillating examples use the analytic references sinh(t)/t and sin(t)/t, both defined as one at t = 0.

More samples can resolve structure that a sparse rule misses. But no finite set of evaluations is a universal accuracy certificate. This tool reports actual error against known formulas, not a general a priori error bound. It models a one-dimensional uniform expectation, not high-dimensional Monte Carlo or a learned data distribution.

JSON retains the Jacobi matrix, eigenvectors, nodes, weights, function values, and both estimates in double precision. The plot rescales vertically for each function; signed contributions can cancel.
