What the simulation teaches

Evidence gathering is a decision, not a reflex. Its value rises when the signal can change a high-impact action and falls when collection is costly or unlikely to reduce uncertainty.

A useful design move

Give the agent a stop rule: gather evidence only when expected decision improvement exceeds the collection cost, then act or route the case explicitly.
