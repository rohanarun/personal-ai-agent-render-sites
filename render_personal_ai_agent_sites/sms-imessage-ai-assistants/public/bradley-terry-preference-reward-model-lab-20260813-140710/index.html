The model starts undecided: every response has reward zero and every matchup is 50/50.

One difference drives every probability.

The model does not need an absolute “perfect answer” target. It pushes the preferred response above the rejected one.

Compare two candidates

A labeler chooses between outputs for the same prompt. This controls for prompt difficulty and yields a relative preference.

Convert score gaps to odds

The logistic function maps any reward difference to a win probability. Equal scores mean 50/50; a widening gap increases confidence.

Minimize negative log likelihood

Each surprising label costs more loss. Gradient descent adjusts both winner and loser scores, while a zero-mean constraint keeps the scale identifiable.

Preference data records the room, not universal truth.

Reward models reproduce systematic features of collection. Use the controls above to make these failure modes visible.

Position becomes preference.

If labelers choose the left answer more often, response quality and screen order become entangled. Randomize presentation and audit win rates by position.

Averages erase disagreement.

A single scalar reward can hide stable subgroups with different values. The split population shows how contradictory labels compress toward indecision.

Length can become a shortcut.

When detail correlates with approval, the reward model may learn verbosity instead of usefulness. Hold rubric dimensions separately and test counterfactual pairs.
