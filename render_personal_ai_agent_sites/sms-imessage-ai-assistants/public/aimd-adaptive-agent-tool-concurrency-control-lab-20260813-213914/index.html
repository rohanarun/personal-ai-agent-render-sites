The limit is a hypothesis, updated every round.

AIMD turns latency feedback into a compact control law that explores and protects capacity.

Measure

Observe completion, not demand.

Each round samples latency at the current in-flight limit and compares it with a service objective.

Increase

Probe with a small additive step.

Healthy rounds add a fixed amount, preventing exponential overshoot near the capacity boundary.

Decrease

Cut quickly when queues form.

Congested rounds multiply the limit by a factor below one, releasing pressure faster than it accumulated.
