Priority inheritance is temporary. It exists only while the critical waiter depends on the lock owner.

Block

Critical work waits on a low-priority owner.

The high-priority agent cannot proceed until the shared tool session or resource lock is released.

Donate

Propagate priority to the owner.

The low-priority holder executes at the waiter’s effective priority, preventing unrelated medium work from extending the inversion.

Restore

Release the lock and drop the boost.

Once the resource changes hands, normal priorities resume and the critical job can complete.
