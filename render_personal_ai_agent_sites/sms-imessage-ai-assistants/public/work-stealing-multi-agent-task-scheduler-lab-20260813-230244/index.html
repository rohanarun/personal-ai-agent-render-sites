Keep ownership local. Move work only when needed.

Each worker pushes and pops its own deque cheaply. Contention appears only when an idle worker attempts to steal from another queue.

Own

Execute from the local end.

New child tasks stay near the worker that created them, preserving locality and minimizing coordination.

Detect

Steal only after becoming idle.

An empty local deque turns the worker into a thief that samples another worker rather than waiting for centralized assignment.

Balance

Take from the opposite end.

Stealing older tasks from the victim end reduces contention with the owner and transfers useful parallel slack.
