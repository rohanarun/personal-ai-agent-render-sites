Monte Carlo Tree Search repeats four operations. Selection follows an upper-confidence rule. Expansion adds an untried action. Rollout samples a possible future. Backup updates visit counts and rewards along the path. More simulations turn uncertain branches into evidence.

UCT(child) = mean reward + c · √(ln(parent visits) / child visits)
