Why the minimum means overlap.

The intuition is probabilistic, but the operational lesson is practical: signatures are candidate filters, not final semantic judgments.

Turn text into a set

A token shingle is a consecutive run of words. Larger shingles preserve more local order; smaller shingles tolerate paraphrase but produce more accidental overlap.

J(A,B) = |A ∩ B| / |A ∪ B|

Keep one minimum per hash

For each hash function, record the smallest hashed shingle. Across many independent hashes, the chance that two minima agree equals their Jaccard similarity.

P[min h(A)=min h(B)] = J(A,B)

Length buys precision

Eight hashes are quick and noisy. One hundred twenty-eight are steadier. The estimator is unbiased in the ideal permutation model, but any one signature still has sampling variance.

An agent-memory policy

  • Normalize deterministic formatting noise before shingling.
  • Use MinHash to shortlist possible duplicates cheaply.
  • Confirm candidates with exact Jaccard or a task-specific semantic check.
  • Keep provenance when merging so the agent can explain what was retained.
