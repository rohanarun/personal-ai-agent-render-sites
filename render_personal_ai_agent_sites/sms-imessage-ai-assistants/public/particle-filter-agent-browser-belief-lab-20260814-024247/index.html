Belief is a population, not one guess.

A particle filter approximates a probability distribution with weighted samples. That lets it represent ambiguity and multiple modes that a single mean would erase.

Predict through uncertain action.

Every particle follows the agent's intended transition. Motion noise sends some particles to neighboring states, preserving hypotheses for clicks that miss, lag, or land on the wrong element.

xᵢ′ ~ p(stateₜ | stateₜ₋₁, action)

Weight by noisy evidence.

The observation model scores each predicted state against what the agent sees. Similar tabs can remain plausible together; a distinctive modal sharply concentrates weight.

wᵢ ∝ p(observation | xᵢ′)

Resample before belief collapses.

Effective sample size detects when only a few particles carry most weight. Resampling copies strong hypotheses and removes weak ones, then resets weights for the next cycle.

ESS = 1 / Σ(wᵢ²)

Three failure modes worth watching.

Particle depletion

Repeated resampling can erase a plausible mode. Motion noise and occasional global proposals help the filter recover when the interface surprises the agent.

Weak observations

If several browser states look alike, weights remain diffuse. Confidence should stay low instead of inventing certainty from ambiguous screenshots or DOM fragments.

Model mismatch

A filter can only propose transitions it knows. Redirects, popups, and authentication screens need explicit hypotheses or a recovery proposal outside the normal action model.

Grounded in sequential Monte Carlo.

This educational implementation is written directly in browser JavaScript. It uses discrete interface states and systematic resampling, without any model or content-generation API.
