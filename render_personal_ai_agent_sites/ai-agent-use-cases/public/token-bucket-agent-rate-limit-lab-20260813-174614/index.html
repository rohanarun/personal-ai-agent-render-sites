Burst freedom with a bounded promise.

Refill, but never overflow

Elapsed time creates tokens at rate r. Capacity B caps saved credit, so an idle agent can accumulate only a known burst allowance.

tokens = min(B, tokens + rΔt)

Spend before dispatch

A request with cost c passes when enough tokens exist. This admission decision occurs before the downstream service is touched.

pass iff tokens ≥ c

Queue or drop explicitly

Queues trade rejection for latency. Drops preserve latency but force callers to back off. Retry storms become worse when rejected calls immediately return.

burst budget = B / c

Agent-system actions

  • Give expensive tools higher request costs.
  • Keep retries behind randomized backoff.
  • Separate user-facing and background buckets.
  • Export queue age before it becomes hidden latency.
