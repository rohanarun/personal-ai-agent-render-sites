The log is truth. State is a view.

Event sourcing separates what happened from the convenient current representation an agent reads.

Append

Record facts, never edits.

Each accepted command emits a new domain event with a stable order. Prior records stay immutable.

Project

Fold events into useful memory.

A deterministic reducer replays the log to build current state, historical state, or a specialized read model.

Snapshot

Accelerate without erasing history.

A snapshot stores a projection at one revision. Later rebuilds start there and replay only subsequent events.
