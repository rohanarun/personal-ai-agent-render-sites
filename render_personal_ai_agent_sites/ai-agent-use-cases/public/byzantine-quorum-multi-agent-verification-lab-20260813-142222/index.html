Quorums work by forced overlap.

Two sufficiently large quorums must share honest members. Those honest members refuse to certify conflicting answers.

n ≥ 3f + 1

Propose

An agent broadcasts a candidate answer and evidence. Byzantine participants may send a false value, send different values to different peers, or remain silent.

Prepare

Each recipient compares messages with its own observation. A matching vote is useful only when enough independently behaving agents can contribute.

Commit

A quorum certificate collects enough matching votes to finalize. Safety and liveness are separate: a conservative threshold may prevent false commits while also causing stalls.

Three ways collective confidence fails.

Multi-agent debate improves reasoning only when diversity, communication, and verification assumptions hold.

Correlated errors

Several honest-looking agents may share the same model, prompt, retrieval source, and blind spot. Counting replicas does not create independent evidence.

Audit provenance, not just votes.

Equivocation

A malicious or compromised agent can tell different peers different stories. Signed transcripts and cross-checking make contradictory claims detectable.

Make messages attributable.

Network partitions

Lost messages can keep a safe system from deciding. Lowering the threshold restores liveness but may destroy the quorum overlap that protects safety.

Do not tune safety away.
