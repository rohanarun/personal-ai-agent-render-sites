Markers turn an execution into a consistent cut.

Record the initiator immediately

The initiator saves its local state, starts recording incoming channels, and sends a marker on every outgoing channel before later messages.

record(Pᵢ); marker → outgoing

First marker records a process

An unrecorded process saves local state on its first marker, treats that incoming channel as empty, and forwards markers.

first marker ⇒ local state + markers

Capture messages before markers

After recording local state, a process records messages arriving on each incoming channel until that channel's marker arrives.

channel state = messages before marker

Agent-system actions

  • Preserve FIFO ordering per logical channel.
  • Attach snapshot IDs to every marker.
  • Persist local and channel state atomically.
  • Validate recovery from captured cuts.
