Inference memory

Generation is a memory-management problem.

KV caching avoids recomputing attention states for earlier tokens, but sequence lengths vary and batches change continuously. Fixed contiguous reservations waste space. Paging maps logical token blocks to any free physical block and enables copy-on-write prefix sharing.

The mechanism

Logical order. Physical freedom.

Append states

Each layer stores key and value vectors for every processed token. Decode steps append new entries rather than recomputing the prefix.

KV length grows one token per step

Map pages

A sequence’s logical blocks point to arbitrary physical blocks. No giant contiguous reservation is required, so short and long requests can coexist.

logical block → physical block ID

Share prefixes

Requests with identical prompts reference the same read-only blocks. A divergent continuation allocates new pages through copy-on-write.

one prefix · many page tables

Fragmentation

Only the final page of a sequence may be partially filled. Smaller pages reduce tail waste but increase page-table and scheduling overhead.

Eviction

Under pressure, removing a reusable prefix can be more expensive than removing a cold continuation. Policy needs reuse information, not age alone.

Batching

Continuous batching replaces completed sequences immediately. Higher occupancy raises throughput until memory bandwidth or cache pressure becomes dominant.
