Prediction and evidence take turns.

The scalar filter below makes every state transition visible. Real systems extend the same idea to vectors and matrices.

Predict forward

Before seeing a new measurement, the filter carries the previous estimate forward. Process noise adds uncertainty because the hidden tool state may have changed.

x⁻ₜ = xₜ₋₁    P⁻ₜ = Pₜ₋₁ + Q

Compute trust

The Kalman gain compares predicted uncertainty with measurement noise.

Kₜ = P⁻ₜ / (P⁻ₜ + R)

Correct with surprise

The residual is measurement minus prediction. High gain follows it aggressively; low gain treats it as noise.

xₜ = x⁻ₜ + Kₜ(zₜ − x⁻ₜ)

Operational meaning

  • Increase Q when tool quality can genuinely change quickly.
  • Increase R when telemetry is noisy or weakly calibrated.
  • Inspect residuals for outliers and model mismatch.
  • Do not confuse a smooth estimate with a semantic guarantee.
