Calculating assignment regret.

Local wins can make the team lose.

The assignment problem asks for a one-to-one matching between agents and tasks that minimizes total cost. A greedy dispatcher repeatedly chooses the cheapest remaining cell. The optimal method reasons across the entire matrix, preserving scarce specialists for the tasks where alternatives are expensive.

min Σᵢ cost(i, assignment(i)) subject to one agent per task

Represent capability as cost

Latency, expected errors, tool access, and domain fit can be combined into a comparable task cost.

02

Enforce one-to-one matching

Every agent receives exactly one task and every task receives exactly one agent in the basic assignment formulation.

03

Optimize the full team

The Hungarian method solves the problem in polynomial time. This small lab uses exact enumeration so every candidate assignment remains inspectable.
