Three views of the same error.

The terms are added, then clamped by worker limits. Their different time horizons explain both the power and the tuning difficulty of PID control.

Proportional sees now.

P multiplies the current queue error. It reacts immediately to a backlog, but a small persistent error can remain if proportional action alone balances near the target.

P(t) = Kp × error(t)

Integral remembers before.

I accumulates error over time, pushing through persistent bias. Saturated capacity can make that memory grow too far, so this lab applies anti-windup when the worker ceiling is reached.

I(t) = Ki × Σ error

Derivative anticipates next.

D reacts to how quickly error changes. It can damp overshoot after a sudden burst, but noisy queue samples can make an aggressive derivative gain jitter.

D(t) = Kd × (error(t) − error(t−1))

Know what this controller cannot decide.

Cold-start delay

Real workers may take seconds or minutes to become useful. A production controller must model pending capacity instead of treating desired workers as instantly active.

Cost boundaries

Queue stability is not the only objective. Minimums, maximums, budgets, and provider quotas should constrain the controller before it changes infrastructure.

Admission control

Autoscaling cannot rescue an unbounded overload. Backpressure, shedding, and graceful degradation remain necessary when demand exceeds the worker ceiling.
