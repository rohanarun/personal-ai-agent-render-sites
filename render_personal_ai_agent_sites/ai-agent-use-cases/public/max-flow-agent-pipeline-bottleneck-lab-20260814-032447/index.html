The cut tells you what to buy.

Adding capacity outside the minimum cut cannot improve end-to-end throughput. Upgrade an edge crossing the cut, recompute, and watch the limit move.

Respect every edge capacity.

Flow on an edge can never exceed its capacity. Intermediate stages conserve work: what enters must leave unless the task is still queued.

0 <= flow(u,v) <= capacity(u,v)

Search the residual graph.

Forward residual capacity allows more work through. Reverse residual capacity lets the algorithm revise an earlier routing decision.

residual(u,v) = capacity(u,v) - flow(u,v)

Stop at the minimum cut.

When the sink is unreachable in the residual graph, reachable and unreachable nodes define a cut whose capacity equals the maximum flow.

max flow = min cut capacity

Three failure patterns, three different fixes.

Fan-out starvation

Retrieval and planning have spare capacity, but intake cannot feed them. Increase source fan-out before scaling downstream workers.

Tool-side collapse

A degraded tool edge redirects work toward the model path. Residual capacity makes that rerouting visible before queues become incidents.

Verification choke

Every successful branch converges on verification. When the final edge is in the minimum cut, upstream scaling buys no throughput.
