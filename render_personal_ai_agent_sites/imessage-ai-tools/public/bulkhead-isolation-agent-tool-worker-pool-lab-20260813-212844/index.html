Capacity boundaries become failure boundaries.

A bulkhead does not add workers. It decides which workload is allowed to consume which workers.

Partition

Bound

Limit each waiting room.

Queues must be finite. Reject or defer excess work before memory and latency grow without bound.

Measure

Tune utilization against isolation.

Too many compartments waste idle capacity; too few allow noisy workloads to recreate a shared bottleneck.
