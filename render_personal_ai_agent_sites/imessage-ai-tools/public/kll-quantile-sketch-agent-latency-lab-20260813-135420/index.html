Compaction is the whole trick.

KLL spends more samples where uncertainty matters, then repeatedly halves overflowing buffers. Surviving values represent larger portions of the original stream.

A

Fill level zero

Every latency arrives at the bottom level with weight one. The sketch does not need to know the stream length in advance.

B

Sort, flip, halve

When a level exceeds capacity, sort it and randomly keep either the odd or even positions. The survivors move up one level.

C

Query weighted order

A sample at level three stands for eight original events. Sorting all retained samples by value and accumulating weights reconstructs approximate ranks.

D

Merge across workers

Combine retained items from regional sketches at their existing weights, compact again, and query one fleet-wide percentile without shipping raw traces.
