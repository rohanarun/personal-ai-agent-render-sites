Computing a balanced routing plan.

Normalize until both sides agree.

Optimal transport moves supply to demand at minimum cost. Entropic regularization smooths the problem, producing a positive kernel. Sinkhorn iterations alternately scale rows to match task supply and columns to match tool capacity. The result converges rapidly to a balanced soft assignment.
