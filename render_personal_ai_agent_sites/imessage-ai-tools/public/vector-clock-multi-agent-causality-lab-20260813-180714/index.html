Three counters make causality visible.

Increment on every event

Agent i advances only component i before recording a local event or sending a message.

Vᵢ[i] ← Vᵢ[i] + 1

Messages carry knowledge

A send includes a copy of the sender’s entire vector, not a physical timestamp.

message.clock = copy(Vsender)

Receive by merge, then tick

The receiver takes the component-wise maximum with the message clock, then advances its own component.

Vᵣ ← max(Vᵣ,Vmsg); Vᵣ[r]++
